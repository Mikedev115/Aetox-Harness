## เริ่มใช้

1. **ติดตั้ง** จาก Microsoft Store หรือตัวติดตั้งข้างบน เลือกช่องทางเดียวแล้วใช้ช่องทางนั้นต่อไป เพราะตัวจาก Store
   กับตัวจากตัวติดตั้งเก็บการตั้งค่า แชท และคีย์แยกกัน
2. **ต่อโมเดล** เปิด **ตั้งค่า › โมเดล** แล้วล็อกอินด้วย ChatGPT, GitHub Copilot หรือ OpenRouter หรือใส่คีย์
   หรือชี้ไปที่ LM Studio หรือ Ollama ในเครื่องของคุณ
3. **สั่งงาน** เลือก **ผู้ช่วย** สำหรับไฟล์ เอกสาร และเว็บ หรือ **โค้ด** สำหรับโฟลเดอร์โปรเจกต์ แล้วบอกว่าอยากได้อะไร

## ทำไมโมเดลเดิมทำได้ดีขึ้น

โมเดลคิด ส่วนที่เหลือ harness ทำ

- **มือ** ไฟล์จริง เบราว์เซอร์จริง เทอร์มินัลจริง โมเดลเขียน แล้ว Aetox ส่งไฟล์ `.xlsx` สไลด์ หรือ commit ให้คุณ
- **ความรู้ที่โมเดลไม่มี** สกิลเก็บเรื่องที่โมเดลเดาเองไม่ได้ เช่น ขนาดจอ 1280×720 ของห้องนำเสนอ
  วิธีที่คนร้ายเจาะการเช็ค path หรือการปัดเศษในใบกำกับภาษีไทย
- **สกิลที่เป็นส่วนหนึ่งของระบบ ไม่ใช่ของแปะเพิ่ม** ทุกสกิลเขียนมาให้ใช้เครื่องมือ ตัวตรวจ และตัวสร้างไฟล์ของ Aetox เอง
  โมเดลอ่านแล้วลงมือได้ทันทีด้วยมือที่เข้ากัน สกิลใหม่หรือสกิลที่ปรับทุกตัวต้องวัดบนโมเดลเดียวกันทั้งตอนเปิดและปิด
  ตัวไหนไม่ช่วยจริงก็เอาออก
- **ตรวจก่อนส่ง** รันเทสต์ เปิดไฟล์ที่ทำเสร็จดูเอง และบอกตรง ๆ ว่าส่วนไหนยังพิสูจน์ไม่ได้

harness เดียวกันนี้ใช้กับ 31 providers เปลี่ยนโมเดลเมื่อไหร่ ส่วนที่ดีขึ้นก็ตามไปด้วย

## ผลที่วัดได้

งานโค้ด: 11 งาน × 2 โมเดลสาธารณะของ OpenAI ([`gpt-6-luna`](https://developers.openai.com/api/docs/models/gpt-6-luna), [`gpt-5.6-terra`](https://developers.openai.com/api/docs/models/gpt-5.6-terra) ความคิดระดับ medium) × 3 รอบ เทียบกับ harness อื่นอีกสี่ตัว
ทุกงานตัดสินด้วยเทสต์ซ่อน ใช้บัญชีเดียวกัน และไม่มีการตั้งค่าของผู้ใช้ในทุก harness

- **โค้ดปลอดภัย** 93.3% เทียบ 68.9% ของ harness อันดับถัดไป (omp) บน Luna และ 97.8% เทียบ 77.8% บน Terra (OpenCode, omp และ pi เสมอกัน)
  แรงนำมาจากสกิลความปลอดภัยที่เปิดมาตั้งแต่ติดตั้ง ถ้าปิดสกิลนี้ Aetox จะได้คะแนนช่วงเดียวกับตัวอื่น
- **งานโค้ดยาวหลายรอบ** เทสต์ผ่านมากที่สุดทั้งสองโมเดล (Terra 95.2%, Luna 91.6%)
- **สไลด์และเอกสารไทย** เปิดสกิลเทียบปิดสกิลบนโมเดลเดียวกัน: สไลด์ภาษาไทย 98 เทียบ 49
  ใบกำกับภาษี 100 เทียบ 85–94
- **จุดที่ยังแพ้** ใช้โทเค็นมากกว่าตัวอื่น (Luna 6.4M เทียบ 0.8–4.5M ราว 90% เป็นอินพุตที่แคชไว้) บน Terra
  ช้ากว่า harness สองตัว และบั๊ก SWE-bench หนึ่งข้อบน Luna แก้ได้ 1 ใน 3 รอบ

คะแนนแต่ละรอบแกว่ง 1.5–2.5 จุด ส่วนต่างไม่กี่จุดจึงถือว่าเสมอกัน ทุก prompt ไฟล์ตั้งต้น และเทสต์ซ่อนเปิดเผยไว้ให้รันเองได้:
[รายงานโค้ดล่าสุด](docs/reports/coding-harness-1.10.0/README.md) ·
[เปิดและปิดสกิล](docs/reports/SKILL-BENCH.md) · [รายงานทั้งหมด](docs/reports/README.md)

## โมเดล

31 providers ทั้งบนคลาวด์และในเครื่อง ChatGPT (Codex), GitHub Copilot และ OpenRouter ล็อกอินได้เลย ที่เหลือใช้คีย์ API
หรือที่อยู่ของเซิร์ฟเวอร์ในเครื่อง LM Studio และ Ollama ได้เครื่องมือชุดเดียวกับโมเดลใหญ่ เปลี่ยนโมเดลกลางแชทได้
บริบททั้งหมดตามไปด้วย รายชื่อโมเดลถามจาก provider ตอนใช้งาน โมเดลใหม่จึงขึ้นมาเองโดยไม่ต้องรอ Aetox รุ่นใหม่
[ดู provider ทั้งหมด](https://mikedev115.github.io/Aetox-landing/th/features/#models)

สร้างภาพในเครื่องก็ได้ ชี้ Aetox ไปที่ ComfyUI หรือ Stable Diffusion WebUI (Forge Neo, Forge หรือ A1111)
แล้ววาดด้วย GPU ของคุณเอง รวมถึง FLUX.2 klein [สร้างภาพในเครื่อง](docs/LOCAL-IMAGES.md)

> **ใช้ฟรี แต่ไม่ได้แถมโมเดลบนคลาวด์ฟรี** งานจริงต้องมีโมเดล จะเป็นบัญชีหรือคีย์ที่คุณมีอยู่แล้ว หรือโมเดลในเครื่องก็ได้
> ราคาเป็นไปตาม provider ที่คุณเลือก

## ความปลอดภัยและข้อมูลของคุณ

- **ข้อมูลอยู่บนเครื่องคุณ** แชท ไฟล์ และข้อมูลเบราว์เซอร์อยู่บนดิสก์ของคุณ ไม่มีเซิร์ฟเวอร์ของเราคั่นกลาง ไม่มีการเก็บสถิติ
  provider บนคลาวด์เห็นเท่าที่ API ของเขาเห็นตามปกติ
- **คีย์** ผูกกับบัญชี Windows ของคุณ และถูกตัดออกจาก log และผลลัพธ์ของเครื่องมือ
- **คุณเลือกเองว่าให้ทำได้แค่ไหน** ถามก่อน · ถามเฉพาะที่เสี่ยง · เต็มสิทธิ์ ส่วนการเผยแพร่อะไรออกไปข้างนอก
  และการปิดโปรแกรมตามชื่อ จะถามทุกระดับ
- **ไฟล์ลับถูกปฏิเสธ** `.ssh` `.aws` ที่เก็บรหัสของ Windows โปรไฟล์เบราว์เซอร์ และไฟล์คีย์ของ Aetox เอง
  ไม่มีเครื่องมือไหนเปิดได้
- **อะไรเป็นตัวกัน** กฎพวกนี้เป็นการเช็กในโค้ดของ Aetox เอง ไม่ใช่ sandbox ของระบบปฏิบัติการ ถ้าเครื่องมีข้อมูลที่เสียไม่ได้
  ให้ใช้ API key แยกเฉพาะ Aetox และรันใน VM หรือ Windows Sandbox

[รายละเอียดความปลอดภัย](https://mikedev115.github.io/Aetox-landing/th/safety/)

## ซอร์ส สัญญาอนุญาต และคนทำ

Aetox ใช้ฟรี และไม่ใช่โอเพนซอร์ส ติดตั้งได้กี่เครื่องก็ได้ ใช้ทำงานเชิงพาณิชย์ได้ แต่ห้ามแก้ไข แจกจ่ายต่อ เปลี่ยนแบรนด์
หรือขาย ([LICENSE](LICENSE)) สกิล เอเจนต์ prompt และ MCP server ที่คุณเขียนเป็นของคุณ และขายได้ (ข้อ 4)
ซอร์สในรีโปนี้หยุดที่ v1.7.0 และยังอยู่ให้อ่านและตรวจสอบได้ รุ่นหลังจากนั้นส่งเป็นไฟล์ติดตั้งเท่านั้น

ทุกรุ่นมี `checksums.txt` บอก SHA-256 ของทุกไฟล์ ลงลายเซ็นด้วยคีย์อัปเดตของแอป และรุ่นที่ build หลัง 21 ต.ค. 2026 มี `sbom.txt`
