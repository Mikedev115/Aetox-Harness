# 🧭 Aetox v1.11.44

วันที่ 27 พฤศจิกายน 2026

แถวโปรเจกต์ในแถบข้างกลายเป็นแถวที่บอกครบ: ไทล์ที่ใช้โลโก้ของโปรเจกต์เอง, ชื่อบรรทัดบน, "N แชท · พาธ" กับชิปภาษาบรรทัดล่าง และเมนู ⋯ ที่เป็นบัตรของโปรเจกต์ · สร้างโปรเจกต์ในไดอะล็อกกลางจอ · โฟลเดอร์ที่ไม่มี manifest บอกภาษาจากชื่อไฟล์ได้ · ชื่อแชทที่ยาวเลื่อนด้วย transform เนียนขึ้นที่ 30px/s และแถวที่เลื่อนไม่ต้องวัดใหม่ทุกครั้งที่ชื่อในแถวเปลี่ยน

- **ตอนนี้** (`39ab66134`, `117da7c2d`, `cc52820ac`)
  - ไทล์ 22px: โลโก้ที่โปรเจกต์มีเอง (อ่านจากโฟลเดอร์ จำกัด 48KB) → ไอคอนเฟรมเวิร์ก/ภาษาจาก projstack → ตัวอักษรแรกในกรอบเส้นบาง · ไม่มีสีประจำโปรเจกต์แล้ว
  - ทั้งรายการโปรเจกต์และแถวของประตูผู้ช่วยใช้ทรงเดียวกัน: ชื่อบรรทัดบน, "N แชท · พาธโฟลเดอร์" บรรทัดล่าง, ⋯ กับดินสออยู่ขวาตลอด (ไม่โผล่ตามเมาส์ และแถวไม่ขยับตอนชี้) · ดินสอเปิดหน้าโปรเจกต์
  - เมนู ⋯ เป็นบัตรของโปรเจกต์: ไทล์+ชื่อ+ดาวปักหมุด, จำนวนแชท, พาธ (กดเปิดโฟลเดอร์), แก้ไขโปรเจกต์, ลบโปรเจกต์ · กว้างเท่าแถว ไม่ล้นออกนอกคอลัมน์
  - รายการโปรเจกต์พับโปรเจกต์ที่ไม่ได้เปิดเกิน 30 วันเป็นแถว "เก่ากว่า 30 วัน · N โปรเจกต์" (`openedAt` มาจาก ProjectMeta ผ่าน cockpit)

## ชิปภาษากลับมา และโฟลเดอร์ที่ไม่มี manifest บอกภาษาได้

- **เดิม** การ์ดโปรเจกต์มีชิปภาษาใต้ชื่อ พอแถวถูกทำเป็นบรรทัดเดียวชิปก็หายไปทั้งบรรทัด ภาษาในแถวจึงเหลือแต่ไทล์ 22px ซึ่งแถว Aetox ใช้โลโก้ของโปรเจกต์ · projstack อ่านแค่ manifest ที่ราก (go.mod, package.json, Cargo.toml และเพื่อนบ้าน) โฟลเดอร์ที่ไม่มี manifest จึงไม่มีป้ายอะไรเลย
- **ตอนนี้** (`f5adca5ee`, `10a98d137`)
  - projstack: โฟลเดอร์ที่ไม่มี manifest บอกภาษาจากชื่อไฟล์ที่รากได้ ภาษาเดียว ตามลำดับ `.html/.htm` → html, `.ts/.tsx` → typescript, `.js/.jsx/.mjs` → javascript, `.py` → python, `.go` → go, `.rs`, `.php`, `.rb`, `.java`, `.css` · ไม่เปิดไฟล์ ไม่เดินโฟลเดอร์ย่อย และ manifest ยังชนะไฟล์เสมอ (โมดูล Go ที่มีหน้า html อยู่ด้วยยังเป็น Go)
  - แถวโปรเจกต์ได้ชิปคืนแบบการ์ดเดิม (ไอคอน 12px + ชื่อภาษา) เป็นบรรทัดของตัวเองใต้พาธ · ไอคอนที่ไทล์ถืออยู่แล้วไม่ถูกวาดซ้ำเป็นชิป · โฟลเดอร์ที่ไม่บอกอะไรเลยไม่มีตัวคั่นลอย
- เทสต์: `TestAFolderOfFilesIsNamedByWhatItHolds` (หน้าเว็บหนึ่งโฟลเดอร์ = html เดียว, manifest ชนะไฟล์) · `projectRowStack.test.ts`

## ชื่อแชทในแถบข้าง: เนียนขึ้น ชี้แล้วไม่หด และช้าลง

- **เดิม** อนิเมชั่นขยับด้วย `text-indent` เบราว์เซอร์จึงจัดหน้าใหม่และปั้นรูปอักษรไทยใหม่ทุกเฟรม ตัวอักษรไหลออกมาเป็นขั้น ๆ · ชี้เมาส์แล้วอายุ, ⋮ และปุ่มปักหมุดโผล่พร้อมกัน ชื่อหด 226 → 147px (วัดบน dev) และ marquee วัดระยะไว้ก่อนส่วนนั้นจะเข้ามา จึงเลื่อนเกินแล้วสะบัดกลับ · ยังใช้ `direction:alternate` วนไม่จบ ส่ายไปมาทุกครั้งที่เมาส์ผ่าน · 45px/s
- **ตอนนี้** (`35dec8e42`, `535cdf195`, `206a8aa0b`)
  - keyframe เป็น `transform translateX` (คอมโพสิต) ไม่ใช่ `text-indent` · ลำดับ hold → travel → hold → return เหมือนเดิม แต่เลื่อนหน้า→หลังรอบเดียวแล้วหยุด ไม่ alternate
  - 30px/s แทน 45 (เจ้าของ 27 พ.ย. 2026: "ช้ากว่านี้นิดนึง") — ชื่อ 70px ใช้เวลาราวสองวินาที
  - อายุอยู่บนแถวตลอด ⋮ เข้าไปแทนที่ในช่องเดิม ชื่อจึงกว้างเท่าเดิม (195px) ทั้งตอนพักและตอนชี้ · แถบแคบกว่า 220px จองช่อง ⋮ 22px เอง
  - ปักหมุดเป็นหมุดเล็ก ๆ หน้า-ชื่อ ไม่ใช่ปุ่มบนแถว และการปักหมุดอยู่ในเมนู ⋯ ที่มีอยู่แล้ว
  - วัดระยะหลัง hover นิ่งแล้ว และถามซ้ำได้ถึง 3 เฟรมถ้ายังไม่เห็นส่วนล้น (ชี้ครั้งแรกหลังรีโหลด)
- เทสต์: `sidebarMarquee.test.ts` 5 ตัวใหม่ · `sidebarHistory.test.ts` ปรับ 2 ตัว (ปักหมุดจากเมนู, ไม่มีปุ่มบนแถว)

## แถวที่เลื่อนวัดใหม่เฉพาะตอนแถวสลับกัน
