# 🪟 Aetox v1.11.19

วันที่ 16 พฤศจิกายน 2026

**รุ่นนี้ยกเครื่องเรื่องเอกสาร: แยกสกิลทำเอกสารเป็นสามชั้น — แนวทางกลาง, หน้ากระดาษรายภาษา, และเทมเพลต — พร้อมสกิลภาษาไทย อังกฤษ จีนที่อ้างมาตรฐานจริงของแต่ละภาษา · เอกสารที่ผลิตออกมาพิมพ์ A4 ได้จริง มีสารบัญที่เลขหน้าถูก ไม่มีลายน้ำ และตารางไม่บีบคอลัมน์ข้อความอีก**

## สกิลทำเอกสาร แยกเป็นสามชั้น

- **เดิม** สกิล `aetox-report` ตัวเดียวรับทั้ง "จะเล่าอะไร" และ "หน้ากระดาษเป็นอย่างไร" ไม่มีเทมเพลตให้ยึด เอเจนต์จึงคิด CSS เองทุกครั้ง — ผลคือรายงานที่ส่งให้ผู้บริหารเมื่อ 15 พ.ย. ออกมา 9 หน้าโดยคอลัมน์ "รายการ" เหลือ 52pt (วัดจาก PDF: `#=21pt · รายการ=52pt · ผล=433pt` บนเนื้อหา 506pt) ภาษาไทยขาดทีละตัวอักษร เลข 10 แตกเป็น 1/0
- **รุ่นนี้** `aetox-document` = หลักการที่ใช้ได้ทุกภาษา (โครง ISO 5966 §6.4, รูปแบบรายงาน/แผ่นเดียว, การพิมพ์, การเติมเลขหน้าสารบัญ, การตรวจก่อนส่ง) — ไม่มีฟอนต์หรือขอบกระดาษของประเทศใดฝังอยู่ และมีเทสต์กันไม่ให้หลุดกลับเข้ามา
- `aetox-document-th` · `aetox-document-en` · `aetox-document-zh` = หน้ากระดาษของภาษานั้น ๆ พร้อมเทมเพลตที่พิมพ์ตรวจแล้ว
- `aetox-report` กลับเป็นสกิลสอนล้วน: ซึ่งรูปแบบเล่าเรื่องไหน (chart/diagram/table/picture), ลำดับเรื่อง, การอ้างฐานของตัวเลข

## หน้ากระดาษไทย ตามคู่มือการพิมพ์หนังสือราชการ

- **เดิม** ไม่มีที่ให้เลขของงานพิมพ์เลย ตัวเลขที่ใช้อยู่เป็นของรายงาน HTML ทั่วไป
- **รุ่นนี้** จากคู่มือการพิมพ์หนังสือราชการ (ที่ นร 0106/ว 2019, 30 พ.ย. 2553): ขอบซ้าย 3 ซม. · ขอบขวา 2 ซม. (พื้นที่พิมพ์ 16 ซม.) · ระยะบรรทัด 1 เท่า · ย่อหน้า 2.5 ซม. · บันทึกข้อความ 29pt/Exactly 35pt · ส่วนงาน-วันที่-เรื่อง 20pt — และย่อหน้า 2.5 ซม. ถูกใส่ในเทมเพลตจริง
- เทมเพลตสามตัว: รายงาน (ปก+สารบัญ 7 หน้า), ใบเสนอราคาแผ่นเดียว (1 หน้า), หนังสือราชการ (1 หน้า) — ไม่วาดตราครุฑหรือตราหน่วยงานขึ้นเอง เพราะตราเป็นของหน่วยงาน
- ทุกเลขในเอกสารมาตรฐานมีป้ายที่มา `[S]` มาตรฐานที่อ้าง · `[M]` วัดบนเครื่องนี้ · `[H]` ค่าตั้งของเรา — และเทสต์บังคับว่าไม่มีแถวในตารางสเปกที่ไม่มีป้าย

## ภาษาอังกฤษ · ภาษาจีน

- `aetox-document-en` — A4/Letter, ขอบ 1 นิ้ว (APA/MLA), เนื้อหา 11–12pt, หัวข้อแบบทศนิยม ISO 2145, สารบัญพร้อมเลขหน้า, จดหมาย full block · แหล่ง: Purdue OWL (APA), ISO 5966, ISO 2145
- `aetox-document-zh` — GB/T 9704-2012: ขอบ 37/35/28/26mm (พื้นที่พิมพ์ 156×225mm), 三号仿宋 บนระยะบรรทัดคงที่ 28pt, เยื้องหน้า 2 ตัวอักษร, ลำดับหัวข้อ 一、/(一)/1./（1）, 函 พร้อม發文字號/主送機關/附件/成文日期
- **ข้อจำกัดที่วัดได้**: เครื่องนี้มี SimSun และ Microsoft YaHei แต่ **ไม่มี 仿宋 (simfang.ttf)** ที่ GB/T 9704 กำหนด เทมเพลตจีนจึง fallback เป็น SimSun และเอกสารมาตรฐานสั่งให้บอกผู้ใช้ одинบรรทัดพร้อมวิธีแก้ (ติดตั้งชุดภาษาจีนหรือวางฟอนต์ที่ได้รับอนุญาตข้างเอกสาร) — ไม่วาดหรือเลียนแบบตัวอักษรเอง

## ตารางที่พิมพ์ไม่พัง และไม่มีลายน้ำ

- ตารางกำหนดความกว้างเฉพาะคอลัมน์ที่เนื้อหาสั้น ปล่อยคอลัมน์ข้อความกินพื้นที่ที่เหลือ; จอต่ำกว่า 560px ย่อแถวเป็นบล็อกพร้อม `data-th`
- เอกสารที่วัดใหม่จากเทมเพลตเดียวกัน: `#=28pt · รายการ=330pt · ผล=151pt` แถวละบรรทัด (ของเดิม 52pt และแถวสูงถึง 190pt)
- **ห้ามลายน้ำ ตราแบรนด์ หรือ "made with"** บนรายงาน สไลด์ และเอกสารทุกชนิด (เจ้าของสั่ง 16 พ.ย. 2026) — และเจอของจริงระหว่างทดสอบ: บรรทัด "สร้างจากเทมเพลต aetox-document" ที่ใส่ไว้ท้ายใบเสนอราคาถูกลบ พร้อมเทสต์กันกลับมา
- ตรวจไฟล์ที่พิมพ์จริงทุกครั้งด้วย `pdf` tool + poppler (`pdffonts`, `pdfimages -list`, `pdftotext -bbox`, `pdftoppm -png`)

## เรื่องของสารบัญ: CSS ทำไม่ได้ ต้องเติมจาก PDF

- วัดแล้วว่า `target-counter()` และ `leader()` ไม่ทำงานใน Edge 157 ที่แอปใช้พิมพ์ แต่ `@page` margin box กับ `counter(page)`/`counter(pages)` ทำงาน
- จึงมี `references/toc-pages.ps1` เติมเลขหน้าสารบัญจาก PDF รอบแรก แล้วพิมพ์ซ้ำ — ทดสอบกับงานจริงได้ `3/4/5/5/7/7` และพิมพ์รอบสองไม่ขยับ
- ระหว่างทดสอบเจอบั๊กจริงในสคริปต์: PowerShell ไม่แยกตัวพิมพ์ `$Html`/`$html` จึงเขียนทับชื่อไฟล์ด้วยเนื้อเอกสาร — แก้โดยใช้ `$doc` และบันทึกไว้ในคอมเมนต์
