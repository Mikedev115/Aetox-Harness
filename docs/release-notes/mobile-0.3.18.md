# Aetox Mobile Android 0.3.18

รุ่นนี้ซ่อมสองอย่างที่เจอหลัง 0.3.17: แอปที่จับคู่กับ PC แล้วขึ้น "Windows ยังไม่พร้อมใช้งาน" ทั้งที่งานบน PC เดินอยู่ และวันที่ใน `mobile-latest.json` ที่เขียนเป็น พ.ศ. บนเครื่องไทย

## มีอะไรใหม่

- **ปิดข้อความ "Windows ยังไม่พร้อมใช้งาน" ที่เด้งซ้ำ** — allowlist ของช่องทางมือถือ (`rpc.CallMobile`) ไม่ได้ตามเมธอดที่เพิ่มเข้าฝั่งเดสก์ท็อปสามตัว (`MobileDesk`, `MobileContext`, `MobileSetPinned`) คำขอของมือถือจึงได้ `ErrMethodNotFound` แล้วถูกพับเป็น 503 `unavailable` เป็นผลให้ชีตไฟล์บนโต๊ะว่างตลอด ปั้นดาวโมเดลไม่ได้ และหน้าคอนเท็กซ์ล้ม · ตอนนี้เติมครบและย้ายเป็น map + `MobileMethodAllowed` ให้เทสต์ถามได้
- **กันลืมรอบหน้า** `desktop/mobile_allowlist_test.go` สแกนไฟล์ `mobile_*.go` ที่ไม่ใช่เทสต์ เทียบทุกเมธอด `Mobile*` กับ allowlist — แดงก่อนแก้ด้วยสามตัวนั้น
- **วันที่ใน manifest เป็น ค.ศ.** `Get-Date -Format yyyy-MM-dd` ใช้ปฏิทินวัฒนธรรมของเครื่อง (ไทย → 2569-11-21) ซึ่งเป็นวันที่ที่เครื่องอ่านไม่รู้จัก · สคริปต์ปล่อยเปลี่ยนเป็น InvariantCulture ได้ `2026-11-21` และแก้ไฟล์ที่ปล่อยไปแล้วบน landing
- **ไม่มีอะไรเปลี่ยนเรื่องสิทธิ์หรือการอัปเดต** — แอปยังเช็ก `mobile-latest.json` วันละครั้ง และติดตั้งเมื่อกดเองเท่านั้น
