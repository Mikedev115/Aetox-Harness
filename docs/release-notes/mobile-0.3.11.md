**รุ่นนี้ไม่ได้เปลี่ยนโค้ด Android** — ไม่มีไฟล์ใน `mobile/android` เปลี่ยนตั้งแต่ [0.3.10](mobile-0.3.10.md)
นอกจากการเพิ่มเลขรุ่น (code 13 → 14) · ที่เปลี่ยนคือ **หน้าจอมือถือ** ซึ่งแอปโหลดมาแสดงจาก **Aetox บน Windows 1.11.24**

ต่อจาก [0.3.10](mobile-0.3.10.md)

## มีอะไรใหม่ (มาจาก Aetox บน Windows 1.11.24)

- **เข้าโหมดโค้ดได้จากมือถือแล้ว** — แถว ผู้ช่วย|โค้ด อยู่ใต้ช่องค้นหาในลิ้นชักซ้าย กดครั้งเดียวแล้วเปิดแชทใหม่บนโต๊ะนั้นทันที
  (17 พ.ย. 2026 แถบสลับโต๊ะถูกถอดออกทั้งแถบ ทำให้มือถือเข้าโหมดโค้ดไม่ได้เลย; รอบแรกวางปุ่มไว้กลางแถบบนของแชท
  เจ้าของสั่ง 18 พ.ย. 2026 ว่า "ไม่เอาขึ้นตรงแชทแบบนี้ … แสดงแค่ตอนแสดงฝั่งซ้าย" จึงย้ายเข้าลิ้นชัก)
  แถบบนของแชทกลับเป็น เมนู · ชื่อแชท · แชทใหม่
- **ชีตโปรเจกต์และชีตทีมกลับมา** — อยู่โหมดโค้ดมีชิปโฟลเดอร์เหนือกล่องพิมพ์ กดแล้วเลือกโปรเจกต์จาก PC
  โต๊ะและโฟลเดอร์ที่เลือกติดไปกับข้อความที่ส่ง และถูกจำไว้ข้ามแชท (โฟลเดอร์ที่ PC ไม่มีแล้วถูกทิ้ง)
- **ชิปโมเดล + ระดับคิดในแถบล่าง** — แถบล่างที่เคยโล่งใช้เปิดชีตเดิม เลือกโมเดลและระดับคิดได้จากมือถือ
- **ปิดจุดที่งานหลุดเงียบ** — จอซ่อนแล้วสตรีมถูกปิด ไม่ใช่ตาย · ข้อความที่ค้างตอนเน็ตขาดถูกส่งซ้ำเมื่อเน็ตกลับ
  (อ่านสถานะจริงก่อน ไม่ทิ้งข้อความเพราะสัญญาณมาระหว่างที่ยังไม่ตอบ) · งานยาวที่จบตอนจอปิดมีแจ้งเตือน ไม่เงียบเหมือนเดิม
- **การ์ดชื่อแชทไม่ดันจอกว้างเกิน** — การ์ดที่ไม่มีจุดตัดบรรทัดเคยวัดได้ 441px ในกรอบ 353px ตอนนี้การ์ดหดตามจอ
- **ตัวติดตั้ง 0.3.11** เซ็นด้วยคีย์เดิม `c6330d76…` (versionCode 14) ติดตั้งทับ 0.3.10 ได้ ข้อมูลและเครื่องที่จับคู่ไว้อยู่ครบ
  หน้าจอที่เห็นในแอปยังมาจาก Aetox บน Windows เหมือนเดิม — APK ไม่ได้เก็บหน้าจอไว้ในตัว
