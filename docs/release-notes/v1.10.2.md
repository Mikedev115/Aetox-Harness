# 🧩 Aetox v1.10.2

วันที่ 19 ตุลาคม 2026

**รุ่นแก้ด่วน: แอปมือถือ Android กลับมาเห็นและกดอัปเดตจากคอมได้**

## แอปมือถือขึ้น "ล่าสุดแล้ว" ตลอด ไม่เคยเสนออัปเดต

- **เดิม** v1.10.1 ส่ง APK ของ Aetox Mobile 0.3.2 ไปกับตัวติดตั้ง แต่ไม่มี `android-build.json` ที่บอกเลขรุ่นของ APK นั้น
  คอมจึงตอบมือถือว่ามี APK แต่ไม่บอกว่ารุ่นอะไร แอปที่เป็นรุ่นเก่ากว่า (0.3.1 ลงไป) อ่านว่า "ล่าสุดแล้ว" กดตรวจกี่ครั้งก็ได้คำเดิม และไม่มีป้ายชวนอัปเดตขึ้นมาเลย
- **รุ่นนี้**
  - ตัวติดตั้งมี APK 0.3.2 พร้อม `android-build.json` ที่ SHA-256 ตรงกัน มือถือรุ่นเก่ากว่าจะเห็น "อัปเดตเป็น 0.3.2" ใน ตั้งค่า › การเชื่อมต่อ และป้ายด้านบน
  - ถ้าคอมมี APK แต่ไม่บอกเลขรุ่น แอปขึ้น "คอมไม่ได้บอกรุ่นแอป" แทนการบอกว่าล่าสุด
  - `release-local.ps1` หยุดก่อนบิลด์ถ้าขาด APK หรือ `android-build.json` หรือ SHA ของสองไฟล์ไม่ตรงกัน

ไม่ได้ทำ: ไม่ได้ออก APK ใหม่ โค้ด Android ไม่เปลี่ยนตั้งแต่ `mobile-v0.3.2` CLI ไม่เปลี่ยน ได้เอนจินใหม่ไปพร้อมรุ่นนี้

## เปลี่ยนอื่น ๆ ในรุ่นนี้

- `go.mod` เขียน `golang.org/x/image` เป็น dependency ตรง worktree ของรุ่นจึงไม่สกปรกหลังบิลด์
- tests ที่เพิ่มในรุ่นนี้: `mobile/tests/appUpdate.test.ts` › "does not offer a version the PC cannot vouch for" ตรวจสถานะ `unknown`
