นอกจากการเพิ่มเลขรุ่น (code 12 → 13) · ที่เปลี่ยนคือ **หน้าจอมือถือ** ซึ่งแอปโหลดมาแสดงจาก **Aetox บน Windows 1.11.20**

ต่อจาก [0.3.9](mobile-0.3.9.md)

## มีอะไรใหม่ (มาจาก Aetox บน Windows 1.11.20)

- **เอาตัวสลับโต๊ะกับแถว "ใครทำ" ออกจากเหนือกล่องพิมพ์** — เจ้าของสั่ง 16 พ.ย. 2026 ("เอา…ออกดิ")
  แถบ ผู้ช่วย/โค้ด และแถว "ใครทำ: ผู้ช่วยทำเอง" ไม่มีแล้ว เหลือกล่องพิมพ์กับรายการแชทเท่านั้น
  (ชีปอ่านอย่างเดียว "โค้ด › โปรเจกต์" ยังบอกว่าแชทที่เปิดอยู่เป็นโต๊ะไหน)
- **เอาตัวกรองโต๊ะในเมนูซ้ายออก** — เจ้าของสั่ง 17 พ.ย. 2026 ("ทั้งหมดเอาออกทีครับ") รายการแชทแสดงทุกแชท
  ทั้งผู้ช่วยและโค้ด ไม่ต้องเลือกโฟลเดอร์หรือโต๊ะก่อนเริ่มแชท — แชทใหม่บนมือถือเริ่มที่ผู้ช่วยเสมอ
  (โต๊ะของแชทถูกตรึงตั้งแต่สร้างบน PC)
- **แก้คำตอบล้นขอบจอ** — ที่ความกว้าง 390px คอลัมน์ของคำตอบเคยกว้าง 391px ในกรอบ 358px เนื้อหาขาดขวา 17px
  รวมปุ่ม "สร้างทีมนี้" ในการ์ดทีม; ล็อกคอลัมน์ให้หดตามจอแล้ว วัดซ้ำไม่ล้น
- **บรรทัดขั้นตอนของคนทำงานไม่ตัดกลางคำ** — "reading … · 4 ขั้" เคยขาดกลางคำ ตอนนี้ตัดไม่เกินสองบรรทัดและอ่านครบ
- **ตัวติดตั้ง 0.3.10** เซ็นด้วยคีย์เดิม `c6330d76…` (versionCode 13) ติดตั้งทับ 0.3.9 ได้ ข้อมูลและเครื่องที่จับคู่ไว้อยู่ครบ
  หน้าจอที่เห็นในแอปยังมาจาก Aetox บน Windows เหมือนเดิม — APK ไม่ได้เก็บหน้าจอไว้ในตัว

## ต้องใช้

Aetox บน Windows **1.11.20 ขึ้นไป** (การเปลี่ยนหน้าจอทั้งหมดมาจากฝั่ง Windows รุ่นนี้)
· Android 10 ขึ้นไป · Tailscale HTTPS
