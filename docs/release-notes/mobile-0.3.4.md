# Aetox Mobile Android 0.3.4

**รุ่นเลขใหม่ ไม่มีการเปลี่ยนในตัวแอป Android**

ต่อจาก [0.3.2](mobile-0.3.2.md) เลข 0.3.3 ไม่เคยปล่อย จึงข้ามมาที่ 0.3.4

## มีอะไรใหม่

- **ไม่มีของใหม่ในตัวแอป** โค้ด Android (`mobile/android`) เหมือน 0.3.2 ทุกบรรทัด รุ่นนี้เปลี่ยนแค่เลขรุ่น (code 7)
  ผู้ที่ใช้ 0.3.2 อยู่ไม่จำเป็นต้องอัป
- **การแก้ที่คนเห็นบนมือถือมาจาก Windows** หน้าจอแชตทั้งหมดมาจาก Aetox บน Windows (APK ไม่มีหน้าจอฝังอยู่)
  การ์ดทีมแบบสั้น ใบส่งงานใต้คำตอบ และการแก้ของหน้าจอ จึงมากับ [Aetox 1.10.6](v1.10.6.md) ไม่ใช่ APK นี้

## ต้องใช้

Aetox บน Windows **1.9.28 ขึ้นไป** (1.10.6 สำหรับของใหม่ข้างบน) · Android 10 ขึ้นไป · Tailscale HTTPS
อัปเดตจาก 0.3.2 ได้จากในแอป: ตั้งค่า › เวอร์ชันแอป › อัปเดต เซ็นด้วยคีย์เดิม การจับคู่และข้อมูลอยู่ครบ
