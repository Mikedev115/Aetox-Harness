# Aetox Mobile Android 0.3.5

**รุ่นเลขใหม่ ไม่มีการเปลี่ยนในตัวแอป Android**

ต่อจาก [0.3.4](mobile-0.3.4.md)

## มีอะไรใหม่

- **ไม่มีของใหม่ในตัวแอป** โค้ด Android (`mobile/android`) เหมือน 0.3.4 ทุกบรรทัด รุ่นนี้เปลี่ยนแค่เลขรุ่น (code 8)
  ผู้ที่ใช้ 0.3.4 อยู่ไม่จำเป็นต้องอัป แต่ไม่มีอะไรเสียหายถ้าอัป
- **การแก้ที่คนเห็นบนมือถือมาจาก Windows** หน้าจอแชตทั้งหมดมาจาก Aetox บน Windows (APK ไม่มีหน้าจอฝังอยู่)
  ของใหม่ของรุ่นนี้จึงมากับ [Aetox 1.10.39](v1.10.39.md) ไม่ใช่ APK นี้

## ต้องใช้

Aetox บน Windows **1.9.28 ขึ้นไป** (1.10.39 สำหรับของใหม่ที่เขียนไว้ข้างบน) · Android 10 ขึ้นไป · Tailscale HTTPS
อัปเดตจาก 0.3.4 ได้จากในแอป: ตั้งค่า › เวอร์ชันแอป › อัปเดต เซ็นด้วยคีย์เดิม การจับคู่และข้อมูลอยู่ครบ
