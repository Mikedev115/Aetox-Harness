# 🧩 Aetox v1.9.23

วันที่ 13 ตุลาคม 2026

**ผู้ช่วยจัดเอเจนและทีมให้ได้เองจากแชท เอเจนเสนอแชทใหม่เป็นการ์ดที่กดแล้วเปิดคู่ข้าง ๆ และเอเจนวิดีโอทำคลิปขายของได้ด้วยสกิลใหม่ promo-film**

## ผู้ช่วยจัดทีมให้

- เดิมถ้าจะมีเอเจนหรือทีม ต้องเข้าตั้งค่าแล้วกดสร้างเองทีละหน้า ผู้ใช้เทียบว่าเครื่องมืออื่นสั่งให้ตั้งค่าตัวเองได้ แต่ Aetox ให้คนทำตามไกด์ ใน tool_runs ไม่มีเอเจนตัวไหนเลยที่ถูกสร้างจากแชท เพราะทางเดียวที่มีคือเขียนไฟล์ ซึ่งถูกปฏิเสธเมื่อโฟกัสโปรเจกต์อยู่
- รุ่นนี้บอกผู้ช่วยในแชทได้เลย หรือกด "ให้ผู้ช่วยจัดให้" บนหน้าทีม แผนก บริษัท ผู้ช่วยดูก่อนว่ามีใครอยู่แล้ว แล้วร่างผังเป็นการ์ดใต้คำตอบ บอกว่าใครทำอะไร ใครไม่ทำอะไร ที่นั่งไหนใหม่ ที่นั่งไหนมีอยู่แล้ว
- ไม่มีอะไรถูกสร้างจนกว่าคุณจะกด สร้าง และเป็นแอปที่สร้าง ไม่ใช่โมเดล ถ้าเปลี่ยนใจ กด ยกเลิกทั้งชุด บนการ์ดเดียวกันได้ ส่วนที่ถูกแก้หรือเริ่มทำงานไปแล้วจะไม่ถูกลบ
- ผังต้องผ่านตรวจ 6 ข้อก่อนการ์ดจะขึ้น: ใช้คนที่มีก่อน · หนึ่งคนหนึ่งงานถนัด · ขั้นเล็กสุดที่พอ · ทุกที่นั่งมีงานจริง · ข้อมูลอยู่ที่เดียว · ให้สิทธิ์เท่าที่ใช้ จ้างใหม่ได้ไม่เกิน 6 ตัวต่อผัง และข้อมูลร่วมของทีมยาวได้ไม่เกิน 600 ตัวอักษร (live run แรกได้ก้อนยาว 1,100 ตัวที่อ่านไม่ไหว)
- ผู้ช่วยเสนอจัดทีมเองได้เมื่อเห็นงานแบบเดิมวนกลับมา ถามครั้งเดียวต่อแชท และกด "ไม่ต้องเสนออีก" ได้
- หน้าทีม แผนก บริษัท ใช้ 6 ข้อเดียวกันตรวจทุกหน่วย แยกจากรายการ "ต่อสายผิด" ที่ต้องแก้ก่อนถึงจะส่งงานได้ หน่วยที่การ์ดสร้างมีป้าย "จัดจากแชท" กดกลับไปที่การ์ดได้ และที่นั่งในทีมมีช่อง งาน กับ ไม่ทำ แล้ว
- ศูนย์บัญชาการบนเว็บมีแถว "ให้ผู้ช่วยจัดทีม" ด้วย (ต้องเปิดสวิตช์ให้เว็บส่งงาน) การ์ดอ่านได้บนเว็บ แต่ปุ่ม สร้าง ยังกดในแอป

## แชทใหม่ที่เอเจนเสนอ

- เดิมงานข้างเคียงที่เอเจนเจอ (บั๊กข้างงาน โปรเจกต์ใหม่) ไม่มีทางเสนอเลย ชิปแบบเก่าถูกปิดไปตั้งแต่ปลาย ส.ค. และตอนที่ยังเปิดอยู่ มันเปิดแชทใหม่ที่โต๊ะของประตู ไม่ใช่ที่ที่งานนั้นควรอยู่
- รุ่นนี้เอเจนขึ้นการ์ดในแชท บอกว่าแชทใหม่มีไว้ทำอะไร จะเปิดที่โต๊ะผู้ช่วยหรือโต๊ะโค้ด ที่โปรเจกต์ไหน (โปรเจกต์นี้ โปรเจกต์อื่น โปรเจกต์ใหม่ หรือโฟลเดอร์ในเครื่อง) เปลี่ยนบนการ์ดได้ก่อนกด
- กด เริ่ม แล้วแชทใหม่เปิดคู่ข้างแชทเดิม การ์ดยุบเหลือบรรทัดเดียวว่าเปิดที่ไหนแล้ว ถ้ามี turn ยังรันอยู่จนเปิดไม่ได้ ข้อความจะไม่หลุดเข้าแชทบนจอ
- เอเจนทำงานของตัวเองต่อ ไม่ลงมือทำงานที่เสนอเอง

## ห้องบริษัทอ่านง่ายขึ้น

- เดิมแผนกที่ยังไม่มีบริษัทไหนถือ ถูกวาดเป็นบริษัทชื่อ Aetox ซึ่งคนอ่านเป็นบริษัทที่สอง และแมพวิทยาเขตกับตึกอยู่ข้างปุ่มเลือกที่ จนคนงงว่าแผนที่สองแบบต่างกันตรงไหน
- รุ่นนี้กลุ่มนั้นเขียนว่า "ยังไม่อยู่ในบริษัทไหน" และแมพเป็นสวิตช์ "เลือกแมพที่อยากแสดง" มุมขวาบน มีแผ่ราบ กับ ซ้อนชั้น ของบริษัทเดียวกัน
- คำว่า เลขา บนหน้าทีม แผนก บริษัท และโทรศัพท์ในออฟฟิศเปลี่ยนเป็น ผู้ช่วย

## คลิปโปรโมทจากเอเจนวิดีโอ

- เดิมงานคลิปขายของเข้า pipeline ของช่อง ซึ่งสั่งให้ใช้หน้าขาว คลิปเปิดตัว 1.9.21–1.9.22 ยาว 43 วิ เสียงและซับครบ แต่ 12 ฉากใช้ layout เดียวกัน มีภาพแอปจริงแค่ภาพเดียว และมีคำภายในขึ้นจอ
- รุ่นนี้เอเจนวิดีโอมีสกิล `promo-film` เล่าเป็น 5 ช่วง (hook ≤ 2 วิที่เห็นของจริง → ก่อน → เปิดตัว → พิสูจน์ → ปิด) ใช้ภาพที่ถ่ายใหม่และ look ของตัวสินค้าเอง
- bar ที่เป็นตัวเลข: สินค้าอยู่บนจอ ≥ ครึ่งคลิป headline 96 px ขึ้นไปบนจอแนวตั้ง ฉากติดกันห้ามใช้ layout ซ้ำ ภาพเปลี่ยนทุก 2 วิ ไม่มีคำภายในบนจอ และต้องดู contact sheet ก่อนส่ง
- หน้าขาวยังเป็น look ของช่อง (`voiceover-clip`) เหมือนเดิม
- วัดที่ chair ของเอเจนวิดีโอ (PF1 สองโมเดล อย่างละ 2 รอบ) คะแนนกฎ ไม่มี/มีสกิล: .63/.67 และ .57/.67 ดูด้วยตา โมเดลหนึ่งเล่าเรื่องครบทั้ง 2 คลิปเมื่อมีสกิล อีกโมเดลไม่ดีขึ้น

## เบราว์เซอร์ในแอป

- เดิมเมื่อเอเจนเปิดหน้าในแท็บที่มีอยู่แล้ว แผงสั่ง navigate ไป URL เดิมซ้ำ ครั้งที่สองยกเลิกครั้งแรก เอเจนได้คำว่า "page failed to load" ภายใน 5–30 ms ทั้งที่หน้าขึ้นปกติ
- 13 ต.ค. เอเจนวิดีโอโดนแบบนี้ 3 ครั้งกับหน้า review ของคลิปตัวเอง จึงส่งคลิปคืนโดยไม่เคยได้ดู
- รุ่นนี้คำสั่งที่เป็นแค่เสียงสะท้อน (ปลายทางเดิม ขณะหน้ายังโหลดหรือโหลดเสร็จแล้ว) ถูกข้าม และ path ไทยแบบดิบกับแบบ percent-encoded นับเป็นหน้าเดียวกัน ถ้าลิงก์พาไปที่อื่นแล้ว พิมพ์ที่อยู่เดิมยัง navigate ได้ตามปกติ

## เวลารวมของเครื่องมือ

- เดิมแถวสรุปเครื่องมือบวกวินาทีแบบ float ตรง ๆ จึงขึ้นเป็น "5.199999999999999s" ทั้งในแชท สรุปแต่ละช่วง และเธรดงานของผู้ช่วย
- รุ่นนี้ปัดเป็นทศนิยมหนึ่งตำแหน่ง ".0" ท้ายหายไป และผลรวมที่ปัดเป็นศูนย์ก็ไม่โชว์ "· 0s"

## ไม่ได้ทำ

- ให้สกิลบังคับให้เอเจนเปิดดูภาพของคลิปตัวเองหลังเรนเดอร์ ทุก run ในการวัดยังไม่ดูเลย (0/8) แม้สกิลจะบอกไว้
- ให้ลูกมือ chair หรืองานเบื้องหลังจัดทีมได้ และให้เว็บกด สร้าง แทนแอป เพราะการอนุมัติเป็นของแอป
- ทำ tool แยกสำหรับเสนอแชทใหม่ มันเป็น action ที่สามของ tool `chat` ที่มีอยู่แล้ว และเปิดได้แค่โต๊ะผู้ช่วยกับโต๊ะโค้ด

## อื่น ๆ ในรุ่นนี้

- 9Router ที่ต้นทางตอบ 404 (ไม่มีโมเดลนั้น) เดิมถูกนับเป็น rate limit แล้วบอกให้รอ 2 นาที ซึ่งครบเวลาก็พังซ้ำ ตอนนี้บอกเป็นภาษาไทยว่าต้นทางไม่มีโมเดลนี้ ให้เลือกโมเดลอื่น
- เมื่อผู้ให้บริการบล็อกเนื้อหาด้วยนโยบายของตัวเอง เดิม turn จบด้วยประโยคภาษาอังกฤษดิบ ๆ ตอนนี้บอกเป็นภาษาไทยว่าเป็นนโยบายของผู้ให้บริการ และให้ลองสลับโมเดลหรือผู้ให้บริการ (ไม่ retry)
- สกิล `promo-film` รุ่นสอง เล็งกล้องจากเฟรมต้นทางจริง ตัวเลขเห็นเป็นภาพ บรรทัดไทยสูงอย่างน้อย 1.3 และตรวจ 4 จังหวะต่อฉาก วัด PF1 คะแนนกฎ .50 → .62 และ .47 → .50 แต่ยังไม่มี run ไหนเปิดดูภาพตัวเองเลย (0/8)
- สกิล `aetox-shadcn` และ `aetox-radix-ui-to-base-ui` ไม่ได้แถมมากับแอปแล้ว งานเฉพาะทางแบบนี้ให้ผู้ใช้ติดตั้งเองเมื่อต้องใช้
- ส่วนเทสต์ที่เพิ่มในรุ่นนี้ ฝั่งจัดทีมคือ `org_tool_test.go` · `org_origin_test.go` · `orgCard.test.ts` · `orgUnitChecks.test.ts` และฝั่งการ์ดแชทใหม่คือ `task_chips_test.go`
- bench เปิด turn เป็นแชตตรงกับเอเจนได้ (`chair`) copy ข้อมูลจริงเข้าแต่ละ run (`data_seed`) และตั้งเพดานเวลาต่อ task ได้ พร้อมชุดทดสอบ PF1 ที่ตรวจจาก mp4 จริง
- เทสต์ที่เพิ่มในรุ่นนี้: `desktop/browser_test.go` (navigate ซ้ำ) · `toolTimeLabel.test.ts` (runSecs) · `installed_skills_test.go` (สกิลที่มากับแอปมาก่อนสกิลของผู้ใช้)
