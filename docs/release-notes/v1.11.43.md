# 🧭 Aetox v1.11.43

วันที่ 27 พฤศจิกายน 2026

แถบข้างรอบสาม: หัวคอลัมน์มีปุ่ม ต้องดู กับ ค้นหา, แถวห้องความสามารถกางค้างไว้ตลอด, ลากคอลัมน์แคบเกิน 160px แล้วพับเป็นรางเอง, และชื่อที่ยาวเกินแถวเลื่อนให้อ่านเหมือนป้ายโฆษณาเมื่อชี้ · ไกด์เปิดมาถามก่อนแล้ว ไม่พาทัวร์เองอีก · หน้าเว็บที่เปิดในแท็บเบราว์เซอร์ใช้ `prefers-color-scheme` ตามธีมที่เลือกในแอป ไม่ใช่โหมดของ Windows

## แถบข้างรอบ 3 (แบบ A)

- **เดิม** ชื่อแชทจางพอกับบรรทัดวัน · ค้นหาเป็นแถวเต็มใต้ "แชทใหม่" · เมนูโปรไฟล์กางโควตาสามบรรทัดทุกครั้งที่เปิด · ไอคอนบนสุดของรางคือ ⚡ ความสามารถ ไม่มีอะไรพากลับไปหน้าแชท · แถวห้องความสามารถพับปิดได้ด้วยการกดหนึ่งครั้งและจำไว้ ทำให้กางรายการหายไปทุกครั้งหลังเปิดแอป
- **ตอนนี้** (`9efa0139d`)
  - หัวคอลัมน์มีกระดิ่ง **ต้องดู** ข้างชื่อเดสก์: กดแล้วรายการแชทถูกแทนด้วยแชทที่ต้องการคุณ — รอคำตอบหรือยังไม่อ่าน — กรองได้สามแบบ จุดบนกระดิ่งบอกว่ามีของค้าง และกดเลือกแชทแล้วรายการเดิมกลับมา · **ค้นหา** เป็นปุ่มแว่นขยายที่หัวเดียวกัน ช่องค้นหาขึ้นที่เดิมใต้หัวแถบและหุบเมื่อปล่อยว่างหรือกด Esc
  - ราง: แชทกลับมาเป็นไอคอนบนสุด จุดเล็กบนไอคอนบอกว่ามีแชทที่ต้องดู · หน้าของห้องความสามารถกางค้างใต้แถวห้องเสมอ กดแถวห้องแล้วเข้าห้อง ไม่พับ และไม่จำการพับเก่าอีก
  - ลากขอบคอลัมน์แคบกว่า 160px แล้วพับเป็นรางทันที (สถานะเดียวกับปุ่ม ≡) · การลากวัดจากหลังรางแอป ไม่ใช่จากขอบหน้าต่าง ขอบจึงตามมือตลอดทาง
  - รางเข้มกว่าคอลัมน์เล็กน้อยพร้อมเส้นคั่นบาง ๆ · เมนูโปรไฟล์อยู่เหนือฉากมืดของคอลัมน์และเหนือห้องความสามารถแล้ว · เมนูเล็กลงหนึ่งขั้น แบ่งกลุ่มบนพื้นของตัวเอง โลโก้ผู้ให้บริการมาแทนชื่อที่ถูกตัด และโควตาหุบไว้จนกด
  - ตัวเลือกโปรเจกต์แบบเต็มแบ่งสองกลุ่ม **ปักหมุด** กับ **ล่าสุด** · ชื่อโปรเจกต์ได้เต็มแถว และบรรทัด "N แชท · เมื่อกี้" อยู่ใต้ชื่อ ไม่ใช่เบียดข้าง
  - ชื่อที่ยาวเกินแถวเลื่อนไปมาเมื่อชี้ (`marquee.ts`) หยุดที่ปลายทั้งสองข้างและกลับ — คนที่ขอการเคลื่อนไหวน้อยได้จุดไข่ปลาและ tooltip เหมือนเดิม
  - แถวที่อ่านง่ายขึ้นโดยไม่เพิ่มสี: ชื่อแชทใช้สีตัวอักษรเต็ม อายุของแชทโผล่เมื่อชี้ ปุ่มของหัวข้อโผล่เมื่อชี้ และแถวที่เป็นทางไป (เพิ่มเติม, ประวัติโปรเจกต์, ห้องสมุด) อ่านเป็นปุ่มตั้งแต่ยังไม่ชี้
  - ปุ่มส่งกับปุ่มแนบไฟล์เล็กลงเป็น 32px เท่ากันทั้งคู่ ที่นั่งของนิ้วจึงไม่ขยับตอนปุ่มสลับหน้าที่

## แชทว่างกลับมามีตัวเลือกเริ่มต้นทุกครั้ง

- **เดิม** พรอมป์เริ่มต้นขึ้นเฉพาะการเปิดแอปครั้งแรก หลังมีแชทแล้วแชทว่างใหม่เอาแต่หน้าว่าง บรรทัดช่วยเหลือใต้ตัวเลือกยังอยู่ทุกครั้ง
- **ตอนนี้** (`9efa0139d`) ตัวเลือกเริ่มต้นกลับมาทุกแชทว่าง · บรรทัดช่วยเหลือยังเป็นการเปิดครั้งแรกเท่านั้น · การ์ดคำถาม แถวสถิติ และคิวงานที่ค้างอยู่กว้างเท่ากล่องพิมพ์แล้ว (`--chat-col` ลบ 72px) แทนที่จะยื่นออกสองข้าง

## ไกด์: เปิดมาถามก่อน ไม่พาทัวร์เอง

- **เดิม** กดไกด์แล้วพาทัวร์ห้าอันในคอลัมน์ความสามารถทันที ก่อนรู้ว่าคนอยากได้อะไร
- **ตอนนี้** (`9efa0139d`) เปิดมาทักสั้น ๆ พร้อมปุ่ม Shift-คลิก และเด็คที่ขึ้นต้นด้วย "อธิบายหน้านี้" — ทัวร์ห้องความสามารถยังเปิดได้ แต่เป็นหนึ่งในการเดินที่เลือกเอง (owner, 27 พ.ย. 2026: "กดครั้งแรกมันควรจะถามก่อน … ตามโฟรเดิม") · เปลี่ยนหน้าจอระหว่างที่ยังไม่เลือกอะไร แค่จำห้องไว้ ไม่เริ่มบรรยายยาวเอง
- คำอธิบายไกด์ใหม่สำหรับ ต้องดู, ปุ่มค้นหา, ช่อง "เปิดเมื่อ" ของชุดคำสั่ง และหน้านำเข้า MCP · ลบคำเก่าที่ไม่มีจุดบนจอแล้ว (แผนก, ขั้นของไดอะล็อกทีม, หน้าผลงาน, ช่อง API key ในหน้าตั้งค่า) ออกจากสามภาษา

## หน้าเว็บในแท็บเบราว์เซอร์ใช้ธีมของแอป

- **เดิม** หน้าถาม `prefers-color-scheme` แล้วเอนจินตอบจากโหมดแอปของ Windows ไม่ใช่ธีมที่เลือกใน Aetox — ต้นไม้ไฟล์ของ DirectAdmin จึงขึ้นชื่อโฟลเดอร์สีเข้มบนพื้นเข้มในแผงข้างแอปโหมดมืด
- **ตอนนี้** (`1708c1d42`, `a12bf58e5`) ธีมบอกโทนให้ฝั่ง Go ผ่าน `BrowserSetColorScheme` และทุกแท็บ—ที่เปิดอยู่และที่จะเปิด—ได้โทนนั้นผ่าน `ICoreWebView2Profile.PreferredColorScheme` · แท็บใหม่ได้โทนก่อนนำทางครั้งแรก เพนต์แรกจึงถูกตั้งแต่ต้น · runtime ที่เก่ากว่า 1.0.1661 ไม่มีอินเทอร์เฟซนี้ แท็บจึงคงพฤติกรรมเดิมของเอนจินและไม่มีอะไรพัง
