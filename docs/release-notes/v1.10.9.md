# 🧩 Aetox v1.10.9

วันที่ 21 ตุลาคม 2026

**คำตอบยาวไม่ถูกพับหายเข้าขั้นตอนอีก · ส่งข้อความตอนเปิดแชทใหม่ไม่ค้าง · Claude ผ่าน 9Router ใช้ token ลดเกือบครึ่ง**

## คำตอบอยู่บนจอเต็ม ไม่ถูกพับเข้าขั้นตอน

- **เดิม** (v1.10.8) คำตอบที่มาเป็นสองก้อนติดกัน เช่นสรุปยาว 2,597 ตัวอักษรตามด้วยย่อหน้าปิดท้าย สรุปทั้งก้อนกลายเป็นบรรทัดหนึ่งใต้หัว "ทำงานไป N ขั้น" แล้วพับหายตอนจบ บนจอเหลือแค่ย่อหน้าสุดท้าย
- **รุ่นนี้** ทุกอย่างหลังเครื่องมือหรืองานมอบหมายชิ้นสุดท้ายนับเป็นคำตอบ อยู่เต็มบนจอเสมอ ระหว่าง live ก็ถามแบบเดียวกัน
- **เดิม** ระหว่าง live เครื่องมือของรอบไปเกาะประโยคก่อนหน้า บรรทัดขั้นบอกเวลากับจำนวนเครื่องมือเพี้ยนไปหนึ่งขั้น (เปิด session ใหม่แล้วถูก)
- **รุ่นนี้** ประโยคและความคิดของรอบถูกวางหน้าแถวเครื่องมือของรอบนั้นตั้งแต่ตอน live

## ส่งข้อความตอนแชทใหม่ยังเปิดไม่เสร็จ

- **เดิม** กดแชทใหม่แล้วพิมพ์ส่งทันที ข้อความไปตกในแชทเก่า งานยังวิ่งครบแต่จอว่างค้างหน้าแรกจนต้องกด Stop
- **รุ่นนี้** bubble ขึ้นทันทีตอนกดส่ง ติดไปที่แชทใหม่ และส่งออกทันทีที่แชทใหม่มาถึง ไม่รออ่านข้อมูลโมเดล

## Claude ผ่าน 9Router: cache กลับมา token ลดเกือบครึ่ง

- **เดิม** โมเดล `cc/` วิ่งทาง chat/completions ซึ่ง 9Router ส่ง system prompt ซ้ำและไม่ส่งตัวเลข cache กลับมา
- **รุ่นนี้** วิ่งทาง Anthropic Messages วัดจริง 8 รอบ 527K → 293K token, cache 33% → 57–74% ตัวเลขในหน้าสถิติตรงกับ log ของ 9Router
- การ์ด cache คิด hit rate เฉพาะ call ที่รายงาน cache มา ส่วนที่ไม่มีตัวเลขแสดงเป็น "ไม่ทราบ" ไม่นับเป็น miss

## หน้าสถิติบอกว่าโมเดลมาจากไหน

ทุกชื่อโมเดลมีโลโก้ผู้ให้บริการ สีกราฟเป็นสีเดียวกับโลโก้ และกดชื่อใน legend เพื่อดูเฉพาะรุ่นนั้นได้

## โต๊ะโค้ด

- map ของโปรเจคอ่านไฟล์ที่ clean จาก git ทีเดียว ไม่ถูกตัดกลางทาง (terraform 1,628 ไฟล์ cold 9–15 วินาที → 0.9 วินาที) และ map เป็นของใช้เมื่ออยากรู้โครงสร้าง ไม่ใช่ขั้นแรกบังคับ
- reproduce bug ด้วยเคสในรายงานเอง ไม่ใช่เคสที่ agent คิดขึ้น และการปิด check ทั้งกลุ่มไม่นับว่าแก้แบบ minimal
- Claude Code เริ่มที่โหมด Auto ในแชตที่ยังไม่เคยเลือกโหมด แชตที่เลือก Default เองยังเป็น Default
