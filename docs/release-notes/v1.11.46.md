## ตัวหลักเปิดบรรทัดหลักฐานเอง และ prompt เลิกบอกว่า shell อ่านดีกว่า read

- **เดิม** 28 พ.ย. 2026 เจ้าของถามว่า Aetox มี remote access ไหม ตัวหลักส่งงานทำบัญชีความสามารถให้ helper แล้วบอกเจ้าของว่า "ยังไม่มี remote" ทั้งที่ตัวเชื่อมเครื่องระยะไกล (`desktop/mission_lan.go`) ทำงานอยู่จริง — คำใน prompt สามจุดทำให้เกิดเรื่องนี้
- **ตอนนี้** (`9de234280`)
  - `coding.md` สั่งให้ "ส่งการค้นให้ helper … ไม่ต้องอ่านไฟล์เดิมซ้ำเอง" ตัวหลักจึงเชื่อคำตัดสินของ helper โดยไม่เปิดหลักฐาน เปลี่ยนเป็นให้ helper หาที่ แล้วตัวหลักเปิดบรรทัดที่ใช้ตอบเอง
  - `prompt.go` มีประโยค "the shell reads more precisely than read does" อยู่ในทุก prompt ที่มี shell เคสนี้ helper ใช้ shell 83 ครั้งแต่ไม่ใช้ search เลย peek ไฟล์ด้วย `-TotalCount 14` และตัดผลค้นด้วย `-First 12` จนไม่เจอไฟล์ที่ต้องใช้ — ลบประโยคนี้ ส่วนท่าอ่านเฉพาะช่วงด้วย shell ยังอยู่ใน guidance ของ shell ที่มีเงื่อนไข "a range you are already sure of" กำกับ
  - ชื่อ tool ใน prompt ไม่ตรงกับของจริง (`grep`/`glob`/`list` ไม่ใช่ชื่อ tool บนเดสก์) แก้เป็น `search action=grep` และ "read and search"
- วัดบน deepseek-v4.1-flash เทียบ before/after อย่างละ 3 รอบ สั่งให้ส่ง helper ทำบัญชี 12 ข้อ (มีจริง 6 ไม่มี 6): ตอบถูก 36/36 เทียบ 35/36 · before มีหลักฐานผิด 1 จุด (อ้าง `remote.go` ที่ PARKED) after ไม่มี · ตัวหลักเปิดไฟล์เองหลังได้ผลจาก helper 6/3/2 ครั้ง เทียบ 28/4/8 ครั้ง · tokens เฉลี่ย 3.2M เทียบ 5.1M · ส่วนการเลิกใช้ shell หาไฟล์ยังไม่เห็นผล
