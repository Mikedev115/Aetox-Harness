# Aetox Mobile Android 0.3.0

**คำตอบไหลลื่นเหมือนบน Windows เห็นทุกแชทและโปรเจกต์ และเปิดดูไฟล์ที่ AI ทำได้ในแอป**

Windows ยังเป็นผู้ทำงานและเก็บข้อมูลเหมือนเดิม มือถือเป็นหน้าจอที่ต่อเข้า Aetox บนเครื่องของคุณ

## มีอะไรใหม่

- **คำตอบไหลลื่น** ระหว่างที่ AI ทำงานจะเห็นประโยคที่ AI พูดไว้ก่อนเรียกเครื่องมือ ขั้นตอนเครื่องมือแต่ละขั้น และคำตอบที่กำลังเขียน ข้อความค่อยๆ ไหลออกมา ไม่กระตุกเป็นก้อน และประโยคไม่หายกลางทางอีกแล้ว
- **เห็นทุกแชท** มือถือที่จับคู่ใหม่จะเห็นทุกแชทหลักบน Windows รวมถึงแชทที่เปิดทีหลังด้วย ส่วนเครื่องที่จับคู่ไว้แล้ว เปิด "ทุกแชท" ได้ที่หน้า "มือถือ" บน Windows โดยไม่ต้องจับคู่ใหม่
- **แชทแยกตามโปรเจกต์** ลิ้นชักซ้ายสลับได้ระหว่าง "ล่าสุด" กับ "โปรเจกต์"
- **ดูไฟล์ที่ AI ทำ** ไฟล์ที่ AI ส่งให้ขึ้นเป็นการ์ดใต้คำตอบทันที แตะเปิดเต็มจอแล้วปัดดูไฟล์อื่นของแชทนั้นได้ เปิดได้ทั้งเอกสาร Markdown ข้อความ โค้ด รูป วิดีโอ เสียง หน้าเว็บ และสไลด์ (สลับดูแบบตัวอย่างหรือซอร์สได้) ปุ่มท้ายหน้ามี แชร์ บันทึกลงเครื่อง และถามเรื่องไฟล์นี้
- **ส่งรูปอย่างเดียวได้** ไม่ต้องพิมพ์อะไรประกอบ ฟองข้อความแสดงชื่อไฟล์ที่แนบไป
- **รายชื่อโมเดลตรงกับที่ติดดาวไว้** ผู้ให้บริการที่ติดดาวขึ้นก่อน ที่เหลือพับไว้ โมเดลที่ปิดไว้บน Windows ไม่แสดง ระดับการคิดไม่ล้นจออีก
- **หน้าตั้งค่ากระชับ** ธีมเป็นแถวเดียว แตะแล้วเลือกจากแผ่นที่แบ่งเป็นมืดกับสว่าง ภาษาเป็นปุ่ม ไทย | English และเลือกเสียงที่ตอบจากรายการ
- **สีของแอปตามธีม** แถบสถานะด้านบนและแถบปุ่มด้านล่างเปลี่ยนสีตามธีมที่เลือก หน้าเชื่อมต่อใช้สีของ Aetox แทนสีเขียวเดิม และโลโก้ใช้สีตัวอักษรของธีม
- **เปิดปิดลื่นขึ้น** ลิ้นชัก หน้าต่างๆ และแผ่นด้านล่างเลื่อนออกตอนปิดด้วย แตะแถวแล้วไม่มีเส้นกรอบค้าง

## สิทธิ์ที่แอปขอ

เหมือน 0.2.0: ไมโครโฟนและกล้อง ขอเฉพาะตอนที่คุณกดใช้ และใช้ได้เฉพาะหน้าของ Aetox Link บน Windows ของคุณ
ไฟล์ที่กดแชร์จะเขียนไว้ชั่วคราวในพื้นที่ของแอปเพียงไฟล์เดียว เพื่อส่งให้แอปที่คุณเลือก

## ก่อนติดตั้ง

- เป็น APK ที่เซ็นด้วยคีย์ทดสอบ ไม่ได้มาจาก Play Store
- ต้องใช้ Android 10 ขึ้นไป และ Tailscale บนมือถือกับ Windows
- ฝั่ง Windows ต้องเป็น Aetox **รุ่นที่มีงานนี้** (stream ใหม่ สิทธิ์ทุกแชท และการ์ดไฟล์อยู่ฝั่ง Windows)
- ต้องเปิด Windows และ Aetox ไว้

## อัปเดตอย่างไร

ติดตั้ง 0.3.0 ทับ 0.2.0 ได้เลย ไม่ต้องจับคู่ใหม่
APK 0.3.0 จำเป็นสำหรับปุ่มแชร์ไฟล์และสีแถบระบบตามธีม ส่วนอื่นมาจาก Aetox บน Windows

## สถานะการทดสอบ

ผ่าน Go tests ของ gateway, engine และ desktop, หน้าจอ 87 tests, svelte-check
หน้าจอทุกหน้าตรวจด้วยข้อมูลตัวอย่างในเบราว์เซอร์แล้ว ความลื่นของคำตอบวัดด้วยการจำลองเน็ตกระตุก
APK ผ่าน unit tests, lint และตรวจลายเซ็น (เซ็นด้วยคีย์ทดสอบเดียวกับ 0.2.0 จึงติดตั้งทับได้)
**ยังไม่ได้ลองบนมือถือจริง** (แชร์ไฟล์ สีแถบระบบ และหน้าเว็บ/สไลด์ในแอป)
