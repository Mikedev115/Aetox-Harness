# Aetox Mobile Android 0.3.8

**รุ่นนี้ไม่ได้เปลี่ยนโค้ด Android** — ไม่มีไฟล์ใน `mobile/android` เปลี่ยนตั้งแต่ [0.3.7](mobile-0.3.7.md)
ที่เปลี่ยนคือเลขรุ่น (code 10 → 11) และหน้าจอมือถือที่แอปโหลดมาแสดง ซึ่งมาจาก **Aetox บน Windows 1.11.15**
ออก APK ใหม่รอบนี้เพราะของที่แก้ไปสองรายการในรุ่น Windows 1.11.15 เป็นเรื่องของมือถือทั้งคู่ และยังไม่มี APK ที่ประกบคู่อย่างเป็นทางการ

ต่อจาก [0.3.7](mobile-0.3.7.md)

## มีอะไรใหม่ (มาจาก Aetox บน Windows 1.11.15)

- **แชทเก่าเปิดได้อีกครั้ง** ก่อนหน้านี้เปิดแชทที่มีการ์ดทีมแล้วหน้าสนทนาว่าง พร้อมข้อความ
  "Unexpected server response. Update or reconnect." ทั้งที่ข้อความยังอยู่ครบในฐานข้อมูล
  ตัวอ่านฝั่งมือถือยังบังคับฟิลด์หัวหน้าและชั้นของทีมที่เลิกใช้ตั้งแต่ 5 พ.ย. 2026 (ถอดชั้นบริษัท–แผนก–หัวหน้า)
  ตอนนี้บังคับแค่ชนิด ชื่อ และรายชื่อสมาชิก · รับฟิลด์เก่าได้ถ้า PC รุ่นก่อนยังส่งมา
  · การ์ดที่อ่านไม่ได้กลายเป็น "การ์ดใบนั้นอ่านไม่ได้" ข้อความอื่นและคำตอบในแชทยังเปิดได้
  แทนที่จะซ่อนทั้งแชท
- **หน้าตั้งค่ามือถือบน PC เป็นสี่การ์ด** เรียงตามลำดับคำถาม: สถานะลิงก์ · ก่อนเปิด/จับคู่/รหัสขอยืนยัน ·
  มือถือทำอะไรได้ · เครื่องที่เชื่อมแล้ว · การ์ดสิทธิ์ใบเดียวใช้ได้ทั้งคำขอที่รออนุมัติและเครื่องที่จับคู่แล้ว
  และแก้สิทธิ์ของเครื่องที่จับคู่ไปแล้วได้ · QR ติดตั้ง Android ย้ายมาเป็นแถวของตัวเองท้ายการ์ด
- **ตัวติดตั้ง 0.3.8** เซ็นด้วยคีย์เดิม `c6330d76…` (versionCode 11) ติดตั้งทับ 0.3.7 ได้ ข้อมูลและเครื่องที่จับคู่ไว้อยู่ครบ
  หน้าจอที่เห็นในแอปยังมาจาก Aetox บน Windows เหมือนเดิม — APK ไม่ได้เก็บหน้าจอไว้ในตัว

## ต้องใช้

Aetox บน Windows **1.11.15 ขึ้นไป** (ทั้งสองข้อข้างบนมาจากฝั่ง Windows รุ่นนี้; PC รุ่นก่อนยังใช้ได้แต่จะเห็นพฤติกรรมเดิม)
