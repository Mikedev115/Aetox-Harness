# 🪟 Aetox v1.10.30

วันที่ 30 ตุลาคม 2026

**วางวิดีโอและไฟล์ลงในแชทได้ · รายการโมเดลอ่านด้วยชื่อโมเดล · ย้ายช่องไปอีกโปรเจคแล้วรายการโปรเจคตามไปด้วย · ปุ่ม «ปิดทั้งหมด» ของแถบแท็บอยู่ขวาสุด**

## แชท: วางคลิปและไฟล์จากคลิปบอร์ดได้ ไม่ใช่แค่ภาพ

- **สาเหตุ** `Ctrl+V` ในช่องแชทรับแต่ภาพ ไฟล์อื่นถูกทิ้งไปเงียบ ๆ หน้าต่างได้ไบต์ของไฟล์ ไม่ได้ที่อยู่ของมัน ไฟล์ที่วางมาจึงมาโดยไม่มี path — คัดลอก `.mp4` จาก Explorer แล้วได้รายการชนิด `video/mp4` พร้อมชื่อไฟล์ แต่ `path` เป็น null
- **วิดีโอ เสียง และ PDF จึงเคยแนบได้ทางลากไฟล์หรือปุ่ม + เท่านั้น** ทั้งที่การวางคือทางที่คนใช้บ่อยที่สุด
- **ตอนนี้ฝั่ง Windows อ่านรายการไฟล์บนคลิปบอร์ดคืน path จริง** แล้วแนบเข้าเส้นเดียวกับลากไฟล์ คือก็อปเข้า sandbox ฝั่งเอนจิน ไม่ต้องลากไบต์ทั้งคลิปผ่านหน้าจอ
- **ภาพแคปเจอร์ที่ไม่มีไฟล์อยู่ข้างหลังยังใช้ทางไบต์เดิม** และการวางที่ไม่พบไฟล์ไม่นับเป็นข้อผิดพลาดให้รบกวน ระหว่างที่โปรแกรมอื่นถือคลิปบอร์ดอยู่จะลองสั้น ๆ ไม่กี่ครั้งแล้วเงียบ

## โมเดล: แถวอ่านด้วยชื่อโมเดล ไม่ใช่ id ที่มีชื่อบริษัทนำหน้า

- **id ยังเป็นสัญญากับผู้ให้บริการ** ส่งกลับตามเดิม และทุก lookup (ราคา หน้าต่าง ปักหมุด แถวการใช้) ยังคีย์ด้วย id — สิ่งที่เปลี่ยนคือคำที่คนอ่านในแถว
- **9Router ใส่เส้นทางเจ้าของนำหน้าชื่อ** (`anthropic/`, `cc/`, `xiaomi/`) และคำของบริษัทติดอยู่ต้นชื่อ (`claude-`, `minimax-`, `mimo-`, `kimi-`, `muse-`) คำเดิมจึงซ้ำทุกแถวของรายการเดียวกัน
- **ตัดเฉพาะเมื่อสิ่งที่เหลือยังบอกได้ว่าเป็นรุ่นไหน** ต้องขึ้นต้นด้วยตัวอักษรและมีเลขรุ่น `haiku-5-5` · `m3.1-flash` · `v2.6-pro` จึงอยู่ครบ ส่วน `gemini-flash` ไม่ถูกตัดเหลือ `flash` เพราะเหลือแล้วไม่บอกอะไรเลย
- **ใช้ที่แถวโมเดล ตัวเลือกรุ่น แผงปรับรุ่น ตารางการใช้ และช่องค้นหา** ซึ่งค้นได้ทั้งชื่อที่เห็นและ id — พิมพ์ "haiku" กับ "claude-haiku-5-5" เจอโมเดลเดียวกัน

## แบ่งจอ: ย้ายช่องไปอีกโปรเจคแล้วรายการโปรเจคตามไปด้วย

- **สาเหตุ** รายการด้านซ้ายบอกว่า «อยู่โปรเจคไหน» จากประวัติโปรเจคที่อ่านตอนเปิดแชท แต่การย้ายระหว่างช่องเป็นการย้ายเคอร์เซอร์อย่างเดียวและไม่อ่านอะไรเลย
- **ถ้าโปรเจคที่กดมีแชทล่าสุดค้างอยู่ในอีกช่องอยู่แล้ว** การกดชื่อโปรเจคจะกลายเป็นการสลับช่อง ตัวแชทเปลี่ยนจริง แต่โปรเจคที่ไฮไลต์และรายการด้านซ้ายยังเป็นของเดิม อ่านเป็น «กดเข้าโปรเจคที่ต้องการแล้วแต่มันพาไปโปรเจคเดิม»
- **ตอนนี้เมื่อโปรเจคเปลี่ยน จะอ่านประวัติโปรเจคใหม่หลังฉาก** ไม่หน่วงการกด ส่วนการย้ายภายในโปรเจคเดิมยังไม่ต้องอ่านเพิ่ม

## แท็บไฟล์: ปุ่ม «ปิดทั้งหมด» อยู่ขวาสุดของแถบ

- **ปุ่มนี้ปิดทั้งแถบ จึงไม่ได้เป็นของแท็บไหน** การวางไว้ข้าง `+` ทำให้ตำแหน่งของ `+` ไม่ได้บอกอีกว่าถัดไปมันจะได้ที่ตรงไหน
- **ย้ายไปชิดขวาสุดของแถบ** ทั้งแถบแท็บของโต๊ะโค้ดและแถบของเวิร์กเบนช์ ใช้คำและตำแหน่งเดียวกัน
- **ความกว้างของปุ่มถูกนับออกจากที่ของแท็บแล้ว** แท็บจึงไม่ล้นออกนอกแถบ

## ความมั่นใจของรุ่น

- เพิ่มชุดทดสอบการวางจากคลิปบอร์ด 7 ข้อ และเทสต์ฝั่ง Windows ที่ยืนยันกับคลิปบอร์ดจริง
- เพิ่มชุดทดสอบชื่อโมเดล 28 เคสจาก id จริงของ 9Router, Bedrock, Copilot และแคตตาล็อก พร้อมเทสต์หน้าจอว่าเลือกแล้วยังส่ง id เดิม
- เพิ่มชุดทดสอบแบ่งจอ 2 ข้อ — ข้ามโปรเจคต้องอ่านรายการใหม่ โปรเจคเดิมต้องไม่อ่าน (ถอดบล็อกที่แก้ออกแล้วเทสต์ล้ม 1 ข้อ)
- ปรับเทสต์หน้าจอของ Settings และตัวเลือกรุ่นให้คาดหวังชื่อที่อ่านได้แทน id
