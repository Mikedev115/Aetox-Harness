# Aetox Mobile Android 0.2.0

**แอปมือถือทำใหม่ทั้งหมด หน้าตาและการใช้งานแบบแอปแชท คุยด้วยเสียงได้ และใช้ธีมชุดเดียวกับ Aetox บน Windows**

Windows ยังเป็นผู้ทำงานและเก็บข้อมูลเหมือนเดิม มือถือเป็นหน้าจอที่ต่อเข้า Aetox บนเครื่องของคุณ

## มีอะไรใหม่

- **เปิดมาเจอแชทเลย** ลิ้นชักซ้ายมีช่องค้นหาแชท รายการที่รอคุณ ไฟล์ และประวัติแยกเป็นวันนี้ เมื่อวาน 7 วันก่อน และเก่ากว่านั้น
- **เลือกโมเดลจากหัวจอ** มีระดับความคิด รายการติดดาวตรงกับบน Windows และเปิดดูโมเดลทั้งหมดของผู้ให้บริการได้
- **ปุ่ม +** ใช้แนบรูปจากกล้อง คลังรูป หรือไฟล์ เลือกวิธีทำงาน (ลงมือ, วางแผนก่อนทำ, คู่คิด) และเลือกโปรเจกต์ให้แชทใหม่
- **พูดแล้วพิมพ์ให้** กดไมค์ในช่องพิมพ์ ข้อความจะขึ้นในช่องให้แก้ก่อนส่ง
- **คุยด้วยเสียง** พูดได้เลย หยุดพูดสักครู่แล้ว Aetox จะตอบเป็นเสียงทีละประโยคระหว่างที่คำตอบยังเขียนอยู่ แตะวงกลมเพื่อพูดแทรก มีคำบรรยาย เลือกเสียงที่ตอบได้ และถ่ายรูปส่งไปพร้อมประโยคถัดไปได้ ทุกประโยคเก็บไว้ในแชท
- **ใต้คำตอบ** มีปุ่มคัดลอก อ่านออกเสียง ถามใหม่ และแชร์ ความคิดและขั้นตอนเครื่องมือย่อเหลือบรรทัดเดียว แตะเพื่อเปิดดู
- **ข้อความของคุณ** กดแก้แล้วส่งใหม่ได้
- **รอคุณ** รวมคำขออนุญาต คำถาม และคำขอจำไว้ในหน้าเดียว คำขอของแชทที่เปิดอยู่จะขึ้นในแชทนั้นด้วย
- **ไฟล์** เปิดดูเต็มจอ บันทึกลงเครื่อง แชร์ หรือกลับไปถามต่อในแชท
- **ธีม** มี 22 ธีมชุดเดียวกับ Windows หรือเลือกให้ตามโหมดมืด/สว่างของมือถือ
- **จับคู่** หน้าแรกบอกขั้นตอนเป็นข้อ แสดงรหัสให้เทียบกับ Windows และสแกน QR ได้ในเบราว์เซอร์ที่รองรับ

## เสียงทำงานอย่างไร

มือถืออัดเสียงแล้วส่งให้ Windows แปลงเป็นข้อความด้วยตัวแปลงเสียงที่ตั้งไว้ใน Aetox
คำตอบอ่านออกเสียงด้วยเสียงอ่านที่ตั้งไว้ใน Aetox เช่นกัน ถ้ายังไม่ได้ตั้งค่าสองอย่างนี้บน Windows จะคุยด้วยเสียงไม่ได้
เสียงที่อัดไม่ถูกเก็บไว้บนมือถือ

## สิทธิ์ที่แอปขอ

แอปขอใช้ **ไมโครโฟน** และ **กล้อง** เฉพาะตอนที่คุณกดใช้ (คุยด้วยเสียง ถ่ายรูป หรือสแกน QR) และให้ใช้ได้เฉพาะหน้าเว็บของ Aetox Link บน Windows ของคุณ
รูปที่ถ่ายเก็บไว้ชั่วคราวในพื้นที่ของแอปจนกว่าจะส่งออกไป

## ก่อนติดตั้ง

- เป็น APK ที่เซ็นด้วยคีย์ทดสอบ ไม่ได้มาจาก Play Store
- ต้องใช้ Android 10 ขึ้นไป และ Tailscale บนมือถือกับ Windows
- ฝั่ง Windows ต้องเป็น Aetox รุ่นที่มี **Aetox Link** และตั้ง HTTPS ที่เชื่อถือได้แล้ว รุ่น stable ปัจจุบันของ Windows ยังไม่มี Link
- ต้องเปิด Windows และ Aetox ไว้ ไม่มีการแจ้งเตือนแบบ push ในแอป Android

## อัปเดตอย่างไร

หน้าจอของแอปส่งมาจาก Aetox บน Windows หน้าจอใหม่ทั้งหมดจึงมาพร้อม Aetox รุ่นที่มีงานนี้บน Windows
ส่วน APK 0.2.0 จำเป็นสำหรับไมโครโฟน กล้อง และการแนบไฟล์ในแอป Android โดย APK 0.1.0-test ปฏิเสธสามอย่างนี้ทุกครั้ง
ติดตั้ง 0.2.0 ทับ 0.1.0-test ได้เลย ไม่ต้องจับคู่ใหม่

บน iPhone ที่ใช้ Web Clip หรือเบราว์เซอร์บน Android จะได้หน้าจอใหม่ทันทีที่ Windows อัปเดต
