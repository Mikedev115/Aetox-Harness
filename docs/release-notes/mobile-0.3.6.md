# Aetox Mobile Android 0.3.6

**รุ่นนี้แก้ตัวแอป Android** โค้ดใน `mobile/android` เปลี่ยน ไม่ใช่แค่เลขรุ่น

ต่อจาก [0.3.5](mobile-0.3.5.md)

## มีอะไรใหม่

- **ท่อที่ถูกตัดกลางทางไม่ถูกกล่าวหาว่าเป็นปัญหาใบรับรองอีก** ก่อนหน้านี้สตรีม TLS ที่ถูกปิดหรือตัด
  (`connection closed`, `closed by peer`, `unexpected end of stream`) ถูกนับเป็นปัญหาใบรับรอง
  หน้าจอจึงขึ้น "ใบรับรองความปลอดภัยของคอมใช้ไม่ได้ · ตรวจวันที่และเวลาบนมือถือให้ถูก" ทั้งที่สาเหตุจริง
  คือ Tailscale บนมือถือยังไม่ขึ้น ตอนนี้แยกออกจากกัน: ขึ้น "คอมไม่ตอบ" หรือ "มือถือยังไม่ได้ต่อ Tailscale"
  พร้อมปุ่มเปิด Tailscale
- **ลองเชื่อมซ้ำให้หนึ่งครั้งก่อนขึ้นหน้าจอผิดพลาด** เมื่อการเชื่อมต่อถูกตัดกลาง handshake
  ไม่ต้องกดเชื่อมต่อเองอีกรอบ
- **หน้าจอที่เห็นในแอปยังมาจาก Aetox บน Windows** การแก้หน้าจอ (คีย์บอร์ดกระตุกตอนพิมพ์) มากับรุ่น Windows
