# 🪟 Aetox v1.10.27

วันที่ 29 ตุลาคม 2026

**สลับระหว่างประตูผู้ช่วยกับโค้ดแล้วกลับมาที่บทสนทนาเดิม ไม่สร้างแชทว่างและไม่โหลดรายการโครงการซ้ำ · แถบเครื่องมือของข้อความที่เลือกจะรอจนปล่อยเมาส์ จึงไม่ลอยมาบังระหว่างลากครอบข้อความ**

## ประตู: กลับสู่บทสนทนาเดิม

- **จำบทสนทนาที่แต่ละประตูเพิ่งออกมา** เมื่อเดินจากผู้ช่วยไปโค้ด แล้วกลับมา จะเปิดบทสนทนาผู้ช่วยเดิมที่กำลังคุยอยู่ แทนการสร้างหน้าแชทใหม่ทุกครั้ง; สลับกลับไปโค้ดก็ย้อนคืนบทสนทนาโค้ดเดิมเช่นกัน
- **ไม่สะสมแชทว่างจากการสลับห้อง** บทสนทนาที่มีข้อความจึงอยู่ตรงหน้าเสมอ ส่วนห้องว่างยังทำงานเหมือนเดิม: สร้างใหม่เมื่อไม่มีบทสนทนาเดิมที่ควรกลับไป
- **ลดการอ่านข้อมูลที่ไม่มีหน้าจอแสดง** การกลับสู่ผู้ช่วยจากแชทโครงการจะไม่สั่งอ่านผังไฟล์และสถานะ Git ทั้งโครงการ ทั้งที่หน้าผู้ช่วยไม่ได้วาดสิ่งเหล่านั้น
- **ล้างความจำชั่วคราวเมื่อเอนจินเปลี่ยน** หลังรีสตาร์ตจะไม่พยายามเปิดบทสนทนาจากเอนจินเก่า และหากบทสนทนาที่จำไว้ถูกลบหรือย้ายไปแล้ว จะกลับไปสร้างห้องใหม่ได้ตามปกติ

## ข้อความ: แถบเลือกไม่บังระหว่างลาก

- **รอให้ปล่อยเมาส์ก่อนจึงแสดงแถบเครื่องมือ** ระหว่างลากครอบข้อความ การเลือกเปลี่ยนทุกพิกเซลแต่แถบจะไม่ตามมาบังจุดที่กำลังลาก
- **อ่านตำแหน่งสุดท้ายเพียงครั้งเดียว** เมื่อปล่อยเมาส์ แถบจึงปรากฏใต้ข้อความที่เลือกจริง ไม่ใช่ตำแหน่งกลางทาง
- **การเลือกด้วยคีย์บอร์ดยังแสดงทันที** เพราะไม่มีการลากที่ต้องรอ และกรณีระบบยกเลิกการลากนอกหน้าต่างก็ยังแสดงแถบได้

## ความมั่นใจของรุ่น

- เพิ่มชุดทดสอบการเดินกลับระหว่างประตู ครอบคลุมบทสนทนาเดิม แชทว่าง บทสนทนาที่ถูกลบ และจำนวนรอบที่หน้าต่างเรียกกลับไปยังเอนจิน
- เพิ่มชุดทดสอบแถบเลือกข้อความ ครอบคลุมการลากทั้งช่วง การเลือกด้วยคีย์บอร์ด การกดบนแถบเอง และการยกเลิกการลากโดยระบบ
