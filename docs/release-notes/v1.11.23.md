## คอมมิตขึ้นชื่อ Aetox พร้อมโลโก้ ไม่ใช่ช่องเปล่า

- **เดิม** ฮุก `scripts/hooks/prepare-commit-msg` เติมท้ายคอมมิตด้วย `Co-Authored-By: Aetox <noreply@aetox.invalid>` — ที่อยู่บนโดเมนที่จองไว้ว่าไม่มีจริง (RFC 2606) GitHub จึงจับคู่กับบัญชีไหนไม่ได้ ผู้เขียนคนที่สองขึ้นเป็นช่องเปล่า ไม่มี avatar และกดเข้าโปรไฟล์ไม่ได้
- **สาเหตุ** ที่อยู่เดิมถูกเลือกแบบนั้นโดยตั้งใจเมื่อ 3 พ.ย. 2026 เพื่อไม่ให้บรรทัดนี้ผูกกับบัญชีใด ๆ — พอเห็นผลบนหน้าคอมมิตจริง เจ้าของขอให้ขึ้นเป็นโลโก้ Aetox แบบเดียวกับที่ Claude Code ขึ้นคู่กับคนที่คอมมิตด้วย
- **รุ่นนี้** ที่อยู่เปลี่ยนเป็น noreply ของบัญชี Aetox-harness (`325798566+Aetox-harness@users.noreply.github.com`) ซึ่ง GitHub จับคู่เป็นบัญชีนั้นเสมอ — คอมมิตใหม่จึงขึ้นโลโก้กับชื่อบนหน้าคอมมิต และไม่แสดงอีเมล
- **ไม่ได้ทำ** ไม่เขียนประวัติคอมมิตเก่าใหม่ (คอมมิตที่ออกไปแล้วยังมีบรรทัดเดิม) และไม่ได้เปลี่ยนเจ้าของคอมมิต — ฮุกเติมแต่บรรทัดผู้ร่วมเขียน ส่วน `publish-public.ps1` ยังคอมมิตเป็นเจ้าของเหมือนเดิม
- **ไฟล์** `scripts/hooks/prepare-commit-msg`
