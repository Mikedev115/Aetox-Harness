# 🔒 Aetox v1.11.42

วันที่ 27 พฤศจิกายน 2026

งาน UI และความเป็นส่วนตัวที่ค้างในทรีไม่ทันเข้าไปในรุ่น 1.11.41 ที่บิลด์จากแท็ก รุ่นนี้เก็บให้ครบ: veil ปิดชื่อ เบอร์ ที่อยู่ ก่อนข้อความออกจากเครื่อง · หัวแถบข้างบอกว่าอยู่โต๊ะไหนและสลับได้จากเมนู · แผงสกิลที่ใช้บอกว่าเซสชันนี้ใช้สกิลอะไรและมีเอเจนกี่ตัวทำงาน · และสกิล ux-check สำหรับกดหน้าที่รันอยู่จริงในมุมคนใช้ครั้งแรก

## ข้อมูลส่วนตัวไม่ออกจากเครื่อง (veil)

- **เดิม** ชื่อ เบอร์โทร ที่อยู่ หรือโฟลเดอร์บ้านในข้อความไปถึงผู้ให้บริการโมเดลตามจริง และออกไปกับ tool call ที่ส่ง argument ออกนอกเครื่องด้วย
- **ตอนนี้** ก่อนคำขอออกจากเครื่อง ค่าพวกนี้ถูกแทนด้วย stand-in ที่บอกชนิด (`⟦PERSON_1⟧`, `⟦PHONE_1⟧`, `⟦ADDRESS_1⟧` …) แล้วคืนกลับก่อนถึงจอ tool หรือไฟล์
  - ค่าหนึ่งได้ stand-in เดียวตลอดบทสนทนา และคนใช้คือ `PERSON_1` เสมอ โมเดลจึงตามได้ว่าใครเป็นใคร และคำขอเหมือนเดิมทุกไบต์จน prompt cache ของผู้ให้บริการยังใช้ได้
  - stand-in เก็บส่วนที่ไม่ชี้ตัวใครไว้ (จังหวัดของที่อยู่ ปีของวันเกิด) โมเดลจึงเขียนประโยครอบ ๆ ได้ถูก
  - ตารางอยู่ในหน่วยความจำเท่านั้น การปิดเป็น deterministic จากข้อความของคำขอเอง เปิดบทสนทนาเดิมจึงได้เลขชุดเดิมโดยไม่ต้องเขียนอะไรลงดิสก์
  - engine ไม่เคยเห็น stand-in: ประวัติและ tool call เก็บค่าจริง · tool ที่ส่ง argument ออกนอกเครื่องถูกปิดอีกชั้นที่ dispatcher ก่อน secret ถูกใส่เข้าไป secret จึงไม่ถูกเข้าใจผิดว่าเป็นข้อความส่วนตัว
  - สิ่งที่แอปเรียนรู้เกี่ยวกับคน (`USER.md`, ไฟล์เสียง, สาขาใต้ `you/`) ถูกอ่านกลับทันทีที่ถูกเขียน ทั้งที่โมเดลเขียนเอง ผ่านการอนุมัติ หน้าตรวจ หรือรอบประจำวัน
- หน้าตั้งค่ามีสวิตช์และชิปบอกสถานะ (`VeilSettings.svelte`, `VeilChip.svelte`)

## หัวแถบข้างบอกว่าอยู่โต๊ะไหน และสลับได้จากตรงนั้น

- **เดิม** สองประตูบนรางเป็นไอคอนเปล่า ต้องชี้ถึงรู้ว่าอันไหนคือโต๊ะไหน และไม่มีอะไรบอกว่าแต่ละโต๊ะไว้ทำอะไร
- **ตอนนี้** หัวแถบข้างเขียนชื่อโต๊ะที่อยู่เป็นคำ และเปิดเมนูที่บอกสองโต๊ะพร้อมคำอธิบายบรรทัดละอัน · การสลับเป็นสองครั้ง (เปิดเมนู แล้วเลือก) ส่วน `Ctrl+1` / `Ctrl+2` ยังสลับทีเดียวและเมนูพิมพ์ปุ่มกำกับไว้ · ระหว่างทางหัวแถบชื่อปลายทางพร้อมสปินเนอร์ทันทีที่กด · รางที่พับอยู่ยังมีไอคอนคู่เดิม

## แผง "สกิลที่ใช้" ของเซสชัน

- อ่านจาก `tool_runs` แบบเดียวกับแหล่งที่มาและไฟล์ที่แก้: สกิลนับว่าใช้เมื่อเอกสารถูกเปิด (`skill_view`) ไม่ว่าโมเดลเรียกเองหรือคนพิมพ์ `/ชื่อ` · นับเอเจนที่ทำงานในเซสชันด้วย (คอลัมน์ `agent` ของ tool run และชื่อใน `task`) คำถาม "งานนี้ทีมทำหรือเราทำ" จึงตอบได้โดยไม่ต้องถามซ้ำ

## สกิล ux-check

- สกิลใหม่ `aetox-ux-check` (โต๊ะ code และ assistant): วิธีกดหน้าที่รันอยู่จริงในมุมคนใช้ครั้งแรก · อะไรนับเป็นข้อบกพร่องด้าน UX และให้คะแนนอย่างไร · วิธีเขียนบรีฟให้ tester และอ่านผลกลับ
- `AGENT.md` ของ tester อัปเดตตามสกิลนี้
