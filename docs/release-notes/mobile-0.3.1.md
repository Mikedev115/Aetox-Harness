# Aetox Mobile Android 0.3.1

**แอปบอกเองเมื่อมีรุ่นใหม่ และอัปเดตจากในแอปได้**

ต่อจาก [0.3.0](mobile-0.3.0.md) ซึ่งมีคำตอบไหลลื่น เห็นทุกแชท และดูไฟล์ในแอป

## มีอะไรใหม่

- **แอปรู้เวอร์ชันของตัวเอง** และ Aetox บน Windows บอกได้ว่ามี APK รุ่นไหนรออยู่
- **แถบ "มีแอปรุ่นใหม่ · อัปเดต"** ขึ้นที่หัวจอเมื่อ Windows มีรุ่นที่ใหม่กว่า แต่ละรุ่นปิดแถบได้ครั้งเดียว
- **ตั้งค่า › เวอร์ชันแอป** บอกรุ่นที่ใช้อยู่ มีปุ่มตรวจหาอัปเดต และบอกว่าล่าสุดแล้วหรือมีรุ่นใหม่
- **อัปเดตแบบกดครั้งเดียว** แอปโหลด APK จาก Windows ของคุณ ตรวจ SHA-256 ให้ตรงกับที่ Windows ประกาศ แล้วเปิดหน้าติดตั้งของ Android ไฟล์ที่ไม่ตรงจะถูกทิ้งทันที

## ทำไมยังต้องกดยืนยัน

Android ไม่ให้แอปที่ไม่ได้มาจาก Play Store ติดตั้งตัวเองแบบเงียบ ๆ ทุกครั้งจะมีหน้าติดตั้งของระบบให้กด "ติดตั้ง"
ครั้งแรกที่อัปเดต Android จะถามให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" จาก Aetox Mobile ก่อน เปิดสวิตช์แล้วกดอัปเดตอีกครั้ง
การจับคู่และข้อมูลยังอยู่ครบ เพราะเซ็นด้วยคีย์เดิม

## สิทธิ์ที่แอปขอเพิ่ม

**ติดตั้งแอป** (REQUEST_INSTALL_PACKAGES) ใช้เฉพาะตอนกดอัปเดต และติดตั้งได้เฉพาะ APK ที่ SHA-256 ตรงกับที่ Windows ของคุณประกาศ

## อัปเดตจาก 0.3.0 หรือเก่ากว่า

รุ่นเก่ายังไม่รู้เวอร์ชันของตัวเอง ไปที่ ตั้งค่า › เวอร์ชันแอป › อัปเดต แอปจะดาวน์โหลด APK ลงโฟลเดอร์ดาวน์โหลด แล้วกดเปิดไฟล์เพื่อติดตั้ง
ตั้งแต่ 0.3.1 เป็นต้นไป อัปเดตได้จากในแอปเลย

## สถานะการทดสอบ

ผ่าน Go tests ของ gateway (รวมการอ่านเวอร์ชัน APK ที่ตรงกับไฟล์ที่ส่งจริงเท่านั้น), หน้าจอ 91 tests, svelte-check
APK ผ่าน unit tests, lint และตรวจลายเซ็น
**ยังไม่ได้ลองอัปเดตบนมือถือจริง**
