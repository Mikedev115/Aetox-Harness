# 🪟 Aetox v1.10.32

วันที่ 30 ตุลาคม 2026

**ร้อนแก้ข้อเดียว — กด Ctrl+V วางภาพแคปหน้าจอลงในช่องแชทได้แล้ว ภาพที่วางในโปรแกรมอื่นได้ก็มาลงที่นี่ได้เหมือนกัน**

## แชท: ภาพแคปหน้าจอวางได้ ไม่ใช่กดแล้วเงียบ

- **สาเหตุ** ตัวอ่านคลิปบอร์ดรู้จักแต่บิตแมปแบบ DIB แต่ภาพแคปของ Windows 11 วางไว้บนคลิปบอร์ดเป็นฟอร์แมต `PNG` ล้วน ไม่มี CF_DIB หรือ CF_DIBV5 อยู่เลย (วัดจากภาพจริง 1 ภาพ: PNG 215012 ไบต์ 2009x1382) ตัวอ่านจึงเห็นคลิปบอร์ดว่าง แล้ว Ctrl+V ก็ไม่มีอะไรเกิดขึ้น ทั้งที่ภาพเดียวกันวางในโปรแกรมอื่นได้ (เจ้าของ 30 ต.ค. 2026: "วางข้างนอกเสือกได้ทำไมวางใน Aetox ไม่ได้")
- **อีกชั้นที่ทำให้เงียบ** สิ่งที่ WebView2 ส่งมาในอีเวนต์การวางมาว่างเปล่าสำหรับภาพ — ไม่มีไฟล์ ไม่มีชนิดที่หน้าจออ่านได้ การแก้ที่อีเวนต์อย่างเดียวจึงไม่เคยช่วย
- **ตอนนี้ถาม Windows ตรง ๆ** ฝั่ง Windows มี `ClipboardImage` อ่านฟอร์แมต `PNG` ก่อน ตามด้วย DIBV5 แล้ว DIB คืนเป็น PNG data URL — ทางเดียวกับที่ `SaveChatImageData` รับภาพที่ไม่มี path อยู่แล้ว ภาพจึงกลายเป็นไฟล์แนบปกติในโฟลเดอร์ของเซสชัน อ่านได้ด้วยสกิลทุกตัว และส่งเข้าห้องแชทเป็นภาพได้เหมือนภาพที่เลือกมาทางอื่น
- **DIB ที่ยังมีอยู่ก็ยังอ่านได้** 24 หรือ 32 บิต ธรรมดาหรือมีตารางสีมาตรฐาน เก็บจากล่างขึ้นหรือบนลง ไบต์โปร่งใสที่มากับภาพแคป (ซึ่งเป็นศูนย์ทั้งภาพ) ถือว่าทึบ ไม่ใช่ภาพโปร่งแสงทั้งใบ
- **ภาพที่ความลึกยังไม่รู้จักถูกปฏิเสธเป็นคำ** ข้อความภาษาไทยบนแชทบอกเหตุ ไม่ใช่ภาพที่วาดผิดเงียบ ๆ และไม่ใช่การวางที่หายไปเฉย ๆ
- **ช่องพิมพ์เอารูปจาก Windows ก่อน ของในอีเวนต์เป็นทางสำรอง** เมื่อรู้ว่าเป็นการวางภาพจะ `preventDefault` ก่อนรอคำตอบ คำของภาพจึงไม่ตกไปเป็นข้อความข้างหลัง
- **การวางข้อความไม่ถูกแตะเลย** ตัดสินจากคำในคลิปบอร์ด ไม่ใช่จากรายการฟอร์แมต เพราะเซลล์สเปรดชีตมีฟอร์แมตภาพติดมาพร้อมคำของมัน สิ่งที่ต้องลงคือคำ
- **ระหว่างที่โปรแกรมอื่นถือคลิปบอร์ดอยู่** การเปิดคลิปบอร์ดรอและลองซ้ำสั้น ๆ เหมือนทางรายการไฟล์ (ย้ายมาใช้ฟังก์ชันเดียวกัน หน้าต่างเองก็อ่านคลิปบอร์ดเดียวกันตอนสร้างอีเวนต์) การวางที่ไม่พบภาพจึงไม่ขึ้นเป็นข้อผิดพลาด

## ความมั่นใจของรุ่น

- เพิ่มเทสต์ฝั่ง Windows 5 ข้อใน `desktop/clipboard_image_windows_test.go` — 32 บิตเก็บจากล่างขึ้น, 24 บิตบนลงพร้อมไบต์เติมท้ายแถว, ตารางสีที่สลับช่อง, `isPNG` รับแต่ PNG จริง และความลึกที่อ่านไม่ได้ต้องถูกปฏิเสธ ไฟล์ชุดนี้ผ่าน 5/5
- เพิ่มเทสต์หน้าจอ 4 ข้อใน `clipboardPaste.test.ts` — ภาพที่ Windows ตั้งชื่อให้ต้องถูกแนบแม้อีเวนต์ว่างเปล่า, คลิปบอร์ดที่ไม่มีภาพตอบ `false` ไม่ใช่แนบของว่าง, ตัวอ่านภาพที่ล้มไม่นับเป็นการวางที่ล้ม และภาพที่เอนจินปฏิเสธต้องขึ้นข้อความบนแชท ไฟล์ชุดนี้ผ่าน 12/12
- ตรวจฝั่ง Windows ด้วยเทสต์ที่ยืนยันกับคลิปบอร์ดจริงของแพ็กเกจ `desktop` และการวางข้อความยังเดินทางเดิมทุกอย่าง
