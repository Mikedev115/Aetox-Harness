# 🪟 Aetox v1.10.21

วันที่ 28 ตุลาคม 2026

**การ์ดโปรเจกต์ในแถบซ้ายบอกว่าสร้างด้วยภาษาอะไรแทนไอคอนโฟลเดอร์ที่เหมือนกันทุกใบ และช่องที่เคยเปิดฟอร์มแก้ชื่อคือ `+` ที่เริ่มแชทใหม่ในโปรเจกต์นั้น · ชีตของเซิร์ฟเวอร์ MCP มีแถวการเข้าสู่ระบบที่บอกบัญชีและขอสิทธิ์ใหม่ได้ รวมถึงกรณีที่บริการเพิกถอนสิทธิ์ และสาเหตุที่ล้มเหลือหนึ่งประโยคที่คนอ่านรู้เรื่อง**

## การ์ดโปรเจกต์บอกภาษาที่ใช้ และ `+` เริ่มแชทแทนการแก้ชื่อ

- **เดิม** การ์ดโปรเจกต์ทุกใบขึ้นไอคอนโฟลเดอร์เหมือนกันหมด จึงไม่มีอะไรบอกว่าใบหนึ่งคือ Go อีกใบคือ Svelte และปุ่มมุมขวาบนเป็นดินสอเมื่อโปรเจกต์มีคำอธิบาย แต่กลายเป็น `+` เมื่อยังไม่มี — สองไอคอนที่แปลว่า "สร้างใหม่" อยู่แล้วที่อื่นในรางเดียวกัน (เริ่มเซสชันใหม่ที่หัวแถบ และ `+` ที่แถวโปรเจกต์) แต่กดแล้วเปิดฟอร์มแก้ชื่อ (เจ้าของ 28 ต.ค. 2026: "คนงง … ใช้ไอคอนเดียวกับสร้างเซสชั่นใหม่" และ "ให้มันแสดงโลโก้ ภาษาหรือเฟรมเวคที่ใช้")
- **รุ่นนี้** การ์ดบอกว่าสร้างด้วยอะไร: ชิปชื่อภาษา/เฟรมเวิร์กพร้อมไอคอน ไอคอนโฟลเดอร์ไม่มีแล้ว · ปุ่มขวาบนเป็น `+` ที่เริ่มแชทใหม่ในโปรเจกต์นั้น (`startChatIn` เปิดโปรเจกต์แล้วพามาที่แชทที่เพิ่งเกิด ไม่ได้定義ทางเข้าใหม่) และการแก้ชื่อ/คำอธิบายย้ายเข้าเมนู `⋯`
- **อ่านจาก manifest ที่รากโปรเจกต์เท่านั้น** `internal/projstack` อ่าน `go.mod` · `Cargo.toml` · `pyproject.toml`/`requirements.txt`/`setup.py`/`Pipfile` · `pubspec.yaml` · `composer.json` · `Gemfile` · `Package.swift` · `*.csproj`/`*.fsproj`/`*.sln` · `pom.xml`/`build.gradle[.kts]` · `package.json` (อ่าน dependencies/devDependencies/peerDependencies) และ `Dockerfile`/`compose` — ไม่เดินโฟลเดอร์ย่อย ไม่รันคำสั่งใด ๆ และตัดที่สามตัว (`projstack.Max`)
- **ภาษาอยู่ก่อนและมีตัวเดียว** โปรเจกต์ที่มีทั้ง `go.mod` และ `package.json` คือโปรเจกต์ Go ที่มีหน้าเว็บ ไม่ใช่สองโปรเจกต์: ภาษาก่อน แล้วจึง TypeScript/Node และเฟรมเวิร์ก (Svelte/Vue/React) แล้วจึง Docker
- **ค่าเดินทางมากับแถวที่แถบซ้ายโหลดอยู่แล้ว** `ProjectMeta.Stack` ขึ้นมากับ `RecentProjects()` ครั้งเดียว ไม่มีคำขอต่อการ์ด (ตามกฎ `pageWindow` ใน `AGENTS.md`) และแคชต่อโฟลเดอร์ตามรายชื่อไฟล์ที่รากกับ mtime/size ของ `package.json` เพราะการเพิ่ม dependency เปลี่ยนคำตอบโดยไม่เปลี่ยนชื่อไฟล์
- **โฟลเดอร์ที่ย้ายหายไปยังอยู่บนรายการ** แค่การ์ดไม่มีชิป เพราะแชทที่อยู่ในโฟลเดอร์นั้นยังอ่านได้
- **ชื่อที่ไม่รู้จักถูกตัดทิ้ง ไม่แสดงดิบ** `projectStack.ts` แปลง id เป็นคำและภาพจาก `lib/fileMarks` ชุดเดียวกับไอคอนไฟล์ใน explorer — ชิปที่อ่านว่า "sveltee" แย่กว่าการ์ดที่มีชิปน้อยลงหนึ่งอัน ส่วนการ์ดที่ไม่มี manifest ที่รู้จักก็ไม่วาดแถวนั้นเลย ไม่เดา
- **การ์ดหน้า "ล่าสุด" มีเมนูสั้นกว่าหน้า "โปรเจกต์ทั้งหมด"** การ์ดที่เพิ่งเปิดมีชื่อกับคำอธิบายใน `⋯` ส่วนปักหมุด/เปิดโฟลเดอร์/คัดลอกพาธ/เอาออกจากรายการยังอยู่หน้า "โปรเจกต์ทั้งหมด" ที่การจัดการอยู่มาตั้งแต่ 7 ก.ย.
- **ทำไมเลือกทางนี้** ไอคอนเดียวที่เหมือนกันทุกใบไม่ได้แยกอะไรเลย และไอคอนที่แปลว่า "สร้างใหม่" อยู่แล้วในรางเดียวกันกลายเป็นตัวเปิดฟอร์มแก้ชื่อ — ทั้งสองอย่างแก้ที่ความหมาย ไม่ใช่ที่ภาพ ชิปที่ชื่อภาษาพร้อมคำอ่านตอบ "โปรเจกต์นี้คืออะไร" ได้ตั้งแต่ก่อนกดเข้าไป

## ชีตของเซิร์ฟเวอร์ MCP: แถวการเข้าสู่ระบบ และสาเหตุที่ล้มเหลือหนึ่งประโยค

- **เดิม** เซิร์ฟเวอร์ที่ถือสิทธิ์ OAuth ของตัวเองไม่มีที่บอกว่าเข้าถึงบริการด้วยบัญชีไหน และเมื่อบริการเพิกถอนสิทธิ์ (400 `invalid_grant`, 401) ทางกลับมามีทางเดียวคือลบเซิร์ฟเวอร์ทิ้ง เพราะปุ่มเข้าสู่ระบบอยู่ในบล็อกสาเหตุ ซึ่งขึ้นเฉพาะตอนที่แอปคิดว่ายังไม่ได้เข้าสู่ระบบ ไม่ใช่ตอนที่สิทธิ์มีอยู่แต่ใช้ไม่ได้แล้ว ส่วนหัวของสาเหตุคือห่วงโซ่ของ transport เอง
- **รุ่นนี้** แถว "การเข้าสู่ระบบ" (`.cap-signin`) ใต้แท็บ ขึ้นกับทุกเซิร์ฟเวอร์ที่สิทธิ์เป็น OAuth ของตัวเอง ไม่ว่าตัวนั้นจะพังหรือไม่: ชื่อที่เก็บสิทธิ์ไว้ · สถานะ (เก็บสิทธิ์ไว้แล้ว / ยังไม่ได้เข้าสู่ระบบ / เก็บสิทธิ์ไว้แล้ว แต่ {name} ไม่รับแล้ว) · และปุ่มเดียวที่ขอสิทธิ์ใหม่ ซึ่งเป็นปุ่มหลักเมื่อสิทธิ์ถูกปฏิเสธ
- **สาเหตุเป็นประโยคเดียว** `refusedAuth()` จับ `invalid_grant` · `invalid_token` · `unauthorized` · `401` · `Grant not found` แล้วขึ้น `capability.sheetCauseRefused` กับ `capability.sheetWhatRefused` ที่บอกว่ากดตรงไหน กรณีอื่นที่ `humanErr` แปลเป็นคำใหม่ไม่ได้ขึ้น `capability.sheetCauseFailed` แทนการพิมพ์ error ดิบ และคำที่ `humanErr` แปลได้ (เช่นพอร์ตตายที่บอกให้เปิดโปรแกรมไหน) ยังขึ้นตามเดิม
- **ข้อความของ transport ไม่ได้หาย** ยังอยู่ครบหลัง `<details class="cap-fix-raw">` พร้อมป้าย "รายละเอียดทางเทคนิค"
- **ปุ่มเข้าสู่ระบบเหลือชุดเดียวในชีต** ปุ่มในบล็อก `.cap-fix` ถูกถอดออก เพราะแถวบัญชีอยู่บนจอตลอดเวลา — ปุ่มเดียวสองที่ในชีตเดียวคือสิ่งที่แถวนี้มาแทน
- **ทำไมเลือกทางนี้** เจ้าของ 27 ต.ค. 2026: "คนทั่วไปเขาไม่อยากอ่านเออเร่อ" และ "ทำไมไม่มีปุ่มเชื่อมต่อหรือล็อคอินใหม่" คำถามที่คนเปิดชีตมาถามคือ "ตัวนี้ไม่ทำงานเพราะอะไร และกดอะไรต่อ" คำตอบที่ดีที่สุดจึงเป็นประโยคเดียวกับปุ่มที่กดได้ ส่วนห่วงโซ่การเรียกเป็นของคนที่กำลังแก้โค้ด ไม่ใช่ของคนที่แค่ต้องการให้มันทำงาน
