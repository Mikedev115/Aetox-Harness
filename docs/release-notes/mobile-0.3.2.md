# Aetox Mobile Android 0.3.2

**หน้าเชื่อมต่อบอกสาเหตุเป็นคำที่อ่านรู้เรื่อง และแอปไม่หลุดกลับหน้าเชื่อมต่อง่าย**

ต่อจาก [0.3.1](mobile-0.3.1.md) ซึ่งบอกเองเมื่อมีรุ่นใหม่ และอัปเดตจากในแอปได้

## มีอะไรใหม่

- **ต่อไม่ติดแล้วบอกว่าเพราะอะไร** แทน error ดิบอย่าง "Unable to resolve host" หน้าเชื่อมต่อบอก เช่น "มือถือยังไม่ได้ต่อ Tailscale" พร้อมวิธีแก้ แยก 7 สาเหตุ ทั้งตอนตรวจที่อยู่และตอนที่หน้าแชตโหลดไม่ขึ้น error ดิบยังอยู่เป็นบรรทัดเล็กด้านล่าง
- **ปุ่มเปิด Tailscale** เมื่อสาเหตุคือ Tailscale ยังไม่ต่อ กดแล้วเปิดแอป Tailscale กลับมาแอปต่อเอง
- **502 จาก Tailscale** บอกว่า Aetox บนคอมยังไม่ได้เปิด ไม่ใช่ปัญหาของมือถือ
- **ไม่หลุดกลับหน้าเชื่อมต่อ** ตอนสลับโหมดมืด เปลี่ยนขนาดตัวอักษร หรือ Android คืนแรมแล้วเปิดแอปกลับมา แอปต่อคอมที่จำไว้เอง
- **กด Back ตอนไม่มีหน้าก่อนหน้า** พักแอปไว้เบื้องหลัง ไม่ทิ้งการเชื่อมต่อ
- **หน้าแชตถูกระบบปิด** แอปต่อใหม่เอง (ไม่เกินนาทีละครั้ง)

## ของใหม่ที่มาจาก Windows

หน้าจอแชตมาจาก Aetox บน Windows จึงได้ของใหม่ไปพร้อม [Aetox 1.10.0](v1.10.0.md) โดยไม่ต้องอัป APK:
เลือกโปรเจกต์และทีมก่อนเริ่มแชต ส่งข้อความแทรกระหว่างที่เอเจนต์ทำงาน หน้าสมาชิกทีม และโมเดลของแชต CLI

## ต้องใช้

Aetox บน Windows **1.9.28 ขึ้นไป** (1.10.0 สำหรับของใหม่ข้างบน) · Android 10 ขึ้นไป · Tailscale HTTPS
อัปเดตจาก 0.3.1 ได้จากในแอป: ตั้งค่า › เวอร์ชันแอป › อัปเดต เซ็นด้วยคีย์เดิม การจับคู่และข้อมูลอยู่ครบ
