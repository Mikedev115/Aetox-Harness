# Aetox Mobile Android 0.3.7

**รุ่นนี้แก้ตัวแอป Android** โค้ดใน `mobile/android` เปลี่ยน ไม่ใช่แค่เลขรุ่น

ต่อจาก [0.3.6](mobile-0.3.6.md)

## มีอะไรใหม่

- **อัปเดตแล้วบอกได้ว่าพลาดตรงไหน** ก่อนหน้านี้การอัปเดตที่ล้มเหลวทุกแบบจบที่คำเดียวว่า
  "อัปเดตไม่สำเร็จ" ทั้งที่สาเหตุต่างกันคนละเรื่อง: ไฟล์ที่โหลดมาไม่ตรงกับที่คอมประกาศ, โหลดจากคอมไม่สำเร็จ,
  Android ไม่ได้ติดตั้งให้, หรือมือถือไม่ตอบกลับเลย ตอนนี้แต่ละแบบมีประโยคของตัวเอง
- **ยืนยันว่าติดตั้งจริง ไม่ใช่เดา** หลังตัวติดตั้งของ Android ปิดลง แอปจะเทียบเลขรุ่นในไฟล์ที่โหลดมากับ
  เลขรุ่นที่ติดตั้งอยู่ ถ้ายังเท่าเดิมจะบอกว่า "Android ไม่ได้ติดตั้งรุ่นใหม่ อนุญาตให้ติดตั้งแล้วกดอีกครั้ง"
  แทนที่จะกลับไปขึ้นแถบ "มีแอปรุ่นใหม่" เงียบ ๆ ทุกครั้งที่เปิดแอป
- **กลับมาจากหน้าอนุญาตติดตั้งแล้วทำต่อเอง** สลับ "อนุญาตให้ติดตั้งจากแอปนี้" แล้วกลับมา แอปจะเปิดตัวติดตั้งให้ทันที
  ไม่ต้องกดอัปเดตซ้ำ ไม่ต้องโหลด 8 MB ใหม่ (APK ที่โหลดและตรวจ SHA แล้วเก็บไว้ใช้ซ้ำได้)
- **ไม่ค้างที่ 0% อีก** ถ้ามือถือไม่ตอบรับคำขอภายใน 30 วินาที หน้าจอจะบอกว่าไม่ได้รับคำตอบแทนที่จะรอเงียบ ๆ
  และถ้ารุ่นไหนเคยติดตั้งไม่ผ่าน แถบเตือนจะไม่ขึ้นซ้ำรุ่นเดิม แต่ยังกดอัปเดตได้ที่ ตั้งค่า › เวอร์ชันแอป
- **หน้าจอที่เห็นในแอปยังมาจาก Aetox บน Windows** การแก้หน้าจอ (ความคิดไหลระหว่างเทิร์น, ระดับความคิด,
  แชททีม) มากับรุ่น Windows
