# 🏢 Aetox v1.10.16

วันที่ 26 ตุลาคม 2026

**ห้องบริษัทเชื่อสิ่งที่คนสั่งทันที — ปิดทีมแล้วห้องโล่ง เปิดลูกมือแล้วเข้ายืนประจำที่ของตัวเอง และไม่มีใครไปยืนห้องคนอื่น**

## สวิตช์ในห้องบริษัท ต้องตรงกับภาพที่เห็น

- **เดิม** การปิดทีมทำโดยสร้าง roster ใหม่ทั้งชุดแล้ว build ห้องใหม่ สวิตช์ที่กดระหว่างเปิดห้องจึงขึ้นกับจังหวะ rebuild — กดปิดแล้วทีมยังแสดง กดเปิดแล้วไม่แสดง เพราะห้องใช้ roster เก่าที่อ่านค่า mute ตอนสร้างครั้งเดียว
- **รุ่นนี้** planner ยกคนของทีมที่ปิดออกจากห้องและใส่กลับที่นั่งเดิมเมื่อเปิดคืน ส่วนห้องสร้างใหม่ทันทีที่ mute หรือ standing เปลี่ยน `redress()` สร้าง roster ใหม่จาก rows ที่อ่านมาแล้ว (`lastCards`/`lastProfiles`/`lastDepts`) ไม่ต้องถามเอนจินซ้ำรอบใหม่
- **ห้องของทีมที่ปิดสนิท** เหลือตัวหลักกับลูกมือ ไม่มีสมาชิกและไม่มีหัวหน้า แต่เฟอร์นิเจอร์ โต๊ะรับ และลูกมือยังอยู่ เพราะลูกมือมาจาก fact ของตัวเอง ไม่ใช่ของทีม
- **ลูกมือยืนประจำที่** `planner.standHands` วางลูกมือที่เปิดไว้ที่หน้าทีมของห้อง (หนึ่งคนหนึ่งรูป) และตอนรับงานจริงจะเอารูปประจำออกก่อน เพื่อไม่ให้ใครถูกวาดซ้ำ
- **ไม่มีทีมก็มีห้องของตัวเอง** เอเจนที่ไม่ได้ขึ้นกับทีมไหนได้ห้องเดี่ยว (โต๊ะเดียว สถานีงาน ที่เก็บไฟล์ กล่อง Output) แทนการไปยืมห้องทีมแรกในบริษัท ส่วนซับเอเจนยืนในห้องของคนที่จ้างมัน
- **path ซ้ายบน** ไม่ขึ้นชื่อทีมซ้ำสองครั้งอีก เมื่อทีมที่ไม่มีแผนกถูกวาดเป็นปีกชื่อเดียวกับทีม

## องค์กรอ่านครั้งเดียว ชิปกับห้องจึงตอบตรงกัน

- snapshot ขององค์กรย้ายมาอยู่ที่ `lib/stores/org.svelte.ts` ที่เดียว (แคช 15 วินาที บังคับอ่านใหม่ได้ เขียน reach รายหัวหน้าได้) ชิปผู้ช่วยกับห้องอ่านจากที่นี่ทั้งคู่
- หน้าตั้งค่าทีมและการบันทึกโปรไฟล์เอเจนเรียก `invalidateOrg()` ทุกครั้ง และห้องที่เปิดค้างอ่าน org ใหม่เมื่อ revision เปลี่ยน — เพิ่มทีมหรือเอเจนกะทันหันแล้วห้องกับชิปเห็นทันที ไม่ต้องรีเฟรช
- ระดับที่ประตูทีมยืนอยู่เปลี่ยนจากบริษัทเป็นทีม ห้องจึงเปิดที่ห้องของทีมเป็นค่าเริ่มต้น ค่าที่คนเลือกเองยังไม่ถูกทับ

## คลังวัตถุดิบของสตูดิโอ เลือกเพลงได้ด้วยหู

- เพลงแสดงเป็นตารางพร้อมข้อมูลการใช้งานและรูปคลื่น แถบเล่นรองรับหยุด เล่นซ้ำ และเลื่อนตำแหน่ง โดยเล่นได้ทีละเพลง
- รูปคลื่นอ่านเบื้องหลังแบบจำกัดงาน ถอดเสียงด้วย ffmpeg ที่ 8 kHz โมโน เก็บเป็นแคชต่อ asset id พร้อมขนาดและ mtime — ไฟล์ที่ถูกแทนที่จึงอ่านใหม่ ไฟล์ที่ย้ายที่ไม่ต้องถอดซ้ำ และถ้าไม่มี ffmpeg หรือไฟล์ไม่มีเสียงจะคืน error ไม่ใช่แท่งศูนย์ที่ดูเหมือนเพลงเงียบ
- `Usage` ใน Store นับจำนวนครั้งที่แอสเซ็ตถูกหยิบไปใช้และเวลาล่าสุด ซึ่งการสแกนโฟลเดอร์บอกไม่ได้
- **โฟลเดอร์รับไฟล์**: วางไฟล์ที่ดาวน์โหลดมาลงกล่องรับแล้วสื่อเข้าคลังเอง มีปุ่มเปิดโฟลเดอร์นั้นจากการ์ด
- **คำขอวัตถุดิบ**: เครื่องมือค้นหาคลังมีแอ็กชัน `request` ให้เอเจนขอสิ่งที่ยังขาดได้ พร้อมระบุประเภทและที่มา คำขอที่บันทึกซ้ำจะไม่ซ้อน ปิดได้เองหรือเมื่อสแกนพบสื่อประเภทที่ต้องการ

## งานที่มอบขึ้นที่ผังในข้อความเดียว

- ผังใต้ข้อความเป็นที่เดียวที่วาดงานที่มอบออกไป ถาดใต้แชทไม่วาดซ้ำ และแถวอ่านสถานะจาก register ก่อน ลูกมือที่ทำงานต่อหลังเทิร์นจบจึงยังบอกได้ว่ากำลังทำอะไร
- ที่ยังอยู่ใต้แชทคือของที่ผังแทนไม่ได้: เฟสของ run ที่ประกาศไว้ และคำถามที่แถวของมันถูกพับไว้

## เปลี่ยนอื่น ๆ ในรุ่นนี้

- **Roblox Studio** มีการ์ดของตัวเองในห้องสมุด: preset ระบุเดสก์ของตัวเองได้แล้ว (เดิมวางเซิร์ฟเวอร์ลงเดสก์ผู้ช่วยเสมอ เครื่องมือจึงไม่เคยถึงเดสก์ที่ทำงานจริง) พร้อม allowlist 12 tools ที่วัดจากเซิร์ฟเวอร์จริง และสกิล `aetox-mcp-roblox`
- **สกิลงานตัดคลิป** พาตั้งแต่ `cut_open`/`assemble` ถึงเรนเดอร์ พร้อมเกณฑ์ตรวจซับ เสียง และเฟรม — โต๊ะผู้ช่วยเปิดห้องตัดได้อยู่แล้วแต่ไม่มีความรู้ว่าจะตัดยังไงให้จบ
- **ตั้งค่า Ollama**: เซิร์ฟเวอร์ที่ไม่ usable (พอร์ตถูกจับแต่ไม่ตอบ Ollama) ยังเห็นแถว Base URL และแก้ที่อยู่ได้ เดิมแถวหายไปทั้งแถว ซึ่งเป็นกรณีที่ต้องแก้พอดี
- **Usage บอกได้ว่าเอนจินรายงานแคชจริงหรือไม่ได้บอก** — `CachedInputTokens` ที่เป็นศูนย์แยกไม่ออกระหว่างแคชพลาดจริงกับเอนจินที่ไม่รายงาน ฟิลด์ `CacheReported` จึงพามาด้วย และสถานะนี้ถูกส่งต่อจากเอนจินที่เรียกผ่าน adapter ไปถึงยอด usage ด้วย
- สกิล Unsplash ระบุเครื่องมือครบทั้ง 8 ตัว ตรงกับ `toolCount` ที่ประกาศไว้
- tests ที่เพิ่มในรุ่นนี้: `localServerEndpoint.test.ts` (แถว Base URL ต้องอยู่เมื่อ ollama ค้าง) เทสต์การปิดทีมแล้วไม่มีแถวหรือการ์ดของทีม เทสต์ session spend ที่เก็บยอดและสถานะแคชจากเอนจิน และเทสต์การยุบแท่งรูปคลื่น
