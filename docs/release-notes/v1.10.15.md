# 🎬 Aetox v1.10.15

วันที่ 24 ตุลาคม 2026

**วิดีโอในเครื่องกลับมาอยู่บนโต๊ะผู้ช่วย — ตัวฟรีที่เรนเดอร์เองอยู่ข้างตัวที่เสียเครดิตอีกครั้ง**

## สั่งทำคลิปในแชทผู้ช่วย แล้วไม่มีเครื่องมือให้ใช้

- **เดิม** การทำวิดีโอเคยแยกเป็นสองทาง: `video` เขียนฉากเป็น HTML แล้วเรนเดอร์เองในเครื่อง ฟรี และ `video_make` ให้ผู้ให้บริการวิดีโอสร้างคลิปที่ดูเหมือนถ่ายจริง เสียเครดิต แต่ tool ฟรีตัวนั้นอยู่กับเอเจนวิดีโอและผู้กำกับเท่านั้น เพราะมันอยู่ในหมวด "ส่งงานเป็นไฟล์" ซึ่งไม่มีโต๊ะไหนประกาศหมวดนี้ โต๊ะผู้ช่วยจึงได้มาเฉพาะ `video_make` ที่เขียนชื่อไว้ตรง ๆ
- ผลคือพอสั่งทำคลิปในแชทผู้ช่วย โมเดลไม่มีเครื่องมือที่ทำได้ จึงออกไปหา Hyperframes ตามดิสก์เองหรือตอบว่าทำไม่ได้ ทั้งที่ตัวเรนเดอร์ติดตั้งอยู่ในเครื่องแล้ว และการสลับเส้นทางวิดีโอเป็น API หรือ MCP ก็ไม่ได้ทำให้ตัวฟรีกลับมา (มันกรองแค่ action ของ `video_make`)
- **รุ่นนี้** โต๊ะผู้ช่วยถือ `video` อยู่ข้าง `video_make` แล้ว สั่งทำคลิปกราฟิกในแชทผู้ช่วยจึงหยิบฉากจากคลังหรือ `blank` มาเรนเดอร์ในเครื่องได้เลย ไม่ต้องผ่านเอเจนวิดีโอ และไม่ต้องเสียเครดิต
- `video_make` ยังเป็นทางของฟุตเทจที่ต้องถ่ายจริงตามเดิม — คำอธิบายของทั้งสอง tool บอกเส้นแบ่งไว้เองว่าเมื่อไรควรใช้ตัวไหน

## เปลี่ยนอื่น ๆ ในรุ่นนี้

- คอมเมนต์ใน `internal/engine/app.go` ที่เขียนว่า "ไม่มีโต๊ะไหนถือ tool นี้" แก้ให้ตรงกับความจริง เพราะตอนนี้โต๊ะผู้ช่วยเขียนชื่อมันไว้แล้ว
- tests ที่เพิ่มในรุ่นนี้: `TestDesksCarryWhatTheyClaim` มีเคสปักว่าโต๊ะผู้ช่วยต้องถือทั้ง `video` และ `video_make` (เคสเดียวกับที่เคยพลาดเรื่อง `image_make` เมื่อ 13 ก.ย.)
