# 🪟 Aetox v1.10.28

วันที่ 29 ตุลาคม 2026

**การ์ดติดตั้งบอกได้ว่าของที่กำลังติดตั้งจะทำอะไรกับเครื่องบ้าง และปักไว้ที่ commit ที่ลิงก์ระบุ · แท็บเบราว์เซอร์ที่ถูกซ่อนไปแล้วกลับมาที่ขนาดเดิม ไม่เหลือพื้นที่ดำ · งานที่ชัดและไม่ได้อยู่ในเรื่องที่ผู้ใช้กำลังทำถูกส่งให้ลูกมือทำแทน โดยที่ลูกมืออ่านบริบทที่ส่งไปรอบเดียว**

## ติดตั้ง: รู้ก่อนกด

- **แถว "จะทำอะไรได้"** การ์ดติดตั้งอ่านจากไฟล์ของแพ็กเกจเอง แล้วบอกว่าจะใช้เซิร์ฟเวอร์อะไร รันคำสั่งอะไร เขียนไฟล์ที่ไหน
- **บอกเจ้าของและรุ่นที่ปักไว้** ผู้เผยแพร่มาจากที่เราตรวจได้จริง ลิงก์ GitHub ที่ระบุ `/tree`, `/releases/tag` หรือ `/commit` ถูกจำไว้ แล้วติดตั้งที่ commit นั้น ไม่ใช่หัว branch ที่ขยับได้
- **ต้นทางที่ติดต่อไม่ได้ขึ้นว่า "ตรวจสอบไม่ได้"** สถานะนี้ไม่มีเลขศูนย์ปลอมขึ้นมาแทน และยังกดติดตั้งได้ตามเดิม
- **ตรวจความน่าเชื่อถือยิงพร้อมกัน** เซิร์ฟเวอร์กับแพ็กสกิลจึงรอเท่าตัวที่ช้าที่สุด ไม่ใช่บวกกัน และตัวเลขการติดตั้งเป็นยอดรวมที่เห็นภาพจริง
- **โลโก้ผู้พัฒนาในผลค้นหา** ภาพโปรไฟล์ของเจ้าของดึงมาแสดงได้ ไม่ต้องรอเปิดหน้าเว็บ และมีเพดานขนาดกับแคชกันการดึงซ้ำ
- **"ให้ใครได้ใช้" ใช้สวิตช์แถวเดียวกับที่อื่นในแอป** แทนปุ่มเปลี่ยนแบบเดิม จึงเลือกได้ตามที่ผู้ช่วยตั้งไว้ หรือกดเลือกเองก็ได้
- **แผงพรีเซ็ต MCP พับชื่อเครื่องมือ** ไว้หลังปุ่ม "ดูชื่อ N ตัว" และสลับเป็น "เพิ่มขึ้นชั้นวาง" ได้จากแผงเดียวกัน

## สกิล: ที่มา และรุ่นที่ปักไว้

- **แถวสกิลที่ค้นเจอบอกที่มาได้** อ่านกลับจากโน้ต `.aetox-source.json` ที่ตัวติดตั้งทิ้งไว้ในโฟลเดอร์สกิล จึงรู้ว่ามาจากไหนและผ่านอะไรมา ไม่ใช่เดาจากชื่อ
- **การอ่านรายการใช้รุ่นเดียวกับตอนติดตั้ง** ถ้าตอนติดตั้งปัก commit ไว้ รายการก็อ่านที่ commit นั้น
- **ที่อยู่ที่หลุดขอบเขตถูกทิ้ง** ถ้า ref ที่ได้มาไม่ใช่ที่อยู่ของ repo หรือมีอักขระแปลก ระบบถอยไปอ่าน branch เริ่มต้นแทนที่จะยอมอ่านที่อื่น

## แกลเลอรี: คลิปและเสียงที่เรนเดอร์แล้ว

- **ไฟล์วิดีโอและเสียงที่เรนเดอร์แล้วขึ้นหน้าเอง** แม้ไม่มี handoff เพราะการมีอยู่ของไฟล์คือหลักฐานว่างานเสร็จ ส่วนชนิดอื่นยังต้องมี handoff เหมือนเดิม กันภาพและสคริปต์กลางทางไม่ให้ปนขึ้นมา
- **คลิปที่อยู่ในโฟลเดอร์ย่อยเป็นการ์ดของตัวเอง** ไม่ถูกยุบรวมเป็นการ์ดโฟลเดอร์จนหาไม่เจอ

## เบราว์เซอร์: แท็บที่ถูกซ่อนกลับมาที่ขนาดเดิม

- **แก้แท็บที่โผล่กลับมาเป็นผิวเดิม** แท็บที่ซ่อนอยู่ไม่ได้ถูกวาดใหม่ วินโดว์ลูกจึงเก็บเฟรมเดิมไว้ พอยกขึ้นมาอย่างเดียวก็ได้สี่เหลี่ยมเดิมกลับมา ไม่ใช่สี่เหลี่ยมของหน้าต่างที่เปลี่ยนขนาดไปแล้ว — เครื่องเจ้าของเคยเห็นแท็บกลับมาเป็น 1854x1628 ในหน้าต่าง 1453x880 แล้วส่วนที่เหลือเป็นดำ
- **ตอนนี้วางสี่เหลี่ยมที่บันทึกไว้ซ้ำด้วยการเปลี่ยนขนาดจริง** และขอให้คอนโทรลเลอร์จัดหน้าใหม่ หน้าเว็บจึงวาดที่ระยะใหม่ทั้งหน้า
- **ไม่แย่งโฟกัส** ทุกเส้นทางยังไม่ยึดโฟกัสจากช่องที่ผู้ใช้กำลังพิมพ์อยู่

## มอบงาน: งานระหว่างทาง และคำตอบที่อ่านรอบเดียว

- **งานที่ชัดและไม่เกี่ยวกับเรื่องที่ผู้ใช้กำลังทำ ถูกส่งให้ลูกมือ** คำอธิบายเครื่องมือมอบงานเขียนว่าเมื่อก่อนอ่านแล้วเหมือน "เก็บไว้ทำเองโดยปริยาย" ซึ่งเป็นตรงข้ามของที่ต้องการ และไม่เคยมีบรรทัดชวนส่งงานที่เจอระหว่างทางออกไปเลย
- **เรื่องที่ผู้ใช้กำลังทำยังอยู่ที่ตัวเมน** งานที่ต้องคุยไปมา ใช้บริบทข้ามขั้น หรือต้องการความไว ยังทำเองเหมือนเดิม
- **brief ของลูกมือบอกสิ่งที่ตัดสินแล้วว่าตัดสินแล้ว** ลูกมือเป็นตัวเราอีกบริบทที่จำอะไรของเราไม่ได้เลย จึงต้องได้ข้อเท็จจริงที่ปิดแล้วและขั้นตอนเดียวที่ต้องการ พร้อมคำขอให้ตอบว่าพบอะไรและเสนออะไร
- **คำตอบของลูกมือมีรูปร่างเดียว** สรุปครั้งเดียวตอนจบ: ทำอะไรไป เจออะไร เหลืออะไร ไม่เล่าเป็นระยะระหว่างทาง เพราะตัวเมนอ่านคำตอบนั้นครั้งเดียว

## ความจำ: รูปร่างคำตอบเป็นเรื่องของโปรไฟล์

- **ความชอบเรื่องความยาวและรูปแบบถูกเก็บไว้ที่ผู้ใช้ ไม่ใช่ที่โต๊ะ** ความยาวคำตอบ จะได้ความเรียงหรือหน้าเว็บ งานเสนอต้องมีภาพไหม — ของพวกนี้เคยถูกเก็บเป็นความชอบของโต๊ะเดียว จึงได้ความเรียงยาวที่โต๊ะหนึ่งแล้วไม่ได้ภาพที่ขอไว้อีกโต๊ะหนึ่ง
- **ตอนนี้เก็บลงโปรไฟล์ที่ทุกโต๊ะ ทุกเอเจนต์ และทุกลูกมืออ่าน** และคำติงเรื่องรูปแบบของสิ่งที่ส่งกลับไปก็นับเป็นความชอบแบบนี้ ไม่ใช่ความผิดของงานครั้งนั้น

## ความมั่นใจของรุ่น

- เพิ่มชุดทดสอบการตรวจความน่าเชื่อถือ ครอบคลุมกรณีที่ต้นทางตอบ ที่ไม่ตอบ และสถานะที่ไม่ควรขึ้นเลขศูนย์
- เพิ่มชุดทดสอบการ์ดติดตั้ง ครอบคลุมแถว "จะทำอะไรได้" การเลือกผู้ใช้ และการพับชื่อเครื่องมือในแผงพรีเซ็ต
- เพิ่มชุดทดสอบมีเดียในแกลเลอรี ครอบคลุมคลิปและเสียงบนดิสก์ที่ไม่มี handoff และไฟล์ที่ต้องมี handoff
- เพิ่มชุดทดสอบที่มาของสกิล และการติดตั้งที่ปัก ref ไว้ รวมกรณี ref ที่หลุดขอบเขต
- เพิ่มชุดทดสอบขนาดแท็บที่ถูกซ่อนแล้วถูกยกกลับมา ว่าวางสี่เหลี่ยมด้วยการเปลี่ยนขนาดจริงและไม่ยึดโฟกัส
- เพิ่มชุดทดสอบงานที่มอบให้ลูกมือ ว่าคำตอบที่ส่งกลับไปยังโมเดลมีบรรทัดบอกรูปร่างของคำตอบ
