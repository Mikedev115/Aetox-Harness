# Aetox Mobile Android 0.3.19

รุ่นนี้ซ่อมสองอย่างที่เจอบนเครื่องจริง: ส่งรูปจากแกลเลอรีไปให้ PC ไม่ได้ (เลือกรูปเสร็จแล้วหน้าค้างเหมือนเดิม) และกดปุ่มถอยของ Android แล้วเด้งออกจากแอป

## มีอะไรใหม่

- **ส่งรูปและไฟล์จากแกลเลอรีได้แล้ว** — ช่อง "รูปภาพ" และ "ไฟล์" เลือกได้ทีละหลายไฟล์ ซึ่ง photo picker ของ Android 13 ขึ้นไปจะส่งผลกลับใน `ClipData` เสมอ แม้เลือกแค่รูปเดียว แต่ `FileChooserParams.parseResult` อ่านแค่ `getData()` หน้าจึงได้รายการว่าง และไม่มีอะไรเกิดขึ้นหลังเลือก · ตอนนี้แอปอ่าน `ClipData` เองก่อน ถ้าไม่มีค่อยถอยไปใช้ `parseResult`
- **ปุ่มถอยปิดสิ่งที่เปิดอยู่ก่อน** — หน้าเว็บของแอปไม่เก็บ history เลย `canGoBack()` จึงเป็น false ตลอด และแอปสั่ง `moveTaskToBack` ทุกครั้งที่กด · ตอนนี้แอปถาม `window.aetoxBack()` ของหน้าก่อน ซึ่งจะปิดชั้นบนสุดทีละชั้น (ตัวดูไฟล์ → โหมดเสียง → ชีต → เมนูข้าง → หน้า) และจะออกจากแอปก็ต่อเมื่อไม่เหลืออะไรให้ปิดแล้วเท่านั้น
- **ฝั่ง PC: รูปใหญ่ไม่โดนตัดกลางทาง** — `/api/upload` ได้เวลาอ่าน body 3 นาที แทน `ReadTimeout` 20 วินาทีที่ใช้ทั้ง server · รูปขนาดไม่กี่ MB ที่ส่งผ่านเน็ตมือถือและ relay ของ Tailscale อาจใช้เวลานานกว่า 20 วินาที

## ต้องใช้

Android 10 ขึ้นไป · ติดตั้งทับ 0.3.18 ได้ (คีย์เซ็นเดิม `c6330d76…`)

**การส่งรูปจากแกลเลอรีใช้ได้ทันทีที่ลงแอปรุ่นนี้** ส่วนปุ่มถอยและการส่งรูปใหญ่ต้องใช้ Aetox บน PC รุ่นถัดจาก 1.11.36 ด้วย เพราะหน้าเว็บและ gateway มากับโปรแกรมบน PC · ถ้า PC ยังเป็นรุ่นเก่า ปุ่มถอยจะทำงานเหมือน 0.3.18
