## แผง "เครื่องนี้" — สเปกจริงของเครื่องที่เปิดอยู่

- **เดิม** แถบ CPU ตอบได้แค่ว่าทั้งเครื่องเท่าไร Aetox เท่าไร คำถามที่ตามมา (RAM 32 GB หมดไปกับอะไร ดิสก์เหลือเท่าไร การ์ดจอใบไหน) ไม่มีที่ให้อ่าน
- **รุ่นนี้** ปุ่ม "ดูรายละเอียด" ท้ายป๊อปอัป CPU เปิดแผง "เครื่องนี้" ด้านขวาแบบเดียวกับ "ดูค่าใช้จ่าย" เป็นแท็บเดียวเปิดค้างคู่กับแชทได้ · อ่านของจริงจาก registry + kernel32 (คอร์/แคช · RAM/commit · ดิสก์ · การ์ดจอ · บอร์ด/BIOS · uptime · แบตเตอรี่ · อะแดปเตอร์ที่อัป) และ `/proc` กับ `/sys` บน Linux
- สเปกที่คงที่อ่านครั้งเดียวต่อโปรเซส (`sync.Once`) เหลือแค่ค่าที่ขยับอ่านซ้ำ และกราฟต่อคอร์มี RPC ของตัวเองที่แผงเรียกทุก 1 วินาที **เฉพาะตอนเปิดแผง** ปิดแท็บแล้วหยุดอ่านทันที — ข้อความท้ายแผงบอกตรง ๆ ว่าเป็นอย่างนั้น
- แก้ค่าที่เคยอ่านผิด: จอไม่ถูกคูณ DPI ซ้ำ (was 4480 × 2800 บนจอ 2560 × 1600 @175%) เพราะถาม DPI awareness ของโปรเซสก่อนคูณ · อะแดปเตอร์เสมือนที่ไม่มี MAC (Tailscale) เลิกรายงาน 100000 Mbps ซึ่งเป็นความเร็วที่ไม่เคยมีอยู่จริง
- แผงเลิกค้างที่ "กำลังอ่านฮาร์ดแวร์…" ตลอดกาล: สาเหตุคือ Svelte โยน `each_key_duplicate` จากกราฟต่อคอร์ที่ key ซ้ำ (สองคอร์ได้เปอร์เซ็นต์เท่ากัน) แล้วหยุดวาดทั้ง component · key เปลี่ยนเป็นลำดับคอร์แล้ว และสถานะรอเป็นโครงแผงพร้อมข้อความ "ยังไม่ได้คำตอบจากเอนจิน — กำลังลองอีกครั้งเอง" ถึงสามครั้งจึงขึ้นปุ่ม "ลองอีกครั้ง"
- **ไฟล์** `internal/machine/` · `desktop/frontend/src/lib/workbench/MachinePane.svelte` · `internal/engine/app.go` · `desktop/frontend/src/lib/stores/workbench.svelte.ts`

## `/ชื่อสกิล` ในช่องพิมพ์เปิด SKILL.md ให้เอเจนอ่านจริง

- **เดิม** เมนู "/" มีแต่ชุดคำสั่ง สกิลไม่อยู่ในลิสต์ และการพิมพ์ `/aetox-th-locale` เองไปถึงโมเดลเป็นข้อความเปล่า กลไก "เรียกสกิล" มีอยู่แล้วแต่ต่อสายไว้กับ CLI ไม่ถึงแชทของแอป
- **รุ่นนี้** ข้อความที่ขึ้นต้นด้วย `/name` ซึ่งไม่ใช่ preset จะเปิดเอกสารผ่าน `skill_view` แล้วแนบไว้ใต้บรรทัดของผู้ใช้ พร้อมแถว `skill_view` ในเทิร์น เอกสารที่ได้จึงเป็นใบเดียวกับที่โมเดลได้จากการเรียกเครื่องมือเอง · preset ยังชนะชื่อที่ซ้ำ และ `/...` ที่ไม่รู้จักยังผ่านไปเป็นข้อความเหมือนเดิม
- เมนู "/" ขึ้นกลุ่ม "สกิล" ก่อน "ชุดคำสั่ง" มีไอค่อนต่างกันตามที่เจ้าของเคาะ สกิลที่วางอยู่เดสก์อื่นขึ้นจางพร้อมป้าย → เดสก์ เลือกแล้วเติม `/ชื่อสกิล ` ลงช่องพิมพ์ · แชทที่ต่อ CLI ไม่แสดงกลุ่มนี้ เพราะ "/" ที่นั้นคือคำสั่งของ CLI
- ประโยคบอกทิศทางของสกิลย้ายมาไว้ที่เดียว (`internal/skill/invocation.go`) ทั้ง CLI และแอปจึงอ่านประโยคเดียวกัน
- **ไฟล์** `internal/engine/skill_invocation.go` · `internal/skill/invocation.go` · `desktop/frontend/src/lib/Palette.svelte` · `desktop/frontend/src/lib/stores/skills.svelte.ts`

## นำเข้าสกิล MCP hooks และโปรแกรมเอเจนจากแอปอื่นในครั้งเดียว

- **เดิม** นำเข้าได้แค่ MCP กับสกิล และกดทีละรายการผ่านแผงติดตั้ง · hooks ไม่มีทางเข้าเลย และโปรแกรมเอเจนที่ติดตั้งอยู่แล้วไม่มีใครสแกนหา
- **รุ่นนี้** แถบ "เจอในแอปอื่นบนเครื่องนี้" ในห้องความสามารถแบ่งเป็นกลุ่ม สกิล/MCP/Hooks/โปรแกรม มีติ๊ก มีแถบ "เลือก N จาก M" และปุ่ม "นำเข้าที่เลือก" นำเข้าทั้งชุดในครั้งเดียวและคืนผลทีละรายการ
- hooks อ่านจาก `~/.claude/settings.json` กับ `settings.local.json` แล้วแปลเป็นรูปของ Aetox (`Bash`→`shell`, `Write`/`Edit`→`change`, `Glob`/`Grep`→`search`) · hook ที่ matcher ระบุคำสั่งหรือจังหวะที่ Aetox ไม่มี (Stop, Notification) ขึ้นเป็นแถวแต่ติ๊กไม่ได้และบอกเหตุผล เพราะ hook คือคำสั่งที่รันทุก tool call
- โปรแกรมเอเจนหาเองบน PATH พร้อมบอกว่ามีไดรเวอร์ตัวไหน ตัวที่ยังไม่มีไดรเวอร์เป็นแถว "ยังไม่มีไดรเวอร์" ไม่ใช่ความเงียบ · ของที่ adapter รันอยู่แล้วไม่ถูกเสนอซ้ำ
- **ไฟล์** `internal/install/hooks.go` · `internal/install/programs.go` · `internal/engine/install_import.go` · `desktop/frontend/src/lib/room/Capability.svelte`

## เมนูฟอนต์อ่านฟอนต์ที่ติดตั้งใน Windows จริง

- **เดิม** ลิสต์ฟอนต์ในหน้าตั้งค่าเขียนตายตัวไว้สองรายการ ฟอนต์ที่ติดตั้งในเครื่องจึงไม่เคยขึ้นมาเลย
- **รุ่นนี้** อ่านรายชื่อตระกูลฟอนต์จากตารางฟอนต์ของ Windows (`EnumFontFamiliesEx`) ตัดตัวซ้ำ ตัดสำเนาแนวตั้ง '@' เรียงตามตัวอักษร และแคช 20 วินาที · เมนูมีช่องค้นหา จำกัด 60 แถวต่อกลุ่มพร้อมบรรทัดบอกจำนวนที่เหลือ (เครื่องนี้มี 310 ตระกูล) และพิมพ์ชื่อแถวด้วยฟอนต์ของตัวเอง
- ค่าที่เลือกเก็บเป็น `family:<ชื่อ>` แล้วประกอบสแต็กโดยให้ฟอนต์นั้นนำหน้าและ Noto Sans Thai ที่ฝังตามหลัง ฟอนต์ที่ไม่มีไทยจึงยังอ่านไทยได้ ไม่กลายเป็นกล่อง · เมนูขยายความกว้างเท่าที่ชื่อล้นจริง ไม่ตัดชื่อเป็น "…" อีก

## แชทไม่ค้างเพราะไฮไลต์โค้ดระหว่างสตรีม

- **เดิม** คำตอบที่กำลังสตรีมถูก render markdown ใหม่ทั้งก้อนทุกเฟรม และ highlight.js ทำให้ DOM โตตามความยาวโค้ด — 300 บรรทัด = 3,309 โหนด 251 ms/เฟรม · 900 บรรทัด = 9,909 โหนด 726 ms/เฟรม หน้าจอจึงไม่มีเวลาว่าง ในเคสจริง (6 เทิร์นพร้อมกัน ตัวหนึ่งวน tool 324 รอบ) renderer ไม่ตอบสนองและหน้าจอค้างถาวรจนต้องปิดแอป
- **รุ่นนี้** ระหว่างสตรีมบล็อกโค้ดวาดแบบ plain ไม่ไฮไลต์ (กรอบ หัวบล็อก ป้ายภาษา และปุ่มยังอยู่ครบ) สีขึ้นตอนคำตอบจบซึ่ง render ครั้งเดียว — วัดหลังแก้ 900 บรรทัดเหลือ 36 ms/เฟรม และคำตอบจบจ่าย 294 ms ครั้งเดียว
- ถ้า renderer ไม่ตอบสนองอีก แอปสร้าง view ใหม่เองหลังรอ 10 วินาที หน้าจอกลับมาโดยไม่ทิ้งเทิร์นที่ยังรันอยู่ (Wails v2.15 จัดการแค่ kind 0 กับ 1)
