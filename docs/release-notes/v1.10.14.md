# 🧩 Aetox v1.10.14

วันที่ 24 ตุลาคม 2026

**บริษัทของคุณมีชีพจรในหน้าจอ โฟลเดอร์ที่เดินอ่านเป็น Explorer จริง และวาดภาพในเครื่องได้เองด้วย ComfyUI หรือ Forge**

## บริษัทของฉันมีชีพจร และห้องบริษัทกลับมาเป็นแท็บในหน้าต่าง

- **เดิม** เวลามอบหมายงานให้เอเจน หน้า "บริษัทของฉัน" ไม่ขยับเลย การ์ดบริษัทบอกจำนวนแผนก/ทีม/เอเจนครั้งเดียวตอนเปิด งานที่กำลังทำไม่ขึ้นที่ไหน และห้องบริษัทอยู่บนพอร์ตอย่างเดียว เปิดดูหลังงานจบจึงเจอเวทีว่าง เพราะ fact ทุกตัวถูกส่งแล้วหายไป ไม่มีที่เก็บ
- **รุ่นนี้** การ์ดบริษัทมีสามตัวเลขที่ขยับตามงานจริง: **กำลังทำงาน · รอคำตอบ · วันนี้เสร็จ** ส่วน "กำลังทำงานตอนนี้" เป็นแถวละงานจากทุกแชท (ใคร งานอะไร แชทไหน เวลา) กดแล้วเปิดแชทนั้นได้เลย ถามทุก 3 วินาที หยุดเมื่อแท็บถูกซ่อน สองคำขอต่อรอบ ไม่มีคำขอต่อแถว และยังโชว์กระดานเดิมเมื่อเอนจินรีสตาร์ท ไม่ล้างจอ
- ห้องบริษัทเปิดเป็นการ์ดในแผงขวาของหน้าต่างได้ ไม่ต้องเปิดเบราว์เซอร์หรือพอร์ต และโหลดโมดูลห้องแบบ lazy (three.js ไม่เข้า startup chunk) ปิดแท็บแล้วคืนหน่วยความจำตามเดิม ส่วนหน้าเว็บบนพอร์ตยังใช้ได้สำหรับจอที่สอง และรับความจำชุดเดียวกับในแอป
- เอนจินจำงานได้แล้ว: fact ทุกตัวที่ห้องพูดถูกเก็บใน `office_facts` (ตาราง migration 72) และงานที่จบ — ทั้งเทิร์นของเอเจนและงานที่มอบหมาย — ถูกเก็บใน `office_work` เปิดห้องจึงเห็นสภาพจริง ไม่ใช่การเล่นซ้ำสถานะเก่า ข้อมูลตัดที่ 7 วัน เพดานสองหมื่นแถว และการเขียนเป็นแบบ best effort ไม่เปิดสโตร์เอง
- วันแรกที่ยังไม่มีความจำ "วันนี้เสร็จ" นับจากบันทึกงานเดิม (jobs) แทนที่จะขึ้น 0 ทั้งที่ทำงานมาทั้งวัน และไม่บวกซ้ำเมื่อความจำมีเลขของตัวเองแล้ว

## ไฟล์ที่เดินอ่าน: สามมุมมอง กรอง ปักหมุด และรูปย่อในแถว

- **เดิม** แถบไฟล์ด้านข้างมีอย่างเดียวคือต้นไม้รายการ ไม่มีขนาด ไม่มีวันที่ ไม่มีรูปย่อ และหาของในโฟลเดอร์ใหญ่ ๆ ต้องไล่ตาดู
- **รุ่นนี้** ตอนเดินอ่านโฟลเดอร์ สลับ **รายการ / รายละเอียด / ไอคอน** ได้ มุมมองรายละเอียดมีขนาดและวันที่แก้ไขล่าสุด ซึ่งอ่านจาก directory entry ที่โหลดมาแล้ว ไม่มีการ stat เพิ่มทีละแถว
- **Ctrl+F** เปิดช่องกรองชื่อ และแถวที่เป็นไฟล์ภาพมีรูปย่อจริง ด้านยาวไม่เกิน 320px หมุนภาพตาม EXIF ให้ถูก ฟอร์แมตที่รองรับ: png jpg gif webp bmp (svg ส่งไฟล์เดิมเพราะเวกเตอร์ไม่มีอะไรให้ย่อ) แก้ไฟล์ภาพแล้วเห็นภาพใหม่ทันที และไฟล์ที่วาดไม่ได้กลับไปใช้ไอคอน ไม่ใช่ภาพพัง
- ปักหมุดโฟลเดอร์ได้ ขึ้นบนสุดของ "ที่ใช้บ่อย"

ไม่ได้ทำ: ต้นไม้ของโปรเจกต์ยังเป็นรายการเดียว เพราะคอลัมน์ขนาด/วันที่ที่นั่นคือการ stat ต่อแถวของ 150,000 แถวที่ไม่มีใครได้ใช้

## สร้างภาพในเครื่อง: ComfyUI เป็นตัวหลัก พร้อม Forge / A1111

- **เดิม** ภาพทุกภาพต้องออกจากเครื่อง ผ่านเจ้าวาดบนคลาวด์แบบที่ตั้งค่าไว้ จะวาดเองในเครื่องก็ต้องสลับไปใช้เว็บของ Forge หรือ ComfyUI เอง แล้วลากไฟล์กลับเข้ามา
- **รุ่นนี้** หน้าผู้ให้บริการ › สร้างภาพ มีสองแถวในเครื่อง **ComfyUI** (ค่าเริ่มต้น `http://127.0.0.1:8188`) และ **Stable Diffusion WebUI** สำหรับ Forge / Forge Neo / A1111 (`http://127.0.0.1:7860`) ทั้งคู่จัดอยู่เหนือเจ้าบนคลาวด์
- ComfyUI ส่ง workflow แบบ API ไปที่ `/prompt` ถาม `/history` จนเสร็จ แล้วโหลดรูปจาก `/view` ใช้ workflow "FLUX.2 Klein 4B Distilled" ที่ติดมากับแอป หรือเลือกไฟล์ workflow ของตัวเอง (Export (API)) ได้ — prompt ลง node ที่ต่อเข้า positive ขนาดลง node ที่มี width+height seed ลง seed, โมเดลที่เลือกลง loader ไฟล์ที่ไม่มีที่ใส่ prompt ถูกปฏิเสธตอนเลือกพร้อมเหตุผลภาษาไทย รายชื่อโมเดลถามจาก `/object_info` ของ loader ใน workflow
- Forge / A1111 ใช้ `/sdapi/v1` ซึ่งมีเหมือนกันเมื่อเปิดด้วย `--api` โมเดลที่ pin ส่งเป็น `override_settings` ของคำขอนั้นแล้วคืนค่าเดิม ถ้า server ปิดอยู่ บอกให้เปิดด้วย `--api` และตัวสำรองวาดแทนได้
- **400 จาก `/prompt` บอก node ที่ผิด** run ที่ล้มบอก exception และกดหยุดแล้วถอนงานออกจากคิวหรือ interrupt ให้
- วัดบน RTX 5050 8 GB กับ FLUX.2 klein 4B fp8: ครั้งแรก 69 วินาที (รวมโหลดโมเดล) ครั้งต่อไป 1.9 วินาที
- คู่มือติดตั้งทั้ง ComfyUI และ Forge Neo อยู่ในซอร์สที่ `docs/LOCAL-IMAGES.md` (ไทย + อังกฤษ)

ยังไม่ได้ทดสอบกับ ComfyUI ตัวจริงบนเครื่องนี้ ส่วนเทสต์ของทั้งสองเจ้ารันกับ server จำลอง

## สร้างภาพ: Pollinations ฟรีเข้าคิวทีละภาพ และการ์ดภาพไม่โกหก

- Pollinations แบบไม่มีคีย์วาดได้ 1 ภาพต่อ 45 วินาที รุ่นนี้ทุกการเรียกเข้าคิวเดียวกัน เจอ 402/429 ที่บอก Retry after จะรอแล้วลองใหม่หนึ่งครั้ง ถ้ายังไม่ผ่านบอกเป็นประโยคไทย ไม่ใช่รหัส
- `image_make` ที่ได้ `for` เป็นคำบรรยาย ไม่มีนามสกุลไฟล์ ไม่ถูกตีความเป็นชื่อไฟล์อีก ภาพลงที่ path ที่ขอ และภาพที่ลงใน `imgs/` ของโปรเจกต์เก่าแสดงในแชทได้แล้ว
- การ์ดภาพที่ถูกลบไปแล้วไม่ขึ้นว่ายังอยู่ และเลือกเจ้าวาดกับตัวสำรองได้ระหว่างที่แชทกำลังทำงาน (เดิม dropdown ดีดกลับไปค่าเก่า)

## ลิงก์ในแผน รายงาน และคู่มือ ไม่พาทั้งหน้าต่างไป 404

- **เดิม** มีแต่แชทกับหน้าจอไฟล์ที่ดักลิงก์ Markdown หน้าอื่น (แผน รายงาน artifacts คู่มือ หน้าบริษัท) ปล่อยให้ webview เปิดเอง ซึ่งแก้ path สัมพัทธ์กับ `wails.localhost` ลิงก์อย่าง `dist/....zip` จึงกลายเป็นหน้า 404 ทับทั้งหน้าต่าง
- **รุ่นนี้** ตัวดักลิงก์ทำงานครั้งเดียวทั้งเอกสาร และดักเฉพาะลิงก์ในเนื้อหา Markdown คลิกกลางใช้ทางเดียวกัน ไม่เปิดหน้าต่างใหม่ของ WebView2 คลิกขวาไม่ถูกแตะ
- ไฟล์ที่เอเจนสร้างด้วยคำสั่ง shell ไม่มีใบเสร็จการเขียนไฟล์ แชทจึงลิงก์ให้ไม่ได้ การ์ดไฟล์นั้น **คัดลอก** ไฟล์ลง Downloads ของเครื่องนี้ (ไม่ย้าย) แล้วให้เปิด / เปิดโฟลเดอร์ / เซฟซ้ำ ถ้าเอนจินอยู่บนเครื่องอื่น การ์ดนี้ไม่ขึ้น เพราะไฟล์ไม่ได้อยู่บนดิสก์นี้

## เปลี่ยนอื่น ๆ ในรุ่นนี้

- รูปที่เปิดบนโต๊ะลากไม่ได้แล้ว เดิมลากแล้วแอปไม่ตอบเมาส์เลย เพราะ Chromium ทำให้ `<img>` เป็นต้นทางลากเองและไม่วาด pointer ระหว่างลาก
