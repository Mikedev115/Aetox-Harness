# 🪟 Aetox v1.11.4

วันที่ 11 พฤศจิกายน 2026

**รุ่นนี้เก็บงานแก้ที่ค้างอยู่บน `main` ตั้งแต่ v1.11.3 มาครบห้าเรื่อง — การ์ดเซิร์ฟเวอร์ที่ต้องเข้าสู่ระบบมีปุ่มให้กดจริง, กดแชทใหม่ระหว่างแชทเก่ากำลังโหลดไม่ถูกทับ, ปุ่มส่งกับปุ่มหยุดกลับมาอยู่ช่องเดียว, คอนโซลอ่านขนาดจอจริงและจอเตี้ยไม่กินบรรทัดที่พิมพ์, และการ์ดติดตั้งสกิลไม่ถูกตัดเพราะโต๊ะไม่ได้ถือ GitHub**

## การ์ดที่ต้องเข้าสู่ระบบมีปุ่มให้กดแล้ว

- **เดิม** การ์ดของเซิร์ฟเวอร์ที่ต้องเข้าสู่ระบบ (เช่น `cloudflare-api`, `linear`, `miro`) มีปุ่มเดียวชื่อ "เพิ่มขึ้นชั้นวาง" ซึ่งบอกการบันทึก ไม่ได้บอกขั้นเบราว์เซอร์ และกดแล้วชีตปิดทันที ความคืบหน้าไปแสดงที่แถวของห้องสมุดซึ่งอาจอยู่คนละหน้า
- **รุ่นนี้** การ์ดที่ต้องเข้าสู่ระบบใช้คำว่า **"เชื่อมบัญชี {name}"** และกดแล้วชีตไม่ปิด: แสดง "กำลังลงทะเบียน Aetox กับ …" หรือ "กำลังรอการอนุมัติในเบราว์เซอร์…" พร้อมปุ่มเปิดหน้าเดิมอีกครั้งและยกเลิก ถ้าล้มเหลวข้อความกับปุ่ม "ลองอีกครั้ง" อยู่ในชีตเดียวกัน ปิดชีตเมื่อบันทึกสำเร็จเท่านั้น การ์ดที่ไม่ต้องล็อกอินยังใช้ "เพิ่มขึ้นชั้นวาง" ตามเดิม
- **ไฟล์** `Capability.svelte` · `locales/th.ts` · `locales/en.ts` · `locales/zh.ts` (คีย์ใหม่ `capability.connectAccount`) · `test/capabilityRoom.test.ts` (เพิ่ม 2 เคส)

## กดแชทใหม่ระหว่างแชทเก่ากำลังโหลดไม่ถูกทับด้วยแชทเดิม

- **เดิม** ทุกประตูของแชทใหม่ (แถวรางซ้าย ดินสอ Ctrl+N พาเลต) ลงที่ `newSession → newSessionAt → moveModelCursor` และเจอสองทางที่การกดหายไป: คำตอบของ `OpenSession` ที่มาถึงทีหลังวาดแชทที่กดไว้ทับแชทใหม่ และคำสั่งโมเดลที่เครื่องยนต์เก่าไม่ตอบค้างข้ามการกดทุกครั้งไปตลอดการเปิดแอป
- **รุ่นนี้** เปิดแชทใหม่แล้วตัดคิวสลับที่ยังค้างและเลื่อนตั๋วให้คำตอบเก่ากลายเป็นของเก่า และเมื่อเครื่องยนต์ถูกเปลี่ยน คิวที่ cursor move รออยู่ถูกปลด การกดจึงไปต่อได้
- **ไฟล์** `stores/cockpit.svelte.ts` · `test/newChatCases.test.ts` (เพิ่ม)

## ปุ่มส่งกับปุ่มหยุดอยู่ช่องเดียวกัน

- **เดิม** ปุ่มหยุดยืนเป็นวงกลมแดงอีกใบทางซ้ายของปุ่มส่ง แถวจึงมีสามก้อน และจุดที่นิ้วกดส่งไม่ใช่จุดที่นิ้วกดหยุด
- **รุ่นนี้** ช่องเดียว 36px เปลี่ยนหน้าเอง — กำลังทำงานและกล่องว่าง = หยุด, มีข้อความ = ส่ง, ว่าง = ส่งจาง · หลังกดส่ง 700 ms ช่องเดิมยังกดไม่ติด ดับเบิลคลิกจึงไม่ฆ่าเทิร์นที่เพิ่งเริ่ม · Esc เป็นเบรกขณะเทิร์นรัน และมาก่อน Escape ตัวอื่นในคอมโพสเซอร์
- **ไฟล์** `Chat.svelte` · `style.css` · `test/composerBrake.test.ts` · `test/queuedMessages.test.ts`

## คอนโซล: ขนาดจอมาจากคอนโซลจริง และจอเตี้ยไม่กินช่องพิมพ์

- **เดิม** ในแท็บเทอร์มินัลของแอป `tea.WindowSizeMsg` พาเอาความกว้างของ screen buffer มาแทนความกว้างหน้าต่าง เฟรมที่กว้างกว่าจอหนึ่งช่วงทำให้เทอร์มินัลตัดบรรทัดเองและทิ้งสำเนาฟุตเตอร์ไว้ใน scrollback ทุกเฟรม · บนจอ 8 แถว การกด `/` ดันฟุตเตอร์สูง 10 แถว จนแถวบนที่กำลังพิมพ์ถูกตัดหาย
- **รุ่นนี้** `consoleSize` ถาม `term.GetSize` และ tick ทุก 500 ms ส่งขนาดเมื่อเปลี่ยนเท่านั้น renderer จึงได้ความกว้างเดียวกับที่โมเดลวาด · เมนูได้แถวเท่าที่เหลือหลังช่องพิมพ์กับแถบสถานะ และส่วนล่างทั้งหมดถูกจำกัดไม่ให้เกินความสูงจอ
- **ไฟล์** `internal/tui/size.go` (เพิ่ม) · `internal/tui/model.go` · `internal/tui/view.go` · `internal/tui/complete.go` · `size_test.go` · `screen_test.go` · `program_test.go`

## การ์ดติดตั้งสกิลไม่ถูกตัดเพราะโต๊ะไม่มี GitHub

- **เดิม** `plugin_install` ถูกนับเป็นเครื่องมือของ GitHub ใน catalog การเชื่อมต่อ ทุกโต๊ะและทุกเอเจนที่ไม่ได้ถือ GitHub จึงถูกตัดทั้งตัว ทั้งที่มันอ่านรีโปสาธารณะได้โดยไม่ต้องใช้บัญชี และทุกครั้งที่เขียนลงเครื่องคือการ์ดที่คนกดเอง
- **รุ่นนี้** `plugin_install` ไม่ถูก gate ด้วย connection GitHub แล้ว ส่วน `github_search` และเครื่องมือของบัญชียังถูก gate ตามเดิม
- **ไฟล์** `internal/connect/connect.go` · `internal/connect/connect_test.go`
