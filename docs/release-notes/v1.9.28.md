# 🧩 Aetox v1.9.28

วันที่ 17 ตุลาคม 2026

**รุ่นที่ทำให้มือถือใช้งานได้จริง: คำตอบไหลบนมือถือระหว่างที่เขียน เห็นทุกแชทและทุกไฟล์ที่เอเจนต์ทำ และแอปมือถืออัปเดตตัวเองจากเครื่องนี้**

## คำตอบบนมือถือไหลลื่น

- **เดิม** มือถือดึงข้อมูลแชทใหม่ทั้งก้อนทุกวินาที คำตอบเลยโผล่มาเป็นก้อน ๆ ประโยคที่เอเจนต์พูดก่อนเรียกเครื่องมือหายไปทั้งประโยค และระหว่างที่เอเจนต์ค้นเว็บ มือถือขึ้นแค่ "กำลังคิดคำตอบ…" ค้างไว้
- **รุ่นนี้** เครื่องนี้ส่งเทิร์นที่กำลังรันให้มือถือแบบสด (`/api/live`) ทั้งคำตอบที่กำลังเขียน ประโยคที่พูดก่อนเรียกเครื่องมือ ขั้นตอนเครื่องมือแต่ละขั้น และสถานะ มือถือที่เปิดแชทกลางทางก็เห็นเทิร์นนั้นครบตั้งแต่ต้น
- ข้อความบนมือถือค่อย ๆ ไหลออกมาแทนการโผล่เป็นก้อนตามจังหวะเน็ต จากการจำลองเน็ตที่กระตุก ข้อความเคยโผล่ทีละสูงสุด 70 ตัวอักษร เหลือไม่เกิน 15 ตัวอักษร และไม่หยุดคั่นระหว่างพยัญชนะไทยกับสระหรือวรรณยุกต์
- การแจ้งให้มือถือโหลดใหม่ส่งเฉพาะตอนที่ข้อมูลเปลี่ยนจริง ไม่ใช่ทุกวินาที มือถือเลยไม่วาดรายการแชทใหม่ระหว่างที่นิ้วกำลังกดหรือเลื่อนอยู่

## มือถือเห็นทุกแชทและทุกไฟล์

- **เดิม** สิทธิ์ของมือถือเป็นรายการแชทที่ล็อกไว้ตอนจับคู่ มือถือที่จับคู่แบบค่าเริ่มต้นเห็นแค่แชทที่ตัวเองสร้าง แชทที่เปิดบน PC ทีหลังไม่ขึ้นเลย และรายการโปรเจกต์ก็ว่างตามไปด้วย
- **รุ่นนี้** มีสิทธิ์ "ทุกแชท" ซึ่งเป็นค่าเริ่มต้นตอนจับคู่ เครื่องที่จับคู่ไว้แล้วเปิดสิทธิ์นี้ได้ที่หน้า "มือถือ" บน PC โดยไม่ต้องจับคู่ใหม่ แชทของ helper ทีม และเลขายังไม่ขึ้นเหมือนเดิม
- ลิ้นชักบนมือถือสลับได้ระหว่าง "ล่าสุด" กับ "โปรเจกต์"
- ไฟล์ที่เอเจนต์ส่งมอบขึ้นเป็นการ์ดใต้คำตอบ และขึ้นทันทีตั้งแต่เอเจนต์ยังทำงานอยู่ หัวแชทมีปุ่มไฟล์พร้อมจำนวน ไฟล์เปิดเต็มจอได้ทั้ง Markdown ข้อความ โค้ด รูป วิดีโอ และเสียง สลับดูแบบตัวอย่างหรือซอร์สได้ ปัดเพื่อดูไฟล์อื่นของแชทนั้น
- หน้าเว็บและสไลด์ที่เอเจนต์ทำเปิดบนมือถือในกรอบ sandbox ที่ไม่มี cookie เรียก API ของเครื่องนี้ไม่ได้ และส่งข้อมูลออกเองไม่ได้
- ส่งรูปหรือไฟล์อย่างเดียวโดยไม่พิมพ์อะไรประกอบได้ และฟองข้อความแสดงชื่อไฟล์แทนบรรทัดที่เขียนไว้ให้เอเจนต์อ่าน
- **ยังไม่มาในรุ่นนี้** PDF ยังเปิดในแอปมือถือไม่ได้ (บันทึกแล้วเปิดด้วยแอปอื่น) และยังดูหน้าเบราว์เซอร์ที่เอเจนต์กำลังใช้จากมือถือไม่ได้

## Aetox Mobile 0.3.1 มากับรุ่นนี้

- **เดิม** แอป Android ไม่รู้เวอร์ชันของตัวเอง และส่วนติดตั้งถูกซ่อนไว้ในแอป APK ใหม่จึงต้องโหลดแล้วติดตั้งเอง
- **รุ่นนี้** build ของ Windows มี APK 0.3.1 ติดมาด้วย แอปบอกเวอร์ชันของตัวเองให้เครื่องนี้รู้ ขึ้นแถบ "มีแอปรุ่นใหม่ · อัปเดต" เมื่อเครื่องนี้มีรุ่นที่ใหม่กว่า กดแล้วแอปโหลด APK จากเครื่องนี้ ตรวจ SHA-256 ให้ตรงกับที่ประกาศไว้ แล้วเปิดหน้าติดตั้งของ Android ซึ่ง Android ยังถามยืนยันทุกครั้ง
- รายชื่อโมเดลบนมือถือตรงกับดาวที่ติกไว้บน Windows ผู้ให้บริการที่มีดาวขึ้นก่อน และโมเดลที่ปิดไว้ไม่แสดง
- หน้าตั้งค่ามือถือกระชับเป็นรายการเดียว ธีมเลือกจากแผ่นที่แบ่งมืดกับสว่าง ภาษาเป็นปุ่ม ไทย | English แทนช่องเลือกของระบบ แถบสถานะกับแถบปุ่มด้านล่างเปลี่ยนสีตามธีม หน้าเชื่อมต่อใช้สีของ Aetox แทนสีเขียวเดิม และลิ้นชัก หน้าต่าง ๆ กับแผ่นด้านล่างเลื่อนออกตอนปิดด้วย
- รายละเอียดอยู่ใน [Aetox Mobile 0.3.0](mobile-0.3.0.md) และ [0.3.1](mobile-0.3.1.md) ยังไม่ได้ลองแชร์ไฟล์ อัปเดตในแอป และสีแถบระบบบนมือถือจริง

## การเปลี่ยนแปลงอื่นในรุ่นนี้

- หน้า "มือถือ" บน PC แก้สิทธิ์ของเครื่องที่จับคู่แล้วได้ที่แถวของเครื่องนั้น
- เครื่องนี้บอกเวอร์ชัน APK ที่ติดมาใน `/install/meta` เฉพาะเมื่อ SHA-256 ในไฟล์ build ตรงกับ APK ที่ส่งจริง
