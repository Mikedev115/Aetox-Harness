# 🪟 Aetox v1.11.9

วันที่ 12 พฤศจิกายน 2026

**รุ่นนี้แก้เรื่องที่รูปแบบการทำงานเคยหายไปจากพรอมป์ต์: พรอมป์ต์ถือสารบัญของทุกใบ และขั้นตอนของเรื่องที่เทิร์นนั้นเกี่ยวกับแนบไปกับเทิร์นนั้นแทน · แผงสมองบอกว่าโมเดลเห็นกี่ใบ และไม่ซ่อนใบที่อนุมัติแล้ว · แผงบริบทเลิกนับกฎโปรเจกต์ซ้ำในก้อนคำสั่งระบบ**

## รูปแบบการทำงาน — พรอมป์ต์ถือสารบัญ ขั้นตอนมาเฉพาะเทิร์น

- **เดิม** ทุกใบแชร์เพดาน 1.5 KB ก้อนเดียว ใบที่รอดจึงเป็นสองสามใบแรกตามลำดับไฟล์ ไม่ใช่ใบที่เทิร์นนั้นเกี่ยวกับ ส่วนที่เกินถูกทิ้งเงียบ ๆ — หน้าจอขึ้น "ใช้อยู่ 25 ใบ · ส่งได้ 3 ใบ · อีก 22 ใบไม่มีที่" ทั้งที่อนุมัติครบทุกใบ
- **รุ่นนี้** พรอมป์ต์ถือสารบัญสั้น ๆ `- routes/<slug>` หนึ่งบรรทัดต่อใบ (เพดาน 6 KB) ส่วนขั้นตอนของใบไหนแนบไปกับข้อความของเทิร์นที่เกี่ยวกับเรื่องนั้น สูงสุด 2 เรื่อง ครั้งละไม่เกิน 1500 ตัวอักษร — กลไกเดียวกับสาขาของความจำเรื่อง "เกี่ยวกับคุณ" คำสั่งระบบจึงไม่ขยับและ cache ไม่แตก
- ใบที่ถูกแนบไปแล้วในแชทนั้นไม่ถูกแนบซ้ำจนกว่าจะถูกแก้ · เทิร์นที่ไม่เกี่ยวกับเรื่องไหนไม่พาอะไรไปเลย
- แต่ละใบมีคำที่ทำให้มันถูกโหลด (ฟิลด์ `words:` ในไฟล์ของใบ) ใบที่เขียนไว้ก่อนมีฟิลด์นี้ยังใช้ได้ด้วยการเทียบ slug กับชื่อโปรเจกต์
- แก้ใบที่โมเดลเขียนไม่ตรงงานได้จากแผง: ปุ่ม "แก้ไข" ต่อแถวเปิดฟอร์มชื่อกับขั้นตอนที่บันทึกจริง ใช้ฟิลด์ `.project-card-edit` ของแอปเดิม ไม่ได้เพิ่มหน้าจอใหม่
- **ไฟล์** `internal/journal/` · `internal/engine/routes_note.go` · `internal/engine/journal.go` · `BrainPanel.svelte` · `locales/{th,en,zh}.ts`

## แผงสมองบอกว่าโมเดลเห็นกี่ใบ และไม่ตัดใบที่อนุมัติแล้ว

- **เดิม** แถวที่สองเขียนว่า "สารบัญในพรอมป์ต์ …" ซึ่งเป็นคำที่ตั้งขึ้นตอนทำกลไก ไม่ใช่คำที่คนอ่านใช้ และแถว "รออนุมัติ 0 / 8" ที่ไม่มีอะไรค้างยังวาดแถบเปล่าไว้เหมือนหน้าจอยังโหลดไม่เสร็จ
- **เดิม** เพดาน 8 ใบของ "คำถามที่ยังไม่ได้ตอบ" ถูกใช้ตัดทั้งลิสต์ ใบที่อนุมัติแล้วจึงหายไปหลังใบที่แปด และปุ่ม "ดูทั้งหมด" ขึ้นให้กดทุกครั้งทั้งที่เป็นข้อเท็จจริงที่ควรเห็นครบ
- **รุ่นนี้** แถบอ่าน "โมเดลเห็น N ใบ · x / 6.0 KB" กับคำอธิบาย "ขั้นตอนจะแนบไปเมื่อถามถึงเรื่องนั้น" และเมื่อมีใบเกินเพดานบอกตรง ๆ ว่า "อีก R ใบยังไม่ถึงโมเดล (ไฟล์อยู่ที่ routes/)"
- แถวรออนุมัติวาดเฉพาะเมื่อมีการ์ดรออยู่จริง · เพดานตัดเฉพาะใบที่รอคำตอบ ใบที่อนุมัติแล้วเห็นครบทุกใบ และปุ่ม "ดูทั้งหมด" ขึ้นเฉพาะเมื่อมีคำถามถูกซ่อนจริง
- **ไฟล์** `BrainPanel.svelte` · `locales/{th,en,zh}.ts`

## แผงบริบทนับตามเจ้าของ — กฎโปรเจกต์ไม่ถูกหักจากคำสั่งระบบ

- **เดิม** กฎโปรเจกต์กับ Git snapshot ถูกส่งเป็นข้อความของผู้ใช้ แต่ตัวนับแบ่งไบต์ชุดเดียวกันนั้นจากก้อน system ด้วย ไบต์จึงถูกนับซ้ำใน "ข้อความสนทนา" ขณะที่ "System prompt" เหลือแต่เศษ — บนโปรเจกต์นี้เหลือ 74 โทเคนจากคำสั่งระบบจริงราว 3.3k
- **รุ่นนี้** แต่ละส่วนของพรอมป์ต์บอกได้ว่าเป็นของ "คำสั่งระบบ" หรือบริบทที่แนบมากับข้อความ และ ledger, ชื่อผู้ใช้, วิธีทำงาน, โฟลเดอร์ที่ผู้ใช้เชื่อม และสารบัญสาขาความจำ บันทึกเป็นส่วนใต้กลุ่มตัวตนของตัวเอง
- แถว "ข้อความสนทนา" มีแถวย่อยบอกว่ากฎโปรเจกต์กับ Git แนบมาเท่าไร พร้อมแถว "บทสนทนา" ที่เหลือ — ผลรวมยังเท่าเดิม ไม่มีไบต์หายหรือเพิ่ม
- ชื่อเดิม "System prompt" เปลี่ยนเป็น "คำสั่งระบบ" (อังกฤษ "Engine instructions") ทั้งสามภาษา
- **ไฟล์** `internal/prompt/prompt.go` · `internal/model/prompt_part.go` · `internal/engine/project_context.go` · `Chat.svelte` · `locales/{th,en,zh}.ts`
