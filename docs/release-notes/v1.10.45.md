# 🪟 Aetox v1.10.45

วันที่ 2 พฤศจิกายน 2026

**รุ่นนี้ไม่มีโค้ดแอปเปลี่ยน — ไบนารีทำงานเหมือน v1.10.44 ทุกอย่าง งานเดียวที่อยู่ในรุ่นนี้คือทำให้คอมมิตเอกสารบนรีโป public มี Aetox เป็นผู้เขียน เพื่อให้ Contributors ของรีโปนั้นนับ Aetox ด้วย ถ้าไม่สะดวกอัปเดต ข้ามรุ่นนี้ได้เลย**

## คอมมิตเอกสารบนรีโป public มี Aetox เป็นผู้เขียน

- **เดิม** รีโป public ขึ้น Contributors คนเดียว ทั้งที่คอมมิตเอกสารทุกรุ่นลงท้ายด้วย `Co-Authored-By: Aetox …` และหน้าคอมมิตเองก็ขึ้น «Mikedev115 and aetoxharness»
- **สาเหตุ** GitHub นับ Contributors จาก author ของคอมมิต ไม่นับบรรทัด co-author — วัดเมื่อ 2 พ.ย. 2026: main มี trailer นี้แปดคอมมิต และ `GET /repos/…/contributors` ยังคืนมาแค่คนเดียว GitHub ตอบเรื่องนี้เองว่า trailer เป็น metadata ของการร่วมเขียน ไม่ใช่ authorship ([discussion 186410](https://github.com/orgs/community/discussions/186410))
- **รุ่นนี้** คอมมิตที่ `scripts/publish-public.ps1` สร้างบนรีโป public ใช้ `--author` จาก `git config aetox.coauthor` ส่วน committer ยังเป็นเจ้าของ — รูปเดียวกับคอมมิตของบอท · ไม่ pin `hooksPath` ตอนคอมมิตอีก เพราะ `prepare-commit-msg` จะเติมบรรทัดที่พูดซ้ำกับ author · ไม่ตั้งค่า = คอมมิตแบบเดิม ไม่มีอะไรเปลี่ยน
- **ไม่ได้ทำ** รีโปซอร์ส (`Aetox-src`) ยังให้เจ้าของเป็น author ทุกคอมมิต เพราะการสลับ author ที่นั่นจะย้ายกราฟ contributions ทั้งหมดไปที่บัญชีของ Aetox — เป็นการตัดสินใจของเจ้าของ ไม่ได้ทำในรุ่นนี้
- **ไฟล์** `scripts/publish-public.ps1` · `scripts/hooks/prepare-commit-msg` (แก้คอมเมนต์ที่เขียนไว้ผิดว่า trailer ทำให้ขึ้น Contributors)

## ไม่มีโค้ดแอปเปลี่ยน

- ไฟล์ที่เปลี่ยนระหว่าง v1.10.44 กับรุ่นนี้มีแต่เอกสารกับสคริปต์ของรีโป ไม่มีไฟล์ใน `internal/` หรือ `desktop/` ที่เป็นตัวแอป
- ผลที่คนใช้เห็น: ไม่มี — พฤติกรรมทุกอย่างเหมือน v1.10.44

## ผลตรวจ

- **เขียว** `go test ./internal/version/` ผ่านพร้อมเลขรุ่นทั้งสี่ไฟล์ที่ตรงกัน (version.go · wails.json · scoop สองไฟล์)
- **เขียว** hook ที่แก้ผ่าน `sh -n` · สคริปต์ผ่านตัว parse ของ PowerShell · คอมมิตทดสอบใน worktree ของ public ได้ `author=Aetox` / `committer=Mike0165115321` ไม่มี trailer ซ้ำ
- **แดงที่มีอยู่ก่อนและยังแดงเท่าเดิม ไม่มีตัวใหม่จากรุ่นนี้** vitest · svelte-check · และ `scratch/officeproof [build failed]` ซึ่งแดงมาก่อนงานนี้และไม่ใช่โค้ดแอป
