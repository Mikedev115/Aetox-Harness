# 🧩 Aetox v1.9.21

วันที่ 12 ตุลาคม 2026

**ห้องตัดมีประวัติถาวรและงานเบื้องหลัง วันของผู้ช่วยมีปฏิทิน บอร์ดไอเดีย และรออ่าน และเอเจนเห็นโต๊ะที่คุณกำลังดูอยู่**

## ห้องตัด

- ประวัติการแก้ไขเก็บบนดิสก์ รีสตาร์ตแอปแล้วยัง undo/redo ต่อได้
- งานยาว (ถอดเสียง เรนเดอร์) รันเบื้องหลังพร้อมความคืบหน้า และยกเลิกได้
- ไทม์ไลน์มีมาร์กเกอร์ ripple cut การตัดต่อเสียง การฟังคลิป เวฟฟอร์ม และพร็อกซี
- เริ่มงานเปล่าได้เลย ตัดคำเติมได้ ดูคลิปต้นทางก่อนวาง และถอดเสียงไฟล์ยาวได้
- สร้างซับให้ทุกคลิปเสียงบนไทม์ไลน์ เรียงตามเวลาที่เล่น

## วันของผู้ช่วย: ปฏิทิน ไอเดีย รออ่าน

- ปฏิทินใหม่ วัน สัปดาห์ เดือน ปี สร้าง block และ deadline บนตารางได้ เปิดที่วันนี้ไปข้างหน้า เชื่อมแอปปฏิทินได้จากฟันเฟือง
- บอร์ดไอเดียแบบ Notion ร่างจากความจำ มีแผนที่ไอเดียที่เห็นว่าอันไหนต่อกับอะไร หน้างานเปิดจากหน้าเริ่มต้นกับปฏิทินได้
- รออ่าน: วางลิงก์ไว้ ผู้ช่วยอ่านและสรุปให้ก่อน
- ผู้ช่วยตั้งกำหนดส่งตามที่คุณบอกแล้วเลื่อนเองไม่ได้
- ทีม: เอาเลขาออก ผู้ช่วยกับโค้ดส่งงานให้ทีมเอง

## เอเจนเห็นโต๊ะ

- ทุกหน้าบนโต๊ะบอกสิ่งที่ผู้ใช้กำลังดูให้เอเจนรู้เอง และเอเจนยืมเครื่องมือตัดตอนห้องตัดเปิด
- มือผู้ช่วย: แสดงจุดที่เอเจนต์เพิ่งทำงานบนแผงงานและแชตทันที
- ห้องตรวจ: ผลของ test และ build ที่เอเจนต์รัน ผ่านไหม พังตรงไหน

## แชทและเครื่องมือ

- การรันเครื่องมือแสดงตามลำดับจริงและบอกงานที่รอคิว แทนที่จะบอกว่ารันขนานกัน
- ป้ายสถานะคำขอโมเดลบอกว่ากำลังเขียนคำตอบหรือเตรียมขั้นต่อไป
- คำตอบจากเทิร์นที่แค่อ่านไม่ถูกส่งกลับว่างานยังไม่เสร็จ
- dropdown ตัวเดียวทั้งแอป (`lib/Dropdown.svelte`) แทน `<select>` ทุกหน้า
- เอาชิปเลือกเชลล์ข้างช่องพิมพ์ออก เอเจนเลือกใช้ WSL เองทีละคำสั่ง

## โมเดลและผู้ให้บริการ

- ผู้ให้บริการเสียง ภาพ วิดีโออยู่ในหน้าการตั้งค่าโมเดล มีตัวกรองตามงาน
- หน้าตั้งค่าสร้างวิดีโอ: คนพูด กับ คลิป และผู้ให้บริการวิดีโอครบชุด
- ปลายทางที่เพิ่มเองเลือกได้ว่าใช้ทำอะไร ถอดเสียง อ่านออกเสียง วาดภาพ ไม่ใช่แค่แชท
- โมเดลของเอเจนทั้งหมดเป็นคำถามเดียวสามคำตอบ
- ผู้ให้บริการเสียงและภาพมีโลโก้ครบ ตารางการใช้งานแยกตามโมเดลมีโลโก้ และช่องความถี่มีไทม์ไลน์หนึ่งปี

## CLI ภายนอก

- Antigravity ขออนุญาตผ่านการ์ดของ Aetox ไม่หยุดหลังเครื่องมือแรก
- Claude Code แสดง error จริง กู้แชตที่ CLI หา session ไม่เจอ และรับงานเบื้องหลัง
- OpenCode ACP ไม่ตายเพราะฐานข้อมูลชนกัน
- แชตแจ้งเหนือช่องพิมพ์เมื่อ CLI ยังไม่ได้เข้าสู่ระบบ พร้อมปุ่มเข้าสู่ระบบ
- agy ที่ Aetox เปิดไม่อัปเดตตัวเอง หน้าต่างคอนโซลไม่เด้งมาทับแอป

## อื่น ๆ ในรุ่นนี้

- แสดงคู่: สลับระหว่างสองแชทแค่ย้าย cursor ไม่โหลดใหม่
- git: แจ้งและให้ลองใหม่เมื่อโหลด diff ค้าง แทนหมุนรอตลอดไป
- สกิลใหม่ `aetox-self-brief` และจับคู่ diff ไฟล์ใหญ่แม้แก้ไขห่างกัน
- บอต: ทักครั้งแรกตอน pair และเมนูคำสั่งสั้นลง
- ตัวอวาตาร์ไม่หายตอนลากบนเดสก์ท็อป
- เครื่องนี้ไม่ค้างตอนกดเข้า drive อ่าน folder ทีละชั้น
- ชุดทดสอบสร้างเอเจนต์และทีม HR1–HR5 (เบนช์ ยังไม่มีสกิลใหม่ตามมา)
