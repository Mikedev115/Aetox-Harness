# 🧩 Aetox v1.10.3

วันที่ 19 ตุลาคม 2026

**รุ่นแก้เล็ก: เมนูผู้ให้บริการและโมเดลของ engine ภายนอกมีโลโก้ และจำผู้ให้บริการที่เลือกไว้**

## ตัวกรองผู้ให้บริการเด้งกลับเป็น "ทั้งหมด" ทุกครั้งที่ปิดเมนู

- **เดิม** ในงานโค้ดที่ใช้ CLI engine (เช่น OpenCode) เลือกผู้ให้บริการเป็น `opencode` แล้วปิดเมนู
  พอเปิดใหม่กลับเป็น "ผู้ให้บริการทั้งหมด" ต้องเลือกใหม่ทุกครั้ง และแถวผู้ให้บริการเป็นข้อความเปล่า ไม่มีโลโก้แบบเมนูโมเดลของ Aetox
- **รุ่นนี้**
  - ตัวกรองที่เลือกจำไว้ตลอดที่แอปเปิดอยู่ แยกตามชุดผู้ให้บริการของแต่ละ engine จึงไม่ไปกรองรายการของ engine อื่น
  - ถ้ายังไม่เคยเลือก เมนูเปิดที่ผู้ให้บริการของโมเดลที่ใช้อยู่
  - ปุ่มและทุกแถวของผู้ให้บริการมีโลโก้ของตัวเอง ชุดเดียวกับเมนูโมเดลของ Aetox

ไม่ได้ทำ: ตัวกรองไม่ได้เก็บข้ามการปิดเปิดแอป

## แถวโมเดลมีโลโก้ค่าย

- **เดิม** OpenCode เสิร์ฟโมเดลหลายค่ายใต้ผู้ให้บริการเดียว รายการ 35 ตัวจึงเป็นข้อความล้วนหน้าตาเหมือนกันหมด
- **รุ่นนี้** แต่ละแถวมีโลโก้ของค่ายที่ทำโมเดล อ่านจากชื่อตระกูล เช่น Nemotron เป็น NVIDIA, MiMo เป็น Xiaomi, Qwen เป็น Alibaba, GLM เป็น Z.ai
  ชื่อที่ไม่บอกค่าย (เช่น Big Pickle) ใช้โลโก้ของผู้ให้บริการที่เสิร์ฟแทน

## เปลี่ยนอื่น ๆ ในรุ่นนี้

- ช่อง "โปรแกรมบนเครื่อง engine" ในฟอร์มเพิ่ม/แก้ engine: ตอนกดที่ช่อง แสงขอบถูกกล่องเลื่อนตัดจนขาดเป็นสองเส้น รุ่นนี้ใช้สีขอบของช่องแทน
- dev engine: build สองครั้งติดกันบน Windows อาจได้ชื่อไฟล์เดียวกัน แล้ว build ที่ดีตัวล่าสุดถูกลบทิ้ง ตอนนี้ชื่อซ้ำจะเลื่อนเลขไปจนว่าง
- tests ที่เพิ่มในรุ่นนี้: `cliModelDisplay.test.ts` › "CLI model maker mark"
- มือถือและ CLI: โค้ด Android ไม่เปลี่ยนตั้งแต่ `mobile-v0.3.2` จึงไม่ออก APK ใหม่ ตัวติดตั้งยังมี APK 0.3.2 พร้อม `android-build.json` เหมือนเดิม
  CLI ไม่เปลี่ยน ได้เอนจินใหม่ไปพร้อมรุ่นนี้
