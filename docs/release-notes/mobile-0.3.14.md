## มีอะไรใหม่ (มาจาก Aetox บน Windows 1.11.28)

- **ความคิดถูกยุบไว้จนกว่าจะกด** ระหว่างเทิร์นยังคิด แอปวาดข้อความความคิดเต็มทุกเฟรมโดยไม่สนใจสถานะยุบ (กล่องสูงสุด 162 px) — ตอนนี้ปุ่ม fold เดียวทั้งตอนกำลังคิดและคิดจบ กางเมื่อกด และยังมี `role=status` ให้โปรแกรมอ่านหน้าจอรู้ว่ากำลังคิด
- **ปัดประวัติขึ้นได้ระหว่างสตรีม** ตัวตามท้ายเคยเขียน `scrollTop` ทุก ~32 ms ทำให้ปัดขึ้นช้า ๆ ได้เพียง 12 px ใน 2.5 วินาที = รู้สึกล็อก — ตอนนี้หยุดตามท้าย 900 ms เมื่อมี `pointerdown`/`wheel`/`touchmove` วัดซ้ำด้วยการลาก 6 px/เฟรม: จาก 12 px เป็น 1,638 px และกลับมาตามท้ายเมื่อเปลี่ยนแชท
- **คำตอบระหว่างสตรีมวาดเร็วขึ้น** เดิมวาดใหม่ทั้งก้อนทุกเฟรม (คำตอบ 8 KB, 173 เฟรม: 367 ms และ HTML 734 KB) ตอนนี้ตัดที่ blank line นอก code fence แล้วต่อเฉพาะบล็อกที่จบแล้ว เหลือ 47 ms และ 21 KB ต่อ 173 เฟรม คำตอบที่จบแล้วยังวาดทั้งก้อนเหมือนเดิม
- **กดสลับ ผู้ช่วย/โค้ด แล้วได้แชทใหม่ของเดสก์นั้นทันที** เดิมปุ่มรอ `pickMode` (ซึ่งยิงถามโฟลเดอร์ผ่านเน็ต) ก่อนเรียก `newChat` และ `newChat` อ่านโหมดกลับจาก localStorage อีกที กดสองครั้งเร็ว ๆ จึงแข่งกันเอง และโฟลเดอร์ที่อ่านไม่สำเร็จถูกนับเป็น "ไม่มีโฟลเดอร์" แล้วเด้งกลับผู้ช่วย — ตอนนี้ `newChat(mode?)` รับเดสก์จากผู้เรียกและจำลง storage ทันที และ `loadProjects` คืน `true`/`false` (อ่านไม่สำเร็จไม่ใช่ลิสต์ว่าง)
