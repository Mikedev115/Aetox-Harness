# 🧩 Aetox v1.10.1

วันที่ 19 ตุลาคม 2026

**รุ่นที่ห้องตัดต่อมีเอฟเฟกต์จริง: เสียง สี มาสก์ ฉากเขียว ความเร็ว ผู้พูดหลายเสียง และสิ่งที่เล่นในห้องตรงกับไฟล์ที่เรนเดอร์**
**ทุกคำตอบมีใบส่งงานให้กดดู ทั้งบนคอมและมือถือ เด็คสไลด์ได้รูปจริงพร้อมเครดิต และผู้ช่วยตามเรื่องที่คุณค้างไว้**
**ขอทีมที่ทำผลงานได้ ผู้ช่วยศึกษาของจริงก่อนเสนอ และกดสร้างทีมจากมือถือได้**

## ห้องตัดต่อ: เอฟเฟกต์ที่ได้ยินและเห็นเหมือนไฟล์จริง

- **เดิม** ทรานสิชันและสีทุกตัวถูกเขียนชื่อไว้ในโค้ด เพิ่มหนึ่งตัวต้องแก้หลายที่ คลิปที่ตั้ง clean หรือใส่เอฟเฟกต์เล่นในห้องเป็นเสียงเดิม ได้ยินจริงแค่ในไฟล์เรนเดอร์ สีบนจอเป็น CSS filter ที่ทำได้แค่ใกล้เคียง ฉากเขียวกับมาสก์ไม่อยู่ในห้องตัด และการส่งออกมีแค่วงหมุน หยุดไม่ได้นอกจากปิดแชต
- **รุ่นนี้**
  - **เอฟเฟกต์เป็นไฟล์ data** หนึ่งเอฟเฟกต์คือไฟล์เดียว มีแท็บเอฟเฟกต์ใน inspector และ op `fx` ที่คนกับเอเจนต์ใช้ร่วมกัน
  - **เอฟเฟกต์เสียง 14 แบบ** เสียงพูด (chipmunk, deep, robot, megaphone, radio, telephone) ห้อง (room, hall, echo, underwater) โทน (bass, bright, warm, lo-fi) ห้องตัดอบเสียงเป็นไฟล์แล้วเล่นไฟล์นั้น จึงได้ยินเหมือนไฟล์ที่เรนเดอร์
  - **ลุคสี 12 แบบ** เป็นตาราง `.cube` เดียวที่ทั้ง ffmpeg และ player (WebGL2) อ่าน สีบนจอจึงตรงกับไฟล์ เครื่องที่ไม่มี WebGL2 แสดงภาพเดิม
  - **มาสก์ ฉากเขียว และโหมดผสมภาพ** player วาดด้วยสูตรเดียวกับเรนเดอร์ วัดใน lab ต่างเฉลี่ย 0.4–1.4/255
  - **ความเร็วไล่ระดับและเล่นถอยหลัง** (slowmid, speedup, slowdown, bullet หรือกำหนดจุดเอง) อบเป็นไฟล์ ความยาวบน timeline รู้ทันทีโดยไม่ต้องรอ
  - **ผู้พูดหลายคน** ตั้งใน Settings → เสียง ว่าคนที่ 1, 2 … ใช้ผู้ให้บริการและเสียงไหน เพศ อายุ บุคลิก แล้ว op `speak` อ่านบทลง timeline แทร็กละคน และอัดเสียงพากย์จากไมค์ได้
  - **เรนเดอร์เป็นงานบนชิป** บอกเปอร์เซ็นต์และเวลาที่เหลือ กด ✕ หยุด ffmpeg และลบไฟล์ครึ่งเดียว หยุดเทิร์นก็หยุดเรนเดอร์ด้วย
- แก้ที่เจอตอนลองจริง: สลับคลิปหลักเป็นไฟล์ใหม่แล้วชั้นสีค้างเป็นภาพดำ เพราะวาดก่อนวิดีโอ decode เสร็จ วัดหลังแก้ สีแดง เหลือง ฟ้า เขียว ต่างจาก ffmpeg ไม่เกิน 3/255

## ใบส่งงานใต้ทุกคำตอบ

- **เดิม** เอเจนต์ทำงานกับเครื่องมือแล้วไม่มีอะไรให้กด คำตอบตั้งแต่ 4 ต.ค. มีการ์ดแค่ 115 จาก 1,065 เพราะการ์ดอ่านจากรายการไฟล์ที่ tool ส่วนน้อยเติม
- **รุ่นนี้**
  - ทุก tool บอกว่าทิ้งอะไรไว้ให้ผู้ใช้ ทำไฟล์ แก้ไฟล์ เปิดหน้า รันเซิร์ฟเวอร์ หรือส่ง (commit, push, ข้อความแชต) และเก็บไว้กับ turn ข้ามรีสตาร์ต
  - ใต้คำตอบเป็น block เดียว ภาพเล็กพร้อมปุ่มดู แผงขวาปิดก็บอก เด็คสไลด์กดดูแล้วไปห้องสไลด์ที่เด็คนั้น
  - มือถือได้ block เดียวกัน ไฟล์ที่เปิดได้มีปุ่มดู ส่วนหน้า localhost เซิร์ฟเวอร์ และโค้ดในโปรเจกต์เขียนว่า "อยู่บนคอม" ไม่ส่ง path ไปมือถือ
  - หน้าจอมือถือมาจาก Windows จึงได้ของใหม่ไปกับรุ่นนี้เลย ไม่ต้องอัป APK (Aetox Mobile 0.3.2 เดิมใช้ได้)

## สไลด์: รูปจริง ความลึก และเปลี่ยนหน้าตอนนำเสนอ

- **เดิม** เด็คมีแต่ตัวหนังสือกับกล่อง ทางหารูปคือค้นเว็บ อ่านรายการ URL ที่ไม่มีภาพ แล้วเดา ใน A/B 18–19 ต.ค. ทางนี้ถูกใช้ 0 ครั้งใน 6 รอบ และรูปที่ทำแล้วไปลงโฟลเดอร์ที่เด็คหาไม่เจอ
- **รุ่นนี้**
  - `media_fetch` ค้นรูปจาก Wikimedia Commons และ Openverse (เก็บเฉพาะ license ที่ใช้ซ้ำได้: PD, CC0, BY, BY-SA) หรือจากรูปบนหน้าเว็บทางการ ตอบเป็นแผ่นรูปมีเลขให้เอเจนต์ดู แล้ว `pick` เซฟรูปที่เลือกลง `imgs/` ข้างเด็คพร้อม src และบรรทัดเครดิต
  - `image_make` รับ `for` แบบเดียวกัน และ `size` ("1536x864")
  - สกิล aetox-slides: หารูปก่อนเขียนเด็ค ไม่มีรูปที่ตรงเรื่องให้สร้างใน look เดียวกันทั้งเด็ค ทุกสไลด์มีหลัง กลาง หน้า แสงทิศเดียว ตัวหนังสือไม่ทับกัน และดู render จริงก่อนส่ง
  - A/B ด้วยโจทย์เดียวกัน: เด็คที่มีรูป 1 → 6 จาก 6 รอบ
  - ตอนนำเสนอเต็มจอ กด ↓/↑ เลื่อนล้อเมาส์ (หนึ่งครั้งหนึ่งหน้า) หรือคลิกที่สไลด์เพื่อเปลี่ยนหน้าได้
- **ยังไม่ได้ทำ** `image_make` ยังทำทีละรูป ถ้าขนานได้จะเร็วขึ้นราว 60 วินาทีต่อเด็ค

## ผู้ช่วยตามเรื่องที่คุณค้างไว้

- **เดิม** ผู้ช่วยทำงานได้ แต่ไม่รู้ว่าคุณค้างอะไรอยู่ ทุกแชตเริ่มเหมือนไม่เคยเจอกัน ไม่ถามสิ่งที่งานต้องรู้ เตือนไม่ได้ และตั้งเวลาไม่ได้ เพราะ tool ตั้งเวลายังติดอยู่กับโต๊ะเลขาที่ยุบไปแล้ว ใน 149 แชตของผู้ช่วย (5–19 ต.ค.) มีการจดงาน 14 ครั้ง ตั้งเวลา 0 ครั้ง
- **รุ่นนี้**
  - เปิดแชตผู้ช่วย แล้วผู้ช่วยรู้ว่างานไหนถึงกำหนดภายใน 2 วัน เลยกำหนดแล้ว หรือถึงวันที่ควรกลับมาตาม (ไม่เกิน 5 รายการ บอกครั้งเดียวตอนเปิดแชต) จะยกขึ้นมาพูดเมื่อเกี่ยวกับสิ่งที่คุณถาม
  - งานมีวันกลับมาตาม (follow-up) แยกจากวันส่ง เช่น ส่งศุกร์ แต่ต้องตามคำตอบวันอังคาร
  - สิ่งที่คุณส่งมาให้จด ผู้ช่วยจดทันที ส่วนเรื่องที่ผู้ช่วยเห็นเองจากบทสนทนา ("ศุกร์ต้องส่งลูกค้า") จะถามคุณหนึ่งบรรทัดก่อนจด
  - พอคุณบอกว่า "ส่งไปแล้ว" หรือ "ไม่ทำแล้ว" ผู้ช่วยจะปิดงานนั้น แล้วเรื่องนั้นไม่กลับมาอีก ผู้ช่วยปิดเองโดยไม่มีคำของคุณไม่ได้ เพราะแอปตรวจว่าคำนั้นอยู่ในข้อความล่าสุดของคุณจริง
  - ผู้ช่วยตั้งงานตามเวลาจากแชตได้อีกครั้ง และ **ตั้งเตือนได้** ("เตือนพฤหัส 9 โมง") ถึงเวลาแล้วผู้ช่วยจะบอกคุณในแชตที่ตั้งเตือนไว้ และเสนอขั้นต่อไปได้หนึ่งอย่าง ถ้าคุณไม่อยู่หน้าเครื่อง จะส่งไป Telegram/Discord ที่จับคู่ไว้ด้วย ทุกการเตือนมีสถานะ (ขึ้นในแอปแล้ว · ส่งถึง bot แล้ว · ส่งไม่ได้) และไม่เตือนซ้ำ ถ้าเลยเวลาไปตอนที่แอปปิดอยู่ จะเตือนตอนเปิดครั้งถัดไป พร้อมบอกว่าควรเตือนตอนไหน การตั้งเตือนถามก่อนทุกครั้ง
  - ครั้งแรกที่เจอกัน (ยังไม่รู้อะไรเกี่ยวกับคุณเลย) ผู้ช่วยตอบเรื่องที่คุณถามก่อน แล้วถาม 2–3 ข้อในฟอร์มเดียว ทุกข้อข้ามได้: อยากให้เรียกว่าอะไร · ใช้ผู้ช่วยทำอะไรเป็นหลัก · อยากให้เตือนทางไหน ถามครั้งเดียวต่อเครื่อง ที่เหลือเรียนรู้จากการใช้งาน
  - ผู้ช่วยถามเมื่องานต้องใช้ข้อมูลเรื่องคุณที่ยังไม่รู้ (กำหนดส่ง ส่งให้ใคร อยากได้แบบไหน) ถามครั้งเดียวแล้วจำ และเสนอขั้นต่อไปเฉพาะเมื่อมีเรื่องค้างจริง ถ้าไม่มีก็จบคำตอบเลย การตอบ yes ครอบคลุมเฉพาะสิ่งที่เสนอ
  - ทุกหัวหน้า (ผู้ช่วยและโค้ด) ห้ามบอกว่าจด ตั้งเวลา หรือส่งแล้ว ถ้า tool ยังไม่ได้ยืนยัน
- **ข้อจำกัด** การเตือนทำงานเฉพาะตอนที่ Aetox เปิดอยู่ มือถือยังไม่มี push notification และหน้า Command Center ยังแสดงการเตือนเป็นแถวงานตั้งเวลาธรรมดา
- **ยังไม่มีผลวัด** ของส่วนนี้ ชุด bench วัด "ความรับผิดชอบ" (จดถูก นึกถึงเรื่องค้าง เงียบเมื่อควรเงียบ ไม่อ้างว่าทำแล้วถ้ายังไม่ได้ทำ) จะ run หลังปล่อยรุ่น

## ค้นเว็บไม่ตอบ "ไม่มีผล" แทนการโดนบล็อก

- **เดิม** DuckDuckGo กันบอทด้วยหน้า CAPTCHA ที่ตอบ HTTP 202 tool อ่านเป็น "(no results)" แบบสำเร็จ ใน tool_runs 364 จาก 1,199 ครั้ง (30%) ว่างเปล่าแบบนี้ เอเจนต์คิดว่าคำค้นไม่ดีแล้วค้นซ้ำ ซึ่งทำให้บล็อกนานขึ้น turn หนึ่งได้ผลว่าง 16 จาก 21
- **รุ่นนี้** หน้า CAPTCHA เป็น error ที่บอกตรง ๆ ว่าโดนบล็อก ทั้งแอปหยุดค้นช่วงหนึ่ง และคำขอออกไปตามจังหวะ
- **ไม่ทำโดยตั้งใจ** แก้ CAPTCHA ปลอมเป็นเบราว์เซอร์ หรือเปลี่ยน IP

## แชตที่ใช้ CLI

- Claude Code, OpenCode และ Antigravity ที่ทำงานใน Aetox เห็นรายชื่อสกิลของโต๊ะ และเปิดสกิลได้ผ่าน `skill_view` (เดิม prompt ของ CLI ไม่มีรายชื่อสกิลเลย จึงไม่เคยถูกเรียก)
- ข้อความที่พิมพ์ระหว่าง turn ของแชต CLI ไม่หายแล้ว ส่งคืนให้หน้าต่างแล้วออกไปเป็น turn ใหม่

## ขอทีมที่ทำผลงานได้ ผู้ช่วยศึกษาของจริงก่อนเสนอ

- **เดิม** ขอว่า "อยากได้ทีมทำยูทูป" หรือ "ทีมเพิ่มยอดขาย" ผู้ช่วยไม่รู้จะเริ่มยังไง ได้แค่รายชื่อตำแหน่งที่เดาเอา
- **รุ่นนี้** มีสกิล `aetox-team-build` ผู้ช่วยแตกโจทย์ออกเป็นชิ้น ไปศึกษางานที่กำลังสำเร็จจริง เปิดดูและวัดเอง
  แล้วเขียนสูตรพร้อมเกณฑ์ที่วัดได้ ทุกเกณฑ์มีเจ้าของหนึ่งตำแหน่ง ใช้เอเจนต์ที่คุณมีอยู่ก่อน แล้วทำหน้าเสนอให้คุณดู
  ทีมถูกสร้างเมื่อคุณกด "สร้างทีมนี้" เท่านั้น เรื่องเงิน โพสต์ หรือ key ต้องผ่านการ์ดของแอป
- จำนวนตัวอย่างที่ศึกษาให้ model ตัดสินเอง พอเมื่อตัวอย่างถัดไปไม่สอนอะไรใหม่ ไม่ใช่โควตาตายตัว
- **ไม่ทำโดยตั้งใจ** ไม่สร้างระบบทีมใหม่ใน engine (ลองแล้ว tool block เกือบเต็มงบตั้งแต่ก้อนแรก) ใช้ tool ที่มีอยู่ทั้งหมด
  และไม่ลอกหน้า ชื่อ หรือโลโก้ของต้นแบบ
- bench TM1 (ทีมเพิ่มยอดขายร้านกาแฟออนไลน์) วัดที่หน้าเสนอ รอบ pilot Terra × 1: ไม่มีสกิล 0.167 · มีสกิล 0.667

## มือถือ: กดสร้างทีมได้จากการ์ด

- **เดิม** แชตที่ร่างทีมตอบว่า "กด สร้างทีมนี้ บนการ์ด" แต่บนมือถือไม่มีการ์ดเลย
- **รุ่นนี้** การ์ดทีมแบบสั้นมาใต้คำตอบและใน "รอคุณ": หน้า ตำแหน่ง งานบรรทัดเดียว ป้าย มีอยู่แล้ว/ใหม่
  และผลตรวจที่พับได้ ปุ่ม "ขอแก้ก่อน" กับ "สร้างทีมนี้" ใช้การตัดสินใจเดียวกับการ์ดบนคอม
  เครื่องที่ไม่มีสิทธิ์ข้อเสนอเห็นการ์ดแต่ไม่มีปุ่ม ได้ของใหม่ไปพร้อมรุ่น Windows ไม่ต้องลง APK ใหม่

## ผู้ช่วยกล้าเปิดเว็บและโปรแกรมทำงานเอง

- **เดิม** ผู้ช่วยเปิด browser เฉพาะตอนค้นหาไม่พอ และบอกขั้นตอนให้คุณทำเองแทน ผู้ใช้บอก "ศุกร์ต้องส่งลูกค้า" ผู้ช่วยตอบครบแต่ไม่ชวนจด
  ส่วนการตั้งเตือนครั้งแรกล้มเพราะเอาชื่อการเตือนไปใส่ช่องชื่อทีม
- **รุ่นนี้** งานอยู่บนเว็บหรือในโปรแกรมอื่น ผู้ช่วยเปิดแล้วทำเอง (ถ้ามีทางที่แม่นกว่า เช่น connector หรือ shell ใช้ทางนั้นก่อน)
  เจอวันที่หรือคำสัญญาที่ยังไม่อยู่ในรายการ ตอบให้เสร็จก่อนแล้วชวนจดหนึ่งบรรทัด และช่องของ schedule มีคำอธิบายครบ
