# 🪟 Aetox v1.11.27

วันที่ 19 พฤศจิกายน 2026

รุ่นนี้แก้เรื่องที่เจอจากการใช้งานจริงตอนเช้า — กด "ย้อนกลับ" ในแชทที่ว่างอยู่แล้วโดนบอกให้รอทั้งที่ไม่มีอะไรทำงาน เพราะเช็คผิดว่า "มีเทิร์นที่ไหนก็ได้ในโปรเซส" แทนที่จะเป็น "แชทนี้" และยกหน้าจอบนโทรศัพท์ขึ้นมาเท่าดেসก์ท็อป: คอนเท็กซ์เป็นหน้าของตัวเอง เครื่องนี้เห็นทุกรายละเอียดเหมือนบนคอม และกดติดดาวโมเดลได้จากมือถือ

## ย้อนกลับและลองใหม่ ไม่ถูกแชทอื่นบล็อกแล้ว

- **เดิม** กด "ย้อนกลับ" ในแชทที่ว่างอยู่ ได้ข้อความ "เอเจนกำลังทำงานอยู่ — รอให้เสร็จ หรือกดหยุดก่อน แล้วค่อยสลับแชท" ทั้งที่แชทนั้นไม่มีอะไรทำงาน · ต้นเหตุคือ `DropExchange` ถาม `turnBusy()` ซึ่งตอบว่า "มีเทิร์นที่ไหนก็ได้ในโปรเซส" ไม่ใช่ "แชทนี้"
- **หลักฐานจาก log** 19 พ.ย. 09:29 มีสองเทิร์นวิ่งพร้อมกันคนละแชท และเทิร์นของแชทที่กดจบไปแล้ว (ยกเลิก 09:29:24) ขณะที่อีกแชทยังทำงานถึง 09:30:58
- **ตอนนี้** `DropExchange` · `RetryFailedTurn` · `ResendEdited` · `SwitchVariant` ถาม `turnRunningIn(<แชทของงานนั้น>)` ซึ่งเป็นคำถามที่ถูกและมีอยู่แล้ว (`DeleteSession`/`ArchiveSession`/`CloseGuideSession` ใช้ตัวนี้) · แชทที่กำลังตอบอยู่ยังถูกปฏิเสธเหมือนเดิม ไม่ได้เปิดช่องให้ตัดบทระหว่างเทิร์น
- **ทำไมปลอดภัย** แต่ละแชทมีเอนจินของตัวเองตั้งแต่ 2026-08-19 (`restoreContext` เขียน `conv.agent` ของแชทนั้น เทิร์นอื่นอ่านไม่ถึง) คอมเมนต์ที่อ้าง "the one agent context" แก้ให้ตรงความจริงแล้ว
- **เทสต์** `TestATurnInAnotherChatDoesNotRefuseWorkInThisOne` ครอบ drop/ลองใหม่/แก้แล้วส่งใหม่/สลับคำตอบ และแดงด้วยข้อความเดียวกับที่ผู้ใช้เห็นถ้าใส่ guard เดิมกลับ · `TestDropExchangeIsStillRefusedWhileThisChatIsAnswering` กันด้านที่ต้องคงไว้

## หน้าจอบนโทรศัพท์แยกเป็นสามหน้า เท่าดেসก์ท็อป

- **เดิม** "เครื่องนี้" ยุบอยู่ใต้ "การใช้งานและค่าใช้จ่าย" และอ่านค่าครั้งเดียวตอนเปิดหน้า จึงค้างที่ค่าเก่า · คอนเท็กซ์ปนอยู่ในชีต "แชทนี้" จนอ่านไม่รู้ว่าตัวเลขไหนเป็นของอะไร
- **หน้าต่างคอนเท็กซ์** เป็นหน้าของตัวเอง: % ของหน้าต่าง · แถบต่อเนื่อง · ทุกแถวมีโทเคนและ % ของหน้าต่าง · พื้นที่ว่าง · ชั้นวาง MCP และการกวาดผลเครื่องมือ · จำนวนสรุป · ราคาแชท
- **เครื่องนี้** เต็มแบบเดสก์ท็อป: ชื่อเครื่อง/รุ่น/CPU/สถาปัตยกรรม/uptime · CPU ทุกคอร์พร้อม P/E · แรมและที่ใช้ได้ · ดิสก์ระบบ · ทุกดิสก์ · ส่วนที่ Aetox ใช้แยกชิ้น — รีเฟรชทุก 1 วินาทีระหว่างเปิดหน้า
- **การใช้งานและค่าใช้จ่าย** เหลือเงิน/โทเคน/กราฟรายวัน รีเฟรชทุก 3 วินาที · ชีต "แชทนี้" เหลือรอบ/ขั้นตอน/ความเร็ว/แคช/เงิน/เวลา ไม่ปนคอนเท็กซ์
- **เงินและเวลาคิดที่คอม** `Spend` เพิ่ม `money`/`moneyEst`/`hasMoney`/`workMs` ตามกฎเดียวกับ status bar (exact เมื่อ priced ครบ, ≈ จาก EstCost เมื่อไม่มี, ไม่แสดงเมื่อบอกไม่ได้) มือถือไม่คิดราคาเอง
- **API ใหม่บนเครื่อง** `GET /api/context` ตรวจสิทธิ์รายแชทก่อนตอบ · `POST /api/pin` → `MobileSetPinned` ผูกดาวชุดเดียวกับเดสก์ท็อป · `/api/machine` ส่งรายละเอียดเต็ม (`coreCpu`, `coreClass`, `disks`, `host`, `version`, `uptime`, `parts`)
- **ถอดหน้า External Adapters ออกจากมือถือ** ตามที่สั่งว่า "ลบออกก่อน" — แถวในเมนู แถวในหน้าตั้งค่า route และเทสต์ของหน้าถูกถอดทั้งชุด ส่วน `MobileSetAdapter` ยังอยู่ครบ
- **ไฟล์** `internal/mobilelink/extras.go` · `internal/mobilelink/contract.go` · `internal/engine/mobile_options.go` · `desktop/mobile_extras.go` · `mobile/src/components/{ContextPage,MachinePage,UsagePage,StatsSheet,ModelSheet,McpPage}.svelte`

## สิ่งที่มือถือขาด — โลโก้ MCP ดาวโมเดล และคีย์แปลที่หาย

- **โลโก้ MCP กลับมา** อ่านจากตารางเดียวกับเดสก์ท็อป (`desktop/frontend/src/lib/mcpMarks.ts`) มีไทล์อักษรสีเดิมเมื่อเซิร์ฟเวอร์นั้นไม่มีแบรนด์
- **กดดาวโมเดลได้จากมือถือ** ทุกแถวในชีตโมเดลกดได้ ไม่ใช่เห็นแต่สองตัวที่ติดดาวอยู่แล้ว — ผูกกับ list เดียวกับเดสก์ท็อป
- **`t()` ถอยไปอังกฤษเมื่อคีย์หาย** แทนที่จะทำให้ทั้งหน้าล้มเหมือนเดิม (คีย์ที่หายไปหนึ่งคีย์เคยทำให้หน้าจอว่างทั้งหน้า)
