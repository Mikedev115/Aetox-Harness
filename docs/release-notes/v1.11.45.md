# 🧭 Aetox v1.11.45

วันที่ 28 พฤศจิกายน 2026

เอเจนขอขนาดจอได้จริงแล้ว: `browser device` ย่อหน้าต่างบราวเซอร์ของแอปเองให้แคบเท่าจออุปกรณ์ พร้อม user agent, touch และ DPR ของอุปกรณ์นั้น แล้ววัดขนาดจริงซ้ำจนตรง — ไม่ต้องมี iframe วางทับหน้าอีก · ภาพพื้นหลังจัดกรอบเองได้ต่อภาพ (ลาก/ซูม/เบลอ) และเบลอกระจกเบกเป็นบิตแมปครั้งเดียวแทนทุกเฟรมที่อะไรขยับ · เมนูหน้าเริ่มมี "เพิ่มห้อง" และหน้าตั้งค่าปิดตัวเองเมื่อคำขอลงช่องแชทแล้ว · `.mrow` ถูกจำกัดอยู่ใน `.mx` จึงไม่หลุดไปแต่งปฏิทินและเมนูหน้าเริ่มอีก

## บราวเซอร์: `browser device` ให้เอเจนใช้เมนูขนาดจอจริง

- **เดิม** เอเจนไม่มีทางย่อหน้าให้แคบ จึงใช้ eval วาง iframe 390px ทับทั้งหน้า (344 ครั้งใน tool_runs เดือน พ.ย. 2026) — iframe นั้นไม่ได้ user agent/DPR ของอุปกรณ์ และค้างอยู่ต่อบนจอผู้ใช้
- **ตอนนี้** (`42224a5e7`)
  - action ใหม่ `device` (`name?`, `turned?`) ในแพ็ก browser ใช้สิทธิ์ของ `browser_capture`: Go ยิงเหตุการณ์ให้แผงย่อหน้าต่าง native ครึ่งของมันเอง แล้วตั้ง user agent/touch/DPR ในเอนจินอีกครึ่งตามที่ `Workbench.setViewport` อธิบายไว้ · จากนั้นวัดขนาดจริงซ้ำจนตรง ไดอะล็อกคือตัวเลขที่หน้าวัดได้ ไม่ใช่คำสัญญา
  - ไม่มีชื่อ = กลับเต็มแผง
  - guidance ของ `device` และ `eval` ห้ามเลียนแบบด้วย iframe/resizeTo/zoom เพราะทิ้งสำเนาหน้าไว้บนจอผู้ใช้และวัดอะไรของอุปกรณ์ไม่ได้เลย
- เทสต์: `go test ./internal/skill/` ผ่าน · `go test ./desktop/ -run 'TestDevice|TestBrowserGuidance|TestBrowserTool'` ผ่าน · `browserViewport.test.ts` 13/13

## ฉากหลัง: จัดกรอบภาพเองได้ต่อภาพ

- **เดิม** ภาพพื้นหลังแสดงตามที่ไฟล์มี ไม่มีทางเลือกจุดโฟกัส ย่อ/ขยาย หรือเบลอภาพของตัวเอง
- **ตอนนี้** (`d080c49ea`)
  - ต่อภาพ: `fit {x, y, zoom}` และ `blur` 0–40px (ค่าตั้งต้น 50/50/100 และ 18px) เก็บใน `index.json`
  - พรีวิวใช้สัดส่วนหน้าต่างจริง ลากภาพเลือกจุดโฟกัสได้ สไลเดอร์ซูม/เบลอ และปุ่มกลับกึ่งกลาง
  - `fitRect` สูตรเดียวใช้ทั้งพรีวิว ภาพเบก และไทล์ จึงเห็นครอปเดียวกัน
  - โหลดภาพ: ภาพที่ใช้งานรอโหลดก่อน ภาพอื่นเติมทีละใบหลังหน้าต่างวาดเสร็จ พร้อม gen กันผลลัพธ์เก่าทับของใหม่ และคืน blob URL เก่า · ตอนเพิ่มภาพใช้ไบต์ที่มีอยู่ในมือแทนการอ่าน base64 ซ้ำผ่านบริดจ์
- เทสต์: `backgroundPreview`, `backgroundWork`, `backgroundPreset`, `localeGuard` ผ่าน (รวมชุดที่รัน 87 เทสต์)

## ฉากหลัง: เบลอกระจกเบกครั้งเดียว ไม่ใช่ทุกเฟรม

- **เดิม** หน้าต่างมี `backdrop-filter` 7–8 ชั้นบนพื้น 2520px แต่ละชั้นอ่านภาพใต้มันใหม่ทุกเฟรมที่มีอะไรขยับ (คำตอบที่สตรีม, สปินเนอร์, hover) — หน้าต่างจึงดูหน่วงเมื่อมีภาพพื้นหลัง
- **ตอนนี้** (`d080c49ea`, `81318b6d7`)
  - ภาพนิ่งเบกเป็นบิตแมปขนาดหน้าต่างครั้งเดียว (`backgroundScene/bakeBlur.ts`: ครอบภาพ, blur ตามที่ตั้ง, webp) แล้ว scene แสดงบิตแมปนั้น · แผงทิ้ง `backdrop-filter` เหลือ tint และได้ `data-bg-blur` เป็นตัวบอกแทน `:has()` ที่ถูกตรวจใหม่ทุก mutation ทั้งเอกสาร
  - คลิป/ภาพเคลื่อนไหว/GIF ยังใช้ฟิลเตอร์สดเพราะพิกเซลเปลี่ยนทุกเฟรม · เบกไม่สำเร็จถอยไปใช้ฟิลเตอร์สดเอง
  - `.bg-mini` ประกาศ `--bg-ratio: 1.6` (สัดส่วนหน้าต่าง 16:10) เป็นค่าตั้งต้น; markup ยังทับด้วยสัดส่วนจริงเมื่อพรีวิวใช้ทรงหน้าต่าง
  - ชิปสลับโหมด Agent|Editor และแท็บที่พับอยู่เป็นกระจกเหมือนแถบที่มันเกาะอยู่ แทนพิลทึบสีดำบนภาพ
- เทสต์: `themeContrast`, `backgroundPreview`, `backgroundWork`, `backgroundPreset` 145/145 · svelte-check 4 errors / 24 warnings เท่า baseline v1.11.44
