# Aetox v1.9.24

**อัดประชุมพร้อมเก็บเสียงต้นฉบับ เปิดห้องประชุมบนโต๊ะทำงาน และจัดเอเจนจากหน้ารวมที่อ่านง่ายขึ้น**

## ประชุมใน Aetox

- เริ่มอัดประชุมจากหน้าจัดการงานหรือปุ่มใต้ไมค์ในแชท เตรียมวาระก่อนเริ่ม และหยุดพักแล้วอัดต่อได้
- เก็บเสียงต้นฉบับพร้อมบทถอดเสียงและสรุป เพื่อย้อนดูเนื้อหาประชุมได้
- ห้องประชุมเปิดเป็นแท็บบนโต๊ะทำงาน แยกพื้นที่อ่านและจัดการประชุมจากแชท
- เอเจนมีสกิลสำหรับงานประชุม ช่วยจัดการข้อมูลประชุมผ่านเครื่องมือของแอปได้

## ไอเดียและพื้นที่ทำงาน

- หน้าไอเดียใช้เอกสารแบบรายบรรทัด พร้อมพื้นที่ดูข้อมูลโปรเจกต์
- เลือกโหมดทำงานจากการ์ดที่ซ้อนหลังกล่องข้อความ และรวมปุ่มอัดประชุมไว้ใต้ไมค์
- ต้นไม้ไฟล์แสดงไฟล์และโฟลเดอร์ทั้งหมด ยกเว้น `.git`
- ส่งวิดีโอจากแท็บสื่อไปเปิดบนมอนิเตอร์ต้นทางในห้องตัดได้โดยตรง

## ทีมเอเจน

- รวมการตั้งค่าเอเจนกับองค์กรไว้ในหัวข้อทีมเอเจน ดูทำเนียบพนักงานและกรองการ์ดรายคนได้
- สร้างเอเจนจากแบบสำเร็จรูปตามหมวด หรือเล่าให้ผู้ช่วยช่วยร่าง
- หน้าภาพรวมแสดงผังองค์กรพร้อมแผงรายละเอียด และตั้งโมเดลให้ทีมได้
- หัวหน้าทีมเห็นลูกทีมครบ แม้เอเจนบางตัวจะถูกปิดไม่ให้ผู้ช่วยเรียกโดยตรง
- ผู้ช่วยส่งเป้าหมายให้ทีม แล้วให้หัวหน้าวางโครงงานก่อนแจกงานตามสายงาน
- แก้การจัดแถวงานของลูกทีมให้ลงช่วงงานของหัวหน้าที่จ้าง แทนการหลุดไปอยู่ในการ์ดคนอื่น

## โมเดลและการทำงานของผู้ช่วย

- เลือกโมเดลและเสียงพูดได้จากหน้าผู้ให้บริการเสียง ภาพ และวิดีโอ
- แก้การตั้งค่าวิดีโอให้รองรับขั้นตอนที่ไม่มีชื่อ และแก้การแปลงค่าก่อนเปลี่ยนโหมด
- เพิ่มสกิล `aetox-humanize` สำหรับปรับงานเขียนให้เป็นธรรมชาติ และถอดสกิล `aetox-deploy` ออกจากชุดที่แถมมากับแอป
- ปรับคำสั่งให้แยกข้อมูลที่อ่านจากคำสั่งแฝง ระวังก่อนทับไฟล์ และทำงานต่อเมื่อพบข้อผิดพลาดที่ไม่เกี่ยวข้องกับงาน
- บอกเอเจนให้ขอผู้ใช้ล็อกอินในแท็บเบราว์เซอร์ แล้วทำงานต่อได้ โดยเบราว์เซอร์เก็บสถานะล็อกอินไว้ข้ามแชทและการเปิดแอปใหม่
- ปรับข้อมูลอ้างอิงในสกิลออกแบบ ภาษีไทย โฆษณา และการตั้งเวลาเผยแพร่เนื้อหา
