# 🪟 Aetox v1.11.8

วันที่ 11 พฤศจิกายน 2026

**รุ่นนี้แก้ชั้นโปรเจกต์ในแถบข้าง: คลิกขวาที่แถวไหนก็เปิดเมนูของโปรเจกต์นั้นตรงตำแหน่งเมาส์ และปักหมุดโปรเจกต์ได้ในคลิกเดียวจากปุ่มบนแถว ไม่ต้องเข้าเมนู ⋯ สองครั้ง**

## แถวโปรเจกต์คลิกขวาได้ และมีปุ่มปักหมุดจริง

- **เดิม** แถวโปรเจกต์ในชั้นโปรเจกต์ไม่มีตัวรับคลิกขวาเลย กดแล้วไม่มีอะไรเกิดขึ้น — แถวแชทเปิดเมนูที่ตำแหน่งเมาส์มาตั้งแต่ 9 พ.ย. แต่ชั้นโปรเจกต์ไม่ได้ตามไป
- **เดิม** เข็มหมุดที่ปลายขวาของแถวเป็นเพียงสัญลักษณ์ว่าปักแล้ว ไม่ใช่ปุ่ม และเมื่อเอาเมาส์ชี้ ปุ่ม + กับ ⋯ จะมาทับจนหมุดจางหาย — การปักหรือถอดหมุดจึงต้อง hover → ⋯ → เลือกในเมนู
- **รุ่นนี้** ปุ่มหมุดอยู่ในกลุ่มปุ่มที่ปลายแถว (หมุด · + · ⋯) กดครั้งเดียวปัก กดอีกครั้งถอด · ปักแล้วปุ่มเป็นสีเน้น และแถวยังแสดงหมุดไว้ตอนไม่ได้ชี้
- ปุ่ม + กับ ⋯ ไม่ขยับตำแหน่ง: หมุดโผล่มาทางซ้ายของทั้งคู่
- คลิกขวาที่แถวเปิดเมนูชุดเดียวกับ ⋯ ตรงตำแหน่งเมาส์ และถูกดึงกลับเข้ากับขอบหน้าต่างเมื่อเปิดใกล้ขอบ · ปิดด้วย Escape หรือคลิกที่อื่น (เดิมเมนูค้างอยู่จนกว่าจะกด ⋯ ซ้ำ)
- เมนูย้ายมาอยู่ที่การ์ดแทนที่จะอยู่ในกล่องปุ่ม เพราะกล่องปุ่มมี transform ซึ่งทำให้เมนูแบบ fixed ไปเกาะผิดที่
