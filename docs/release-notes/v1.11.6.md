# 🪟 Aetox v1.11.6

วันที่ 11 พฤศจิกายน 2026

**รุ่นนี้ให้ห้องพาเครื่องมือของตัวเองมาด้วย — ติดตั้งห้องหนึ่งครั้งได้ทั้งหน้าและความสามารถที่ห้องต้องใช้ โดยคุณยังเป็นคนกดอนุมัติเครื่องมือแต่ละตัว · มาพร้อมการรอตามเวลาที่ผู้ให้บริการสั่ง แทนที่จะปล่อยเทิร์นตายในหนึ่งวินาที**

## ห้องพาเครื่องมือของตัวเองมาด้วย

- **เดิม** ห้องคือหน้าเว็บในกรอบของแอป ถ้าห้องต้องอ่านหรือเขียนอะไรผ่านเครื่องมือ เอเจนต้องเขียนเครื่องมือนั้นแยกอีกงานหนึ่ง แล้วคุณต้องไปอนุมัติในหน้าตั้งค่าเอง ห้องที่เขียนไว้ให้คนอื่นใช้จึงพาความสามารถที่มันต้องใช้ไปด้วยไม่ได้
- **รุ่นนี้** `room.json` ประกาศ `tools` ได้ — ชื่อโฟลเดอร์ในห้องที่มี `tool.json` (เขียนด้วยสกิล `aetox-tool-maker`) และ `probe.json` ถ้าอยากให้มีตัวอย่างสำหรับทดลอง action ที่อ่านอย่างเดียว เอนจินแปลงแต่ละตัวเป็น **ฉบับร่าง** เท่านั้น ยังเรียกไม่ได้จนคุณกดอนุมัติที่ **ตั้งค่า › เครื่องมือ › ของคุณ** — ที่เดียวกับเครื่องมือที่เอเจนเขียนให้คุณทุกตัว
- การ์ดห้องขึ้นชิป `เครื่องมือ n` หรือ `รออนุมัติ n` และชี้ว่าตัวไหนติดตั้งแล้ว ตัวไหนยังรอ พร้อมเหตุผลถ้ามี
- เครื่องมือที่ใช้ id เดียวกับของที่ติดตั้งอยู่แต่เนื้อไฟล์ต่างกันถูกปฏิเสธพร้อมเหตุผล (`room-tool-taken`) ไม่ทับของที่คุณอนุมัติไว้แล้ว · โฟลเดอร์ที่ปีนออกนอกห้องหรือ symlink ชี้ผิดที่เป็นปัญหาแบบเดียวกับมาตรฐานข้ออื่น — ห้องยังเปิดได้ โดยไม่มีเครื่องมือชิ้นนั้น
- ลบห้องแล้วเครื่องมือที่ห้องพามาจะถูก **ปิด** ไม่ใช่ลบ เพราะของที่คุณอนุมัติแล้วเป็นของคุณ · ห้องที่ไม่ประกาศ `tools` ทำงานเหมือนเดิมทุกอย่าง ไม่ต้องแก้อะไร
- **ไฟล์** `desktop/deskrooms.go` · `internal/engine/user_tools.go` · `WorkbenchStart.svelte` · `workbench/rooms/deskRooms.svelte.ts` · `internal/skill/skills/aetox-desk-room/SKILL.md` · `locales/{th,en,zh}.ts`

## รอตามเวลาที่ผู้ให้บริการสั่ง ไม่ปล่อยเทิร์นตายในหนึ่งวินาที

- **เดิม** ผู้ให้บริการตอบ 429 พร้อม `Retry-After` 27-30 วินาที แต่ไคลเอนต์มีเพดานรอ 20 วินาที จึงคืน 429 ให้ผู้เรียกทันที เทิร์นที่กดลองใหม่จึงตายใน ~1 วินาทีด้วยข้อความเดิมทุกครั้ง (log 11 พ.ย. 2026: `[continue]` หกครั้งติดกัน จบใน 1.0-1.3 วินาที)
- **รุ่นนี้** เพดานของการรอที่ผู้ให้บริการระบุเป็น 90 วินาที และมีบรรทัด log ตอนนอนรอ ช่วงเงียบจึงอธิบายได้ว่าเป็นการรอ ไม่ใช่เทิร์นที่ค้าง
- **ไฟล์** `internal/model/httpclient.go` · `httpclient_retry_test.go`
