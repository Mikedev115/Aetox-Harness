## พรอมป์: ใบทางการค้าออกด้วย `document` ไม่ใช่เขียนหน้าเอง

## สิทธิ์เต็ม: ถามแค่ `.env` และคำสั่งที่ออกเน็ต

- **เดิม** โหมดสิทธิ์เต็มยังถามการ์ดหลายแบบ ทั้ง publish, ssh ข้ามเครื่อง, งานตั้งเวลา และปิดโปรเซสตามชื่อ ทั้งที่ทุกอย่างอยู่บนเครื่องนี้และจบในเทิร์น
- **รุ่นนี้** `safety.ShouldPrompt` ตัดสินโหมด full-access ก่อนรายการทุกโหมด: ถามเฉพาะ `EffectShellNetwork` และ `EffectReadSecret` ที่เป็นตระกูล `.env` สองโหมดที่เหลือยังถามครบเหมือนเดิม
- `EffectShellNetwork` คือคำสั่งที่เน็ตเป็นเนื้อใน (`curl`, `wget`, `Invoke-WebRequest`/`RestMethod`, `iwr`/`irm`, `nc`, `telnet`, `ftp`, `sftp`, `scp`, `rsync`, `ssh`) และ git ที่ outbound (`clone`/`fetch`/`pull`/`push`/`ls-remote`/`submodule`) ทั้งทาง shell และทาง git tool · `npm install`/`go mod download` ไม่อยู่ในลิสต์เพราะเป็นขั้นของงานในเครื่อง
- ไฟล์ข้อมูลจำลองที่ชื่อพ้องไฟล์ความลับ (`credentials.json`, `secrets.yml`, `account.json`, `oauth.json`, `service-account*.json`) ไม่ต้องขออนุญาตอ่านแล้ว ขณะที่ `.env`/`.npmrc`/`.netrc`/`.git-credentials`/`id_rsa` และนามสกุลกุญแจ (`.pem` `.key` `.pfx` `.p12` `.jks`) ยังถามเหมือนเดิม · โฟลเดอร์ credential จริง (`.ssh`/`.aws`/`.gnupg`/`.azure`/`.kube`) ถูกตัดสินก่อน จึงไม่มีการยกเว้นให้ไฟล์ในนั้น
