## มีอะไรใหม่ (มาจาก Aetox บน Windows ที่รวมคอมมิต `78b315e38`)

- **แถบบนของแชทมีปุ่มไฟล์เสมอ และเห็นว่ามีอะไรเปิดอยู่บนโต๊ะของ PC** เดิมปุ่มนี้หายไปเมื่อแชทไม่มีไฟล์ และแสดงได้แค่ไฟล์ที่แนบมากับคำตอบ — ไฟล์ที่เอเจนเปิดไว้บนโต๊ะ (แผงขวาของ PC) ไม่มีทางไปถึงมือถือเลย ตอนนี้ปุ่มอยู่ตลอดและกดแล้วเปิดชีตสองส่วน:
  - **บนโต๊ะ · PC** — ทุกไฟล์ที่เปิดอยู่บนโต๊ะของแชทนั้น พร้อมขนาด และคำว่า "เปิดอยู่บน PC" ของแท็บที่อยู่หน้าสุด
  - **ไฟล์ของแชทนี้** — ไฟล์ที่เทิร์นนั้นส่งมาให้
  - กดแถวไหนเปิดดูเต็มจอด้วยตัวดูไฟล์เดิม (ปัดดูไฟล์ถัดไปได้เหมือนเดิม)
  - รายการรีเฟรชตอนเปิดแชทและตอนเทิร์นจบ (ช่วงที่เอเจนเพิ่งเปิดไฟล์ระหว่างทำงาน)
- **อ่านได้เฉพาะไฟล์ในโปรเจกต์ของแชทนั้น** ฝั่ง PC ส่งให้มือถือแค่ชื่อ ชนิด และขนาด ไม่มีพาธ และเปิดไฟล์ด้วยด่านเดียวกับไฟล์ที่เอเจนส่งมา (sandbox ของโปรเจกต์, กัน symlink หลุด, เพดาน 16 MB) · แท็บที่ชี้อยู่นอกโปรเจกต์ไม่ขึ้นในรายการ
