# 🪟 Aetox v1.10.43

วันที่ 1 พฤศจิกายน 2026

**รุ่นนี้เลิกล็อกรุ่นของเซิร์ฟเวอร์ MCP — รายการเก็บแค่คำสั่งต้นทางที่เขียนไว้ และของที่ติดตั้งด้วยรุ่นก่อนถูกปลดให้เองครั้งเดียว** หน้าความสามารถก็ไม่ต้องเปิดห้องซ้อนอีกชั้น: หัวข้อของห้องย้ายมาเป็นเมนูย่อยในคอลัมน์ซ้าย ทะเบียนเครื่องมือในตัวกลับไปหน้าตั้งค่า และ External Adapters เป็นหน้าเต็มแทนป๊อปอัป

## รายการ MCP เก็บแค่ต้นทาง — ไม่ตรึงรุ่น ไม่มีแถวอัปเดต

- **เดิม** ตอนติดตั้งเซิร์ฟเวอร์จากทะเบียน Aetox เขียนคำสั่งโดยพาชื่อรุ่นติดไปด้วย (`uvx mcp-for-blender==2.2.4`, `npx -y foo@1.2.3`) เก็บเลขรุ่นไว้ในที่มาของรายการ และตั้งตัวตรวจที่ถามทะเบียนซ้ำทุก 12 ชั่วโมง พร้อมแถว «มีอยู่ 2.2.4 → 2.2.6» ให้กดยืนยันก่อนเปลี่ยน
- **สาเหตุ** `npx`/`uvx` รันรุ่นล่าสุดที่ทะเบียนมีให้เองอยู่แล้วทุกครั้งที่เริ่ม คำสั่งที่ระบุรุ่นจึงเป็นการตรึงของที่ไม่มีใครตั้งใจตรึง และตัวตรวจ 12 ชั่วโมงกับแถวอัปเดตคือการรอ การต่อเน็ต และการกดยืนยันเพื่อสิ่งที่ไม่มีอะไรต้องทำ — เลขรุ่นที่ค้างอยู่ในไฟล์จนกว่าจะมีคนกด
- **รุ่นนี้** รายการเก็บคำสั่งตามที่เขียนไว้ (`npx -y foo`, `uvx foo`) และที่มาเหลือแค่ชนิดกับชื่อแพ็กเกจ ไม่มีเลขรุ่น ไม่มีตัวตรวจรุ่นของเซิร์ฟเวอร์ ไม่มีแถวอัปเดตของเซิร์ฟเวอร์ และไม่มีปุ่ม «ตรึงรุ่น» อีก — แบบเดียวกับที่ Claude Code, Cursor และ VS Code เก็บไว้ คือเก็บแค่คำสั่ง
- **ของที่ติดตั้งไว้แล้วถูกปลดให้เองครั้งเดียว** เปิดแอปรุ่นนี้ครั้งแรกจะปลด `==x.y.z` / `@x.y.z` / `--from=` / `--package=` ออกจากรายการที่ติดตั้งด้วยรุ่นก่อน และลบคีย์ version ในที่มา แล้วเขียนกลับเฉพาะสองคีย์นั้น คีย์อื่นในไฟล์ไม่ถูกจัดรูปแบบใหม่ · สคริปต์ `node server.js` และแท็กของ docker ไม่ถูกแตะ เพราะไม่ได้ดึงแพ็กเกจจากทะเบียน
- **รายการ «รุ่นใหม่» เหลือของสกิลอย่างเดียว** สกิลยังต้องคัดลอกโฟลเดอร์ลงเครื่องจริง จึงยังต้องมีคนกดเมื่อต้นทางขยับ (และยังเก็บ sha ไว้เป็นใบเสร็จว่าใส่อะไรลงไป) ข้อความในคู่มือของหน้านี้บอกเหตุผลว่าทำไมเซิร์ฟเวอร์ไม่อยู่ในรายการนี้
- **ไม่ได้ทำ** ทางเลือก «ตรึงรุ่น» ถูกถอดทั้งทาง ไม่มีที่ให้ล็อกเซิร์ฟเวอร์ไว้ที่รุ่นใดรุ่นหนึ่งอีกแล้ว

## หน้าความสามารถเป็นเมนูย่อยในคอลัมน์ซ้าย

- **เดิม** หน้า «ความสามารถ» มีเมนูของตัวเองซ้อนอยู่ในห้องอีกชั้น หน้าตาเหมือนคอลัมน์ซ้ายอีกอัน ผู้ใช้ต้องกดเข้าห้องหนึ่งชั้นก่อนจึงจะรู้ว่ามี MCP เซิร์ฟเวอร์ สกิล เครื่องมือในตัว ชุดคำสั่ง การใช้คอมพิวเตอร์ และการเชื่อมต่ออยู่ข้างใน
- **รุ่นนี้** หัวข้อของห้องย้ายออกมาเป็นเมนูย่อยในคอลัมน์ซ้าย พับ/กางได้ จำสถานะไว้ และเปิดค้างไว้เป็นค่าเริ่มต้น ห้องจึงไม่มีเรลของตัวเองและเปิดข้างคอลัมน์แทนการทับ ขณะอยู่ในห้องนี้รายการเซสชันถูกซ่อน
- **จำนวนที่ค้างขึ้นที่เมนู** ห้องประกาศจำนวนของแต่ละหน้าให้คอลัมน์ซ้ายวาดเอง จึงถอดตัวเฝ้าทั้งเอกสาร (MutationObserver) ที่คอยอ่านป้ายจากหน้าเว็บออก
- **ทะเบียนเครื่องมือในตัวกลับไปหน้าตั้งค่า** เพราะเป็นรายการอ่านอย่างเดียว ไม่ได้ต่อหรือเปิดอะไร จึงไม่ต้องอยู่รวมกับสิ่งที่ต้องต่อและต้องสอน
- **External Adapters เป็นหน้าเต็ม** เดิมการ์ดห้าใบกับสวิตช์เด้งเป็นป๊อปอัปกลางจอพร้อมม่านคลุมทั้งแอป รุ่นนี้ใช้กรอบเดียวกับหน้าอื่น ไม่มี dialog ไม่มี portal ไม่มีม่าน และไม่มีการดัก Tab หรือ Esc เพื่อปิด
- **ไม่ได้ทำ** ตัวเฝ้าสถานะของ picker ยังไม่ได้ย้ายไปเป็น store กลาง หน้าใหม่จึงอ่านจากค่าที่ picker เขียนไว้
