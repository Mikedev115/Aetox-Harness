# Aetox Mobile Android 0.3.13

**รุ่นนี้ไม่ได้เปลี่ยนโค้ด Android** — ไม่มีไฟล์ใน `mobile/android` เปลี่ยนตั้งแต่ [0.3.12](mobile-0.3.12.md)
นอกจากเลขรุ่น (code 15 → 16) · ที่เปลี่ยนคือ **หน้าจอมือถือ** ซึ่งแอปโหลดมาแสดงจาก **Aetox บน Windows 1.11.27**

ต่อจาก [0.3.12](mobile-0.3.12.md)

## มีอะไรใหม่ (มาจาก Aetox บน Windows 1.11.27)

- **หน้าสถิติแยกเป็นสามหน้าเท่าดেসก์ท็อป** — หน้าต่างคอนเท็กซ์เป็นหน้าของตัวเอง (% ของหน้าต่าง · แถบต่อเนื่อง · ทุกแถวมีโทเคนของมัน · พื้นที่ว่าง · ชั้นวาง MCP · ราคาแชท)
  "เครื่องนี้" กลับมาเป็นหน้าเต็ม (ชื่อเครื่อง/รุ่น/CPU/สถาปัตยกรรม/uptime · CPU ทุกคอร์พร้อม P/E · แรม · ดิสก์ระบบ · ทุกดิสก์ · ส่วนที่ Aetox ใช้) รีเฟรชทุก 1 วินาที
  และ "การใช้งานและค่าใช้จ่าย" เหลือเงิน/โทเคน/กราฟรายวัน รีเฟรชทุก 3 วินาที
- **ชีต "แชทนี้" ละเอียดเท่าดেসก์ท็อป** เหลือรอบ/ขั้นตอน/ความเร็ว/แคช/เงิน/เวลา — ไม่ปนคอนเท็กซ์ · เงินและเวลาคิดที่ PC (`Spend.money`/`moneyEst`/`hasMoney`/`workMs`) ตามกฎเดียวกับ status bar มือถือไม่คิดราคาเอง
- **ค่า % ที่อ่านผิดถูกเอาออก** เดิมแต่ละแถวมี % เทียบหมวดที่ใหญ่สุด (40%/100%/90%) ซึ่งอ่านได้ว่าเป็นสัดส่วนของหน้าต่าง และแถบทุกแถวเป็นสีฟ้าเดียวกัน — ตอนนี้เหลือชื่อหมวดกับโทเคน และแถบใช้สีเดียวกับจุดของมัน
- **โลโก้ MCP กลับมา** ต่อเซิร์ฟเวอร์จากตารางเดียวกับเดสก์ท็อป มีไทล์อักษรสีเดิมเมื่อไม่มีแบรนด์
- **กดดาวโมเดลได้จากมือถือ** ทุกแถวในชีตโมเดลกดได้ ผูก list เดียวกับเดสก์ท็อปผ่าน `POST /api/pin` → `MobileSetPinned`
- **ถอดหน้า External Adapters ออก** ตามที่สั่งว่า "ลบออกก่อน" (API `MobileSetAdapter` ยังอยู่)
- **คีย์แปลที่หายไม่ทำให้หน้าล้ม** `t()` ถอยไปอังกฤษแทนการปล่อยหน้าจอว่าง

## ต้องใช้

Aetox บน Windows **1.11.27 ขึ้นไป** สำหรับหน้าจอชุดนี้ (หน้าจอทั้งหมดโหลดมาจากฝั่ง Windows รุ่นนั้น)
· บน Windows 1.11.26 ตัวแอปติดตั้งและใช้งานได้ตามปกติ แต่จะเห็นหน้าจอของรุ่นนั้น
· Android 10 ขึ้นไป · Tailscale HTTPS
