# Aetox Mobile Android 0.3.9

**รุ่นนี้ไม่ได้เปลี่ยนโค้ด Android** — ไม่มีไฟล์ใน `mobile/android` เปลี่ยนตั้งแต่ [0.3.8](mobile-0.3.8.md)
ที่เปลี่ยนคือเลขรุ่น (code 11 → 12) และหน้าจอมือถือที่แอปโหลดมาแสดง ซึ่งมาจาก **Aetox บน Windows 1.11.18**

ต่อจาก [0.3.8](mobile-0.3.8.md)

## มีอะไรใหม่ (มาจาก Aetox บน Windows 1.11.18)

- **กรองรายการแชทตามโต๊ะจากเมนูซ้าย** — แถว ผู้ช่วย | โค้ด | ทั้งหมด เหนือรายการในเมนู กรองตามโต๊ะของแชท
  และอยู่ในขอบเขตเดียวกับช่องค้นหา (ไม่มีการยิงคำขอใหม่ รายการยังมาจาก snapshot เดิม) · เลือกโต๊ะในเมนูแล้ว
  แถบเหนือกล่องพิมพ์เปลี่ยนตามเสมอ · "ทั้งหมด" เป็นตัวกรองของรายการอย่างเดียว ไม่แตะโต๊ะของแชทใหม่
- **สลับโต๊ะ ผู้ช่วย/โค้ด ได้จากแถบเหนือกล่องพิมพ์** — แถบ `.seg.desk` สูง 44px อยู่ทั้งตอนพิมพ์และตอนเปิดชีต
  (เดิมตัวสลับอยู่ใต้คำถามในหน้าแชทว่าง และหายไปเมื่อส่งข้อความแรก) · แชทที่เปิดอยู่มีชิปอ่านอย่างเดียว
  "โค้ด › โปรเจกต์" หรือ "ทีม" · โต๊ะและโฟลเดอร์ที่ใช้ล่าสุดถูกจำไว้ที่เครื่อง แชทใหม่จึงเปิดที่โต๊ะเดิม
  · ส่งแชทโค้ดโดยไม่มีโฟลเดอร์ไม่ได้แล้ว — เปิดชีตเลือกโปรเจกต์ให้ก่อนส่ง
- **ตัวติดตั้ง 0.3.9** เซ็นด้วยคีย์เดิม `c6330d76…` (versionCode 12) ติดตั้งทับ 0.3.8 ได้ ข้อมูลและเครื่องที่จับคู่ไว้อยู่ครบ
  หน้าจอที่เห็นในแอปยังมาจาก Aetox บน Windows เหมือนเดิม — APK ไม่ได้เก็บหน้าจอไว้ในตัว

## ต้องใช้

Aetox บน Windows **1.11.18 ขึ้นไป** (ทั้งสองข้อข้างบนมาจากฝั่ง Windows รุ่นนี้; PC รุ่นก่อนยังใช้ได้แต่จะเห็นพฤติกรรมเดิม)
· Android 10 ขึ้นไป · Tailscale HTTPS
