# 🧩 Aetox v1.10.0

วันที่ 18 ตุลาคม 2026

**รุ่นที่เอเจนต์คุมโปรแกรมบน Windows ได้จริง: เห็นภาพทุกขั้น รู้ว่ากดแล้วจอเปลี่ยนไหม และมีปุ่มหยุดบนจอ**
**ตอบเป็นภาษาของโจทย์ครบ งานโค้ดใช้ round น้อยลง และมือถือเลือกโปรเจกต์ ทีม และส่งข้อความแทรกระหว่างทำงานได้**

## เอเจนต์คุมโปรแกรมบน Windows

- **เดิม** tool `computer` อ่านหน้าต่างเป็นรายการ control แล้วกดทีละปุ่ม ไม่ส่งภาพกลับมา กดแล้วไม่มีใครบอกว่าจอเปลี่ยนหรือเปล่า model ตัวหนึ่งคลิกจุดว่างเดิม 133 ครั้ง อีกตัวบอกว่าเริ่มเกมใหม่แล้วทั้งที่นาฬิกาเกมเดินต่อ (bench ข้ามค่าย 18 ต.ค.)
- **รุ่นนี้** ศึกษาจาก computer use ของระบบที่ทำสำเร็จก่อน แล้วทำเป็นของเราที่ใช้ได้กับทุกค่าย
  - read และทุก action ส่งภาพหน้าต่างกลับมาด้วย ภาพย่อด้านยาว 1568px แล้วแปลงพิกัดกลับเป็นพิกเซลจริงเอง คลิกจากพิกัดในภาพได้ มี zoom ดูส่วนเล็กที่ความละเอียดเต็ม
  - ทุกครั้งที่กด engine เทียบภาพก่อนกับหลัง แล้วบอกว่า "หน้าจอไม่เปลี่ยน" หรือเปลี่ยนตรงไหน กดเดิมแล้วจอไม่ขยับ 3 ครั้งถูกปฏิเสธ 8 ครั้งต้องดูหน้าจอใหม่ก่อน
  - เมาส์ครบชุด (ซ้าย ขวา กลาง ดับเบิลคลิก ลาก hover) ชื่อคีย์แบบที่ model คุ้น พิมพ์ภาษาไทยตรงจุดที่ focus อยู่ action `wait` รอจนข้อความหรือหน้าต่างขึ้น และ `steps` ทำหลายขั้นในหน้าต่างเดียวในการเรียกครั้งเดียว (ไม่เกิน 8 ขั้น ปุ่มที่ย้อนไม่ได้อย่างลบ ส่ง ยืนยัน ชำระ ไม่กดในชุด)
  - อ่านสถานะ เปิดอยู่ ปิดอยู่ เลือกอยู่ กดไม่ได้ เปิด combo box และเมนูย่อยได้ dialog อย่าง Save As ขึ้นในรายการหน้าต่าง หน้าต่างที่เปลี่ยนชื่อกลางทางยังตามได้
  - พิกัดตามค่าย model: Gemini, Qwen3, GLM-V, Doubao Seed, UI-TARS, DeepSeek ใช้ grid 0–1000 ตามเอกสารของค่ายเอง ที่เหลือใช้พิกเซลของภาพ
  - **ตาช่วย** model ที่ดูภาพไม่ได้ใช้ `capture` + `ask` แล้วได้คำบรรยายพร้อมพิกัดจาก model ที่ดูภาพได้ผ่าน OpenRouter
  - **ปุ่มหยุดบนสุดของจอ** ขึ้นตลอดเวลาที่ Aetox คุมเครื่อง กดแล้วหยุดแชตที่คุมอยู่ คนขยับเมาส์ระหว่างนั้นปุ่มเปลี่ยนเป็นสีเตือนและบอก model
- แก้ที่เจอระหว่าง bench: app ที่ไม่รู้จัก DPI (Tk, app เก่า เกมหลายตัว) เคยคลิกเลยไป 1.75 เท่าที่สเกล 175% ตอนนี้ตรงแล้ว (เกมเป้า 0 → 5 จาก 5 hit) · Windows ไม่ยอมยกหน้าต่างขึ้นหน้าจน drag ล้ม · โปรแกรมที่รันแบบ admin เคยถูกรายงานว่า "หน้าจอล็อก" · กรอบ element เคยอ่านได้ค่าขยะเพราะชนิดข้อมูลผิด
- bench ใน dev ด้วย gpt-5.6-terra: 10 งานพื้นฐานผ่าน 10/10 งาน SA1 จาก 21 calls / 125 วิ เหลือ 6 calls / 25 วิ · 12 งานต่างประเภทรอบแรกผ่าน 10/12 · 13 งานบน Discord, Solitaire, Steam, WinRAR, เกม Tk รอบแรกผ่าน 11/13
- **ยังไม่ได้ทำ** ไม่ได้ทดสอบเกมที่มี anti-cheat เพราะ input สังเคราะห์อาจทำให้บัญชีโดนแบน · Notepad ที่ต้องสลับ tab และการบันทึกผ่าน Save As ของ Paint ยังค้าง

## ตอบเป็นภาษาของโจทย์

- **เดิม** prompt พูดว่า "the user's language" แต่ไม่เคยบอกว่าคือภาษาอะไร และมีภาษาไทยปนอยู่ในสิ่งที่ model อ่าน โจทย์อังกฤษชุดเดียวกัน GPT-6 Luna ตอบอังกฤษผ่าน Aetox แค่ 13 จาก 63 คำตอบ ที่เหลือเป็นไทย ฮีบรู รัสเซีย จีน
- **รุ่นนี้** engine ดูภาษาของข้อความเองแล้วเขียนไว้ข้างเวลาว่าต้องตอบภาษาอะไร (บอกเฉพาะที่แน่ใจ: ไทย อังกฤษ ญี่ปุ่น เกาหลี จีน) และทุกอย่างที่ model อ่านเป็นภาษาอังกฤษ ทั้งชั้นมอบงาน ผลของเครื่องมือ ข้อความห้องตัดต่อ และคำอธิบายเอเจนต์ที่มากับแอป ส่วนบนจอยังเป็นไทยเหมือนเดิม
- คำตอบภาษาไทยที่มีอักษรฮีบรู อาหรับ ซีริลลิก หรือเทวนาครีหลุดมา ("הเพิ่ม") ถูกลบออก ยกเว้นในโค้ด และเมื่อผู้ใช้พิมพ์อักษรนั้นมาเอง
- ผลวัด 66 รันใน[รายงานงานโค้ด 1.10.0](../reports/coding-harness-1.10.0/README.md): โจทย์อังกฤษ Luna ตอบอังกฤษ 13 → 63 จาก 63 · Terra 47 → 63 จาก 63 · โจทย์ไทยยังตอบไทย 9 / 9

## งานโค้ดใช้ round น้อยลง

- **เดิม** model เสีย round ไปกับพิธี: ถาม git status / diff ว่าตัวเองแก้อะไรไป round ที่มีแต่ todo และจบเทิร์นด้วย "งานที่เหลือคือ…" โดยไม่ได้แก้ไฟล์เลย
- **รุ่นนี้**
  - ผลของ write / edit มีบรรทัดบอกไฟล์ที่ agent ตัวนั้นแก้ในเทิร์นนี้ (+N −N, ใหม่, ลบ, กลับเป็นเหมือนเดิม) ไม่ต้องถาม git
  - git และ repo_map ที่ผลเหมือนเดิมตอบด้วยที่อยู่ของผลเดิม แทนการส่งข้อความเดิมซ้ำ
  - ขอให้แก้แต่จบเทิร์นโดยไม่มีไฟล์เปลี่ยน ถูกส่งกลับไปทำอีกหนึ่งครั้ง
  - โน้ตสั้นราย model จากคำแนะนำของผู้ผลิตเอง (GPT-6 และ GPT-5.x)
  - shell ของ agent เก็บ `.pyc` ของ Python ไว้ใน temp ไม่ทิ้ง `__pycache__` ไว้ใน project (A/B 66 รัน: Terra 30.0 → 27.9 rounds, 343 → 304 วิ/รัน, token −9.5%)
  - สกิลระบุไฟล์ที่ต้องอ่านทุกครั้งด้วย `with:` ใน SKILL.md แล้วไฟล์นั้นมากับตัวสกิลในคำตอบเดียว
- **เขียนโค้ดที่มีจุดเสี่ยง** write / edit ของไฟล์โค้ดสแกนหาค่าที่ไปถึง SQL, shell, path, URL, HTML, log และอื่น ๆ แล้วแนบวิธีกันบรรทัดเดียวพร้อมเลขบรรทัด และบอกว่าห้ามเปลี่ยนสิ่งที่สเปกรับ
- ผลวัดเทียบ 1.9.27: Terra SlopCodeBench 93.8 → 95.2% · CWEval func-sec@1 93.3 → 97.8% · เวลา 70 → 63 นาที · Luna เวลา 31 → 26 นาที · SWE-bench ตามรายงานบั๊ก 1 → 3 ใน 3 รอบ
- **ยังอ่อน** SWE-bench ทางการบน Luna 1 ใน 3 รอบ และ token ยังมากกว่าตัวครอบอื่น (ราว 90% เป็นขาเข้าที่แคชไว้)
- **ไม่ได้เปลี่ยน** ค่า verbosity ของ model ยังเป็นค่าเดิม สวิตช์ `AETOX_VERBOSITY` มีไว้ A/B จนกว่า bench จะยืนยันว่าคะแนนไม่ตก

## มือถือ: เลือกโปรเจกต์ ทีม และพิมพ์แทรกระหว่างทำงาน

- **เดิม** แชตใหม่จากมือถือเลือกได้แค่โมเดล ระหว่างที่เอเจนต์ทำงานต้องกดหยุดก่อนถึงจะส่งข้อความได้ และประโยคที่เอเจนต์พูดระหว่างทางหายไปจากประวัติเมื่อกดหยุด
- **รุ่นนี้**
  - เลือกโปรเจกต์ (ค้นหาได้ มีรายการล่าสุด) และเลือกว่าจะให้ผู้ช่วยทำเองหรือส่งให้ทีมก่อนเริ่มแชต
  - ส่งข้อความและไฟล์แทรกเข้าเทิร์นที่กำลังทำงานได้เลย ข้อความไม่ตกหล่นและไม่ส่งซ้ำ
  - ประวัติเก็บประโยคระหว่างทางและคำแทรกของผู้ใช้ตามลำดับเวลา ไม่หายเมื่อหยุดตอบ
  - แชตทีมมีหน้าสมาชิกพร้อมมาสคอต ยศ และงานที่แต่ละคนกำลังทำ
  - แชตที่ใช้ CLI แสดงและบันทึกโมเดลกับ effort ของ CLI ตัวนั้นจริง
- **Aetox Mobile 0.3.2** หน้าเชื่อมต่อบอกสาเหตุเป็นคำไทยพร้อมวิธีแก้ แทน error ดิบ "Unable to resolve host" (แยก 7 สาเหตุ มีปุ่มเปิด Tailscale) และแอปไม่หลุดกลับหน้าเชื่อมต่อตอนสลับโหมดมืด Android คืนแรม หรือกด Back รายละเอียดใน [Aetox Mobile 0.3.2](mobile-0.3.2.md)

## งานสั้นในแชต CLI ให้ CLI ตัวนั้นทำ

- **เดิม** ในแชต Code Agent ที่เลือก Claude Code, OpenCode หรือ Antigravity งานสั้นอย่างเขียน commit message แยกกลุ่ม commit ตัวเลือกคำตอบ หรือ journal ไปใช้โมเดลของ Aetox
- **รุ่นนี้** งานสั้นทุกจุดส่งไปที่ CLI ของแชตนั้นด้วยโมเดลและ effort ของแชต ถ้า CLI ใช้ไม่ได้จะบอก error ตรง ๆ ไม่แอบไปใช้โมเดลอื่น

## การเปลี่ยนแปลงอื่นในรุ่นนี้

- ชั้น MCP เพิ่ม Reddit (ไม่ต้องใช้ key ดู subreddit ได้ ค้นหาไม่ได้), YouTube, Pexels, Unsplash, Shopify (เครื่องมือเริ่มร้าน) และ Gamma

- เมนูทีมในช่องแชตไม่ยืดช่องว่างฝั่งซ้าย และคำอธิบายสมาชิกอยู่ใต้ชื่อ
- ข้อความ commit ที่ Aetox เขียนเห็นไฟล์ในโฟลเดอร์ใหม่ที่ยังไม่ได้ add (เดิม model เขียนว่าโฟลเดอร์นั้นไม่มีบรรทัด)
