# 🪟 Aetox v1.10.29

วันที่ 30 ตุลาคม 2026

**แอปไม่ถูกฆ่าตัวเองหลังอัปเดตตัวเองแล้ว · ผังสมองไม่ถูกจุดของวันดันจนอ่านชื่อไม่ได้ · การ์ดที่อธิบายข้อความที่เลือกไม่โตเลยขอบจอ · สกิลพาไปห้องและหน้าจอที่ผู้ใช้เห็นจริง และวิดีโอเริ่มจาก brief ก่อนลงมือตัด**

## โปรเซส: แอปไม่หายกลางเทิร์นหลังอัปเดตตัวเอง

- **สาเหตุ** `aetox.exe` กลายเป็น orphan ทุกครั้งหลัง self-update เพราะโปรเซสที่เฝ้าการอัปเดตเปิดให้แล้วจบไป เลข PID ของมันจึงเป็นเลขของโปรเซสที่ตายแล้ว ซึ่ง Windows แจกให้ตัวอื่นใช้ต่อ การฆ่า process tree ที่หยิบเลขนั้นมาเป็นรากจึงนับแอปที่กำลังรันอยู่เป็นลูกหลาน แล้วจบทั้งต้นไม้ — ไม่มี panic ไม่มีไฟล์ crash ไม่มี event ของ Windows และ log ขาดกลางเทิร์น
- **ตอนนี้รากต้องอ่านเวลาสร้างได้ก่อนจะฆ่า** แต่ละโปรเซสถูกเปิด handle ครั้งเดียวเพื่อกัน PID ถูกรีไซเคิลระหว่างนั้น และเทียบเวลาสร้างก่อนยิง
- **โปรเซสที่เกิดก่อนตัวที่อ้างว่าเป็นพ่อ ไม่ถูกนับเป็นลูกหลานอีก** ต้นไม้จึงไม่ลากโปรเซสอื่นที่บังเอิญได้เลขเดิมเข้ามาด้วย

## ผังสมอง: จุดของวันเริ่มปิด

- **วงนอกไม่บานทุกวันที่ใช้แอป** ผังวาดหนึ่งจุดต่อหนึ่งวัน จุดจึงเพิ่มขึ้นเรื่อย ๆ จนทั้งภาพถูกดันออกและอ่านชื่อโหนดไม่ได้ ทั้งที่วันไม่ใช่สิ่งที่คนเปิดผังมาดู
- **คำอธิบายภาพคือทางเปิดกลับ** กดชนิด "วัน" ในคำอธิบายภาพแล้ววันกลับมาวาดตามเดิม
- **ผังที่มีแต่วันกับตัวคนยังวาดวันไว้** เพราะไม่มีอะไรอย่างอื่นให้ดู

## คำตอบจากข้อความที่เลือก: การ์ดไม่ตกจอ

- **ความสูงของการ์ดถูกจำกัดด้วยที่ว่างของข้างที่มันเลือกเอง** ใต้ข้อความก่อน เว้นแต่ใต้ไม่มีที่และด้านบนมีมากกว่า การ์ดจึงไม่โตเลยขอบล่างของหน้าต่างในจังหวะที่คำตอบพิมพ์ขึ้นทีละบรรทัด
- **เนื้อหาในบอร์ดเลื่อนเอง** ไม่ใช่การ์ดล้นจอ ข้อความที่เลือกยังย่อสองบรรทัดเหมือนเดิม
- **การย่อสองบรรทัดย้ายไปที่กล่องในสุด** เพราะ line-clamp จำกัดความสูงแต่ยังวาดบรรทัดที่เกินลงไปใน padding ที่มีสีพื้น จึงเห็นเป็นแถบตัวอักษรที่ถูกเฉือนใต้ข้อความ

## สกิล: ห้องที่ผู้ใช้เห็น และ brief ก่อนการตัด

- **`aetox-teach` พาไปห้องที่มีอยู่จริง** ห้องในคอลัมน์เหลือหกห้อง ที่เหลืออยู่ในแผงข้างแชทและเปิดจากปุ่ม **+** ส่วนหน้า Today · Calendar · Timeline · Work · Read later และ Company มีคำอธิบายของตัวเองแล้ว
- **Settings และ Capabilities ตรงกับหน้าจอ** ตั้งเป็นห้ากลุ่มตามที่หน้าแสดง และ Capabilities มีหกหน้า รวม Using the computer กับ Avatar ที่เอกสารเดิมไม่มี
- **บอกว่าฉากเปิดครั้งแรกเล่าเรื่องทีม** ผู้ใช้ใหม่จึงอาจถามหา "ประตูทีม" ซึ่งไม่มี งานถูกส่งต่อจากแชทเสมอ
- **`aetox-video-cut` เริ่มจาก brief** เพิ่มหกรูปแบบของคลิปและส่วนที่แต่ละแบบต้องมี บอก brief กลับเป็นคำของผู้ใช้ก่อนลงมือเมื่อฟุตเทจยาว และถามส่วนที่ยังไม่มีใครระบุในข้อความเดียว
- **ตัวเลขความยาว hook และจังหวะมีที่อ้างอิง** เป็นค่าที่บอกออกมา ไม่ใช่กฎที่ไฟล์บังคับ พร้อมกติกาว่าเศษที่ไม่ได้ความหมายเท่านั้นที่ตัด

## ความมั่นใจของรุ่น

- เพิ่มชุดทดสอบการฆ่า process tree ว่าอ่านเวลาสร้างก่อนยิง และไม่นับโปรเซสที่เกิดก่อนรากเป็นลูกหลาน
- เพิ่มชุดทดสอบผังสมอง ว่าวันเริ่มปิด กดเปิดได้จากคำอธิบายภาพ และผังที่มีแต่วันยังวาดวัน
- ปรับชุดทดสอบแผงสมองให้คาดหวังชนิดที่วาดโดยไม่มีวัน
