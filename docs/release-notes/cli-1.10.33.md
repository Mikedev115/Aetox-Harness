# Aetox CLI 1.10.33

วันที่ 31 ตุลาคม 2026

**`aetox settings` — ค่าที่เป็นของคุณเดินทางไปเครื่องอื่นได้แล้ว · และคำปฏิเสธของโมเดลที่ตอบได้เทิร์นเดียวขึ้นเป็นภาษาไทยพร้อมชื่อโมเดล**

รุ่นนี้ใช้เลขรุ่นเดียวกับ [Aetox 1.10.33](v1.10.33.md) และได้เอนจินของรุ่นนั้นไปด้วย

## `aetox settings` — โปรไฟล์ตั้งค่าที่พาไปเครื่องอื่นได้

โปรไฟล์คือ **ค่าที่เป็นของผู้ใช้ ไม่ใช่ของเครื่อง**: โมเดลที่เลือก ระดับการคิด สวิตช์ของฟีเจอร์ ทีม หัวหน้า สมองของเอเจน ตารางเวรของแต่ละทีม และแถว automation (workflow) ระบบทำงานเป็นไฟล์ JSON ที่คุณถือไปเอง — ยังไม่ผูกกับบัญชีอีเมลเพราะที่เก็บบนคลาวด์ยังไม่มีในรุ่นนี้

```powershell
aetox settings                                  # ดูสรุปว่าเครื่องนี้มีค่าอะไรจะเดินทาง และอะไรต้องตั้งใหม่ปลายทาง
aetox settings export --list                    # รายชื่อ 57 ค่าที่โปรไฟล์พาไปได้ พร้อมชื่อที่คนอ่าน
aetox settings export --out D:\backup\aetox.json
aetox settings plan D:\backup\aetox.json         # แผนทีละแถวว่าจะเปลี่ยนอะไร — ยังไม่เขียนอะไร
aetox settings apply D:\backup\aetox.json        # ไม่ใส่ --yes = พิมพ์แผนให้ดูก่อนแล้วหยุด
aetox settings apply D:\backup\aetox.json --yes  # ใช้จริง
aetox settings apply D:\backup\aetox.json --yes --only model,think_level
```

- **`export` เขียนไฟล์เดียวจบ** ค่าเริ่มต้นคือ `./aetox-settings-<วันที่>.json` ถ้าโปรไฟล์จะเกินขีดจำกัด มันปฏิเสธตั้งแต่ก่อนสร้างไฟล์ — โปรไฟล์ที่ build นี้จะไม่ยอมใช้ก็ไม่ควรมีอยู่บนดิสก์
- **`plan` ไม่เขียนอะไรเลย** พิมพ์ `label: ค่าเดิม → ค่าใหม่` ทีละแถว บอกว่าอะไรมีปัญหาก่อนใช้ และบอกว่าอะไรต้องตั้งใหม่ที่เครื่องปลายทาง
- **`apply` ต้องมี `--yes` ถึงจะเขียน** ไม่ใส่คือดูแผนแล้วจบ ตรงกับหลักที่ว่าไม่มีอะไรถูกเขียนทับก่อนผู้ใช้เห็น และ `--only` ให้เลือกเป็นรายค่าได้เมื่อไม่อยากยกทั้งใบ
- **apply ที่ไม่เหลืออะไรให้เปลี่ยนก็บอกตรง ๆ** ขึ้น "ไม่มีอะไรต้องเขียน — เครื่องนี้ตรงกับโปรไฟล์อยู่แล้ว" ไม่ใช่เงียบหรือเขียนทับด้วยค่าเดิม

## อะไรเดินทาง และอะไรอยู่กับเครื่อง

- **57 ค่าเดินทาง** เป็น allow-list ที่ประกาศไว้ใน `internal/settingsprofile` — ค่าใหม่จะเดินทางก็ต่อเมื่อมีใครใส่ชื่อและป้ายของมันลงไป ไม่ใช่เพราะมันบังเอิญอยู่ในโครงสร้างค่า
- **สิ่งที่ไม่อยู่ในโปรไฟล์และต้องตั้งใหม่ที่เครื่องปลายทาง** path ของเครื่อง (โฟลเดอร์ทำงาน), คีย์และ credential (ผูกกับบัญชี Windows ของเครื่องนั้น), ไฟล์โมเดลเสียง และไฟล์ workflow ที่อ้าง path — ทั้งหมดถูกรายงานเป็นข้อ ๆ ใต้หัวข้อ "ต้องตั้งใหม่ที่เครื่องปลายทาง" ไม่ใช่ปล่อยให้ค้นเองทีหลัง
- **ขีดจำกัด 512 KB · 400 รายการต่อช่อง · ชื่อ 120 ตัวอักษร** เกินข้อใดข้อหนึ่งหรือเป็นโปรไฟล์ว่าง ปฏิเสธทั้งใบ ไม่เขียนทับค่าเดิมแม้แต่ค่าเดียว

## ข้อความปฏิเสธของโมเดลที่ตอบได้เทิร์นเดียว

- **ผู้ให้บริการที่ตอบ "multiturn chat is not enabled" ถูกแปลเป็นคำที่บอกทางออก** ข้อความบนเทอร์มินัลบอกชื่อโมเดลที่ถูกปฏิเสธ และบอกให้เปลี่ยนไปใช้โมเดลอื่นแล้วลองใหม่ แทนที่จะปล่อย JSON ของผู้ให้บริการให้อ่านเอง
- **ข้อความดิบยังอยู่ใต้บรรทัดนั้น** ในวงเล็บ เพื่อให้ตรวจย้อนได้ว่าใครเป็นคนปฏิเสธ
- **กรณีที่ประโยคไม่ได้ระบุชื่อโมเดลก็ยังอ่านได้** ข้อความจะพูดถึง "โมเดลนี้" แทนการปล่อยช่องว่าง

## หมายเหตุ

- **ไม่ได้เปลี่ยนที่เก็บของเดิม** ค่าที่ `settings` อ่านและเขียนคือค่าเดียวกับที่แอปใช้ (`%APPDATA%\aetox`) โปรไฟล์เป็นสำเนาที่ตั้งใจส่งออก ไม่ใช่ที่เก็บชุดที่สอง
- **`aetox` ยังใช้เอนจินของแอปเมื่อติดตั้งอยู่บนเครื่องเดียวกัน** ตามพฤติกรรมเดิมของแพ็กเกจนี้
