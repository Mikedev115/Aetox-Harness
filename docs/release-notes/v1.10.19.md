# 🪟 Aetox v1.10.19

วันที่ 26 ตุลาคม 2026

**ที่อยู่เหนือไฟล์ที่เปิดอยู่กดได้ทุกชั้น รวมชั้นสุดท้ายที่เคยเป็นแค่ตัวหนา และแถบแท็บมี ← → ย้อนกลับ–ไปข้างหน้าอย่างที่เบราว์เซอร์มี**

## ที่อยู่เหนือไฟล์กดได้ทั้งหมด

- **เดิม** ชั้นสุดท้ายของที่อยู่คือชื่อโฟลเดอร์ที่ไฟล์ตั้งอยู่ และถูกวาดเป็น `<strong>` เฉย ๆ กดไม่ได้ ทั้งที่มันคือที่ที่คนส่วนใหญ่หมายถึงเวลาเหลือบขึ้นไปดูที่อยู่ (เจ้าของ 26 ต.ค. 2026: *"ควรจะแสดงให้กดได้ทั้งหมด"*)
- **รุ่นนี้** ทุกชั้นเป็นปุ่มเดียวกันหมด รวมชั้นสุดท้าย ซึ่งยังอ่านเป็นคำตอบด้วยตัวหนาและสียังต่างจากชั้นอื่น ตามที่มันควรเป็น
- **ที่กดแล้วไม่เกิดอะไร ตอนนี้บอกที่ที่กด** ปุ่มที่เคยกดแล้วเงียบไม่ใช่เพราะไม่มีปุ่ม แต่เพราะโฟลเดอร์สัมบูรณ์ที่อยู่นอกโปรเจกต์ถูกถามไปที่เอนจิน ถูกปฏิเสธ (`browse_root.go`: "มีโปรเจกต์เปิดอยู่แล้ว") และคำปฏิเสธไปโผล่ที่บรรทัดข้อผิดพลาดของแชท ซึ่งอยู่อีกหน้าจอหนึ่งจากที่ที่เขากด รุ่นนี้คำตอบมาอยู่ในแถบเดียวกันกับที่กด
- **โฟลเดอร์ในโปรเจกต์เปิดต้นไม้ลงไปถึงโฟลเดอร์นั้น** ไม่ย้ายรากของต้นไม้ เพราะการย้ายรากถูกปฏิเสธเมื่อมีโปรเจกต์เปิดอยู่ คำตอบจึงเป็นท่าที่ใช้ได้ทั้งในโปรเจกต์และในโฟลเดอร์ที่เปิดดูอยู่
- **ที่อยู่แบบสัมบูรณ์ที่จริง ๆ อยู่ในโปรเจกต์ ก็กดได้แล้ว** ที่อยู่บนแถบนี้อาจเป็นเส้นทางเต็มของไฟล์ที่อยู่ในโปรเจกต์ (การ์ดในแชท การเปิดของเอเจนต์ แท็บที่บันทึกไว้) ขณะที่ต้นไม้เรียกทุกอย่างแบบสัมพัทธ์ `relativeUnder` ใน `filePath.ts` เทียบสองอย่างนั้นให้ตรงกัน — ตัดตัวคั่นท้ายออกทั้งสองข้าง และไม่สนตัวพิมพ์ เพราะพาธบน Windows ไม่มีตัวพิมพ์ และโฟลเดอร์เดียวกันกลับมาเป็น `D:` จาก binding หนึ่งและ `d:` จากอีกอันหนึ่ง
- **`browseFolderAt` ตอบว่ารากขยับหรือไม่** คำปฏิเสธเดียวที่มันมีจึงไปถึงคนที่กด ไม่ใช่แค่ขึ้นที่แชท

## ← → ย้อนกลับ–ไปข้างหน้าในแถบแท็บ

- **ใหม่** สองปุ่มที่ขอบซ้ายของแถบแท็บ และคีย์ Alt+← / Alt+→ เดินย้อน–ไปข้างหน้าบนสิ่งที่เคยอยู่หน้าในกลุ่มนั้น ไม่ว่าจะเป็นแท็บ ไฟล์ ห้อง หรือหน้าที่เอเจนต์เปิด (เจ้าของ 26 ต.ค. 2026: *"ควรจะกดกลับได้หมด"*)
- **ประวัติแยกตามกลุ่ม** เพราะการแบ่งสองบานคือเอดิเตอร์สองตัว ← ของบานซ้ายเดินไฟล์ที่เคยอยู่หน้าของซ้าย และไม่ดึงคนออกจากบานขวา
- **แท็บที่ปิดไปแล้วคือที่ที่กลับไปไม่ได้** ประวัติก้าวข้ามมันไป ไม่ได้ลงไปหยุดที่มัน
- **ประวัติเขียนที่จุดเดียว** ที่ `setActive` ซึ่งเป็นทางเดียวที่ "อะไรอยู่หน้า" เปลี่ยน แท็บ ห้อง หน้า ปุ่มบนแถบ และการเปิดของเอเจนต์ จึงไม่ต้องมีใครจำเอง ส่วนการเดินประวัติไม่ถูกบันทึกซ้ำเป็นที่ที่ต้องกลับไป (`walking`)
- **การเดินประวัติไม่ได้มาจากการกดของคนเท่านั้น** ตอนเปลี่ยนโปรเจกต์ ประวัติถูกล้าง เพราะที่ที่คนไปในโปรเจกต์ก่อนไม่ใช่ที่ในโปรเจกต์ใหม่ ส่วนมุมมองการเขียน/เอเจนต์ยังคงอยู่เหมือนเดิม
- ซองประวัติจำกัดที่ 40 ขั้น เก็บในหน่วยความจำเท่านั้น ไม่ลงดิสก์
- Alt+← / Alt+→ เลือกเพราะเป็นสิ่งที่เอดิเตอร์และเบราว์เซอร์ทุกตัวบนแพลตฟอร์มนี้หมายถึงย้อนกลับ/ไปข้างหน้า และลูกศรส่ง `code` เดียวกันทุกผังแป้น คีย์บอร์ดไทยจึงส่ง `ArrowLeft` เหมือนกัน
- แถบวัดความกว้างแท็บใหม่โดยคิดพื้นที่ของสองปุ่มนี้ด้วย จึงไม่มีแท็บถูกซ่อนเพราะปุ่มแย่งที่
