**รุ่นนี้ไม่ได้เปลี่ยนโค้ด Android** — ไม่มีไฟล์ใน `mobile/android` เปลี่ยนตั้งแต่ [0.3.11](mobile-0.3.11.md)
นอกจากเลขรุ่น (code 14 → 15) · ที่เปลี่ยนคือ **หน้าจอมือถือ** ซึ่งแอปโหลดมาแสดงจาก **Aetox บน Windows 1.11.26**

ต่อจาก [0.3.11](mobile-0.3.11.md)

## มีอะไรใหม่ (มาจาก Aetox บน Windows 1.11.26)

- **ปุ่มเดียวเปิดเมนู** ปุ่มกราฟเปิดสี่รายการ (แชทนี้ · เครื่องนี้ · การใช้งาน · External Adapters) และ MCP/สกิลเข้าลิสต์เมนูซ้าย
  แต่ละหน้าโหลดเฉพาะตอนเปิด ไม่ poll · การใช้ทั้งเครื่องออกจากชีตแชท เหลือตัวเลขของแชทกับเครื่องนี้
- **หน้าสถิติเต็ม** การใช้งานต่อโมเดลพร้อมค่าใช้จ่าย · เครื่องนี้เป็นดิสก์ทุกตัว การ์ดจอ และ uptime — adapter ลดข้อมูลบน PC ก่อนส่ง
- **หน้าตั้งค่าเป็นสารบัญ** เปิดด้วยการ์ดสถานะว่าเชื่อมกับเครื่องไหน เห็นกี่แชท แล้วแยกค่าที่เป็นของมือถือเองออกจากรายงานจาก PC ห้าหน้าที่อ่านอย่างเดียว
- **ชีตโมเดลสามแถว** ผู้ให้บริการ · โมเดล · ระดับความคิด แบบเดียวกับเดสก์ท็อป เห็นทั้งแคตตาล็อกของเจ้านั้น (เดิมเห็นแค่ตัวที่ติดดาว)
- **แถบบนบอกโต๊ะของแชท** และเลิกบอกซ้ำเหนือกล่องพิมพ์
- **สลับโต๊ะได้ทุกเมื่อและส่งได้จริง** — เดิมปุ่มสลับไม่ทำอะไรขณะมีแชทเปิด และแชทใหม่ที่เกิดมาถือ key โฟลเดอร์ที่เครื่องนั้นไม่มีสิทธิ์
  ทำให้ส่งอะไรกลับไปที่ PC ไม่ได้เลย · โหมดครบสี่ตัว (เพิ่ม มุ่งเป้า) พร้อมคุณภาพและสิทธิ์ของแชทใหม่
- **เห็นของบน PC ครบขึ้น** — MCP server, สกิลและเครื่องมือ, External Adapters พร้อมเลือก CLI runtime ให้แชทได้จากมือถือ
- **สามภาษา** เพิ่มจีน ครบ 359 คีย์ ใช้ศัพท์เดียวกับ locale จีนของฝั่งคอม
- **ตัวติดตั้ง 0.3.12** เซ็นด้วยคีย์เดิม `c6330d76…` (versionCode 15) ติดตั้งทับ 0.3.11 ได้ ข้อมูลและเครื่องที่จับคู่ไว้อยู่ครบ
  หน้าจอที่เห็นในแอปยังมาจาก Aetox บน Windows เหมือนเดิม — APK ไม่ได้เก็บหน้าจอไว้ในตัว
