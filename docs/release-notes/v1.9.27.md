# 🧩 Aetox v1.9.27

วันที่ 17 ตุลาคม 2026

**รุ่นแรกที่มี Aetox Link ให้มือถือคุยกับเอเจนต์บนเครื่องนี้ได้ ติดตั้ง MCP และสกิลจากแชทปกติ และโต๊ะทั้งสองบอกสิ่งที่รออยู่ตั้งแต่หน้าแรก**

## Aetox Link และ Aetox Mobile

- **เดิม** จะใช้มือถือต้องรัน `tailscale serve` เอง ก๊อปที่อยู่มาวาง แล้วกดสร้าง QR อีกที และรุ่น stable ของ Windows ยังไม่มี Link เลย
- **รุ่นนี้** หน้า "มือถือ" ในตั้งค่าอ่านสถานะ Tailscale เอง กดปุ่มเดียวแล้วแอปตั้ง HTTPS ให้ (ใช้ 443 หรือ 8443 ถ้า 443 มีของอื่นอยู่ ไม่ทับของเดิม และถอดออกตอนปิด) QR ต่ออายุเองทุก 3 นาที มีปุ่ม "คัดลอกลิงก์เชิญ" สำหรับมือถือที่สแกนไม่ได้ และ QR เล็กสำหรับติดตั้งแอปเมื่อ build นั้นมี APK มาด้วย
- มือถือใหม่ได้สิทธิ์ตั้งต้นแค่เริ่มแชทใหม่ ส่วนแชทเดิมต้องให้สิทธิ์ทีละแชท
- หน้าจอมือถือมาจาก Windows เครื่องนี้ จึงได้หน้าตาใหม่ไปพร้อมรุ่นนี้: แชทแบบแอปแชททั่วไป คุยด้วยเสียงผ่านตัวแปลงเสียงและเสียงอ่านที่ตั้งไว้บน Windows ธีมชุดเดียวกับแอป ข้อความที่ส่งขึ้นเป็นฟองทันทีและคีย์บอร์ดไม่ปิดตอนส่ง
- การ์ดคำถามบนจอที่ถูกตอบจากมือถือหรือช่องทางไปแล้ว กดบนจอจะไม่ไปตอบคำถามใบใหม่ที่ขึ้นมาแทนอีก การ์ดอนุญาตก็เช่นกัน
- **ยังไม่มาในรุ่นนี้** แอป Android ที่เปิดมาแล้วเข้าหน้าสแกน QR เลยและไอคอนแบบ adaptive มีโค้ดแล้ว แต่ต้องรอ APK รุ่นถัดไป ยังไม่ได้ build และยังไม่ได้ลองบนมือถือจริง

## ติดตั้ง MCP และสกิลจากแชทปกติ

- **เดิม** ห้องความสามารถมีแผงผู้ช่วยติดตั้งยืนอยู่ข้างหน้า เป็นแชทแยกที่มีบริบทของตัวเอง
- **รุ่นนี้** ผู้ช่วยในแชทปกติดูของที่ติดตั้งแล้วก่อนแนะนำของใหม่ ค้น เทียบสองถึงสี่ตัว หาเอเจนต์ที่เหมาะกับงาน และจัดวางของที่ติดตั้งแล้วเป็นการ์ดในแชท ทุกการติดตั้งหรือจัดวางยังรอคุณกดการ์ด และเมื่อปฏิเสธก็ไม่หาทางอื่นไปทำแทน
- ห้องความสามารถเหลือสองลิงก์: "ให้ AI หา" ที่เปิดแชทปกติ และ "คุยติดตั้งก่อนหน้า" ที่เปิดอ่านแชทติดตั้งเก่าได้อย่างเดียว
- ห้องสมุด MCP เปิดมาเป็นการ์ดตามงาน 11 หมวด (พัฒนา ข้อมูล ระบบ เกม ออกแบบ การตลาด เว็บ การเงิน งานออฟฟิศ เชื่อมต่อ ค้นหา) แทนกองเดิมสี่หมวด และมีแถว Godot กับ Unity
- เครื่องมือ MCP ที่ส่งรูป resource หรือข้อมูลแบบโครงสร้างกลับมา ตอนนี้เอเจนต์เห็นจริง ไม่ใช่แค่ "(content omitted)" รูปผ่านการตัดสินใจเดียวกับเครื่องมือในตัว (งบรวม 5 MB 16 ล้านพิกเซล 16 รูปต่อผล) ตัวเลขใน JSON ไม่เพี้ยนแล้ว และลิงก์ที่ server ส่งมาไม่ถูกเปิดเอง

## โต๊ะผู้ช่วยและโต๊ะโค้ด

- **โต๊ะผู้ช่วย** หน้าเริ่มขึ้นด้วย "รอคุณอยู่" คือประชุมที่ยังไม่ได้ถอดเสียงกับร่างความจำที่ยังไม่เก็บ (เก็บทั้งหมดได้ในปุ่มเดียว) ห้องแบ่งเป็นสองกอง ทำงาน กับ เก็บและส่งต่อ ชิ้นงานกลับมาเป็นห้องพร้อมจำนวนชิ้นของสัปดาห์ รออ่านย้ายไปอยู่ในเมนู + และแถว "หยิบต่อได้" ถูกเอาออก
- **โต๊ะโค้ด** หน้าเริ่มบอกรีโปกับ branch ไฟล์ที่ยังไม่ commit และไฟล์ที่ขยับมากที่สุด แล้ว checks กับ PR บรรทัดละอัน ปุ่ม "ให้เอเจนแบ่ง commit" เปิดห้อง Git แล้วเริ่มแบ่งให้เลย
- จัดการงานกับปฏิทินอยู่ในเมนู + ของทุกแชทหลังประตูผู้ช่วย ไม่ใช่แค่แชทหลัก
- แท็บเว็บ ชิปแนบหน้าเว็บ palette และรายการแหล่งข้อมูลแสดงไอคอนของเว็บนั้น แทนลูกโลกแบบเดียวกันหมด และหน้าแท็บว่างมีช่องค้นหาด้วย Google หรือพิมพ์ที่อยู่เว็บ
- ไฟล์ที่งานส่งมอบอ่านจากรายการส่งมอบของแชท ไฟล์ที่แค่ถูกสร้างหรือเปิดไม่นับเป็นชิ้นงาน เทิร์นที่ส่งหลายไฟล์รวมเป็นกล่องพับ "ไฟล์ในงานนี้" และไฟล์ที่เขียนไม่สำเร็จไม่ขึ้นการ์ดแล้ว

## ห้องตัดต่อและห้องประชุม

- ผู้ช่วยตัดต่อในห้องที่เปิดอยู่ทีละขั้นให้เห็น หัวอ่านไปที่จุดนั้นและไฮไลต์ช่วงก่อนแก้ หยุดหรือย้อนทั้งหมดได้ ไม่เขียนไฟล์และเรนเดอร์อยู่เบื้องหลังอีก
- ห้องตัดต่อได้ roll/slip, easing ของ keyframe, transition เพิ่ม, แต่งซับ, ส่งออกเป็นช่วง SRT หรือภาพนิ่ง และคีย์ลัดตัดต่อ ชื่อภาษาไทยเปลี่ยนจาก "ห้องตัด" เป็น "ห้องตัดต่อ"
- ห้องประชุมอัดหน้าจอพร้อมเสียงได้ เลือกจอหรือหน้าต่างพร้อมภาพตัวอย่าง เลือกคุณภาพวิดีโอ 3 ระดับ และเลือกตัวถอดเสียงกับโมเดลสรุปเฉพาะประชุมนั้น ไฟล์เสียงยาวถูกส่งแปลงเป็นส่วน ๆ ไม่ล้มด้วย 413

## เปิดแอปและอัปเดต

- **เดิม** บน Windows ไฟล์ socket ของเครื่องยนต์เสียได้ 2–39 ครั้งต่อวัน แล้วหน้าโหลดรอจนหมดเวลาก่อนเริ่มใหม่ ดูเหมือนโหลดสองรอบ
- **รุ่นนี้** Windows ต่อเครื่องยนต์ผ่าน tcp ตั้งแต่แรก เครื่องยนต์เริ่มก่อนหน้าต่าง และหน้าโหลดเดิมลื่นขึ้น มีคำว่า harness ข้างโลโก้
- อัปเดตดาวน์โหลดเบื้องหลังเองบนช่องทางที่รับได้ แล้วถามแค่ตอนรีสตาร์ต ถ้าดาวน์โหลดไม่สำเร็จจะกลับไปเป็นปุ่มดาวน์โหลดเดิม

## การเปลี่ยนแปลงอื่นในรุ่นนี้

- ปลายทางที่เพิ่มเองตั้งชื่อชนกับผู้ให้บริการเครื่องมือ (เสียง ภาพ วิดีโอ) ไม่ได้แล้ว เดิมคีย์ของเครื่องมือถูกส่งไปปลายทางนั้น และลบแถวแล้วคีย์หายตาม
- Kiro ผ่าน 9Router ที่บอกว่าข้อความยาวเกิน ตอนนี้แชทย่อประวัติแล้วลองใหม่ และโควตารายเดือนเต็มบอกตรง ๆ แทนการนับถอยหลังรอ
- สลับโมเดลจาก Telegram หรือ Discord ระหว่างเทิร์น ช่องทางบอกผลตรวจการเชื่อมต่อของโมเดลที่รออยู่
- หน้าโมเดลไม่ว่างเมื่อผู้ให้บริการที่เปิดไว้ถูกถอด และกดเปลี่ยนผู้ให้บริการเร็ว ๆ แล้วการ์ดไม่แสดงค่าของตัวก่อนหน้า
- คำขออนุญาตและคำถามของลูกมือส่งไปที่เอเจนต์ที่จ้าง ไม่โผล่เป็นปุ่มให้ตอบตรง ๆ
- เด็คสไลด์ใช้ฟอนต์คู่เดียวกับแอป และเครื่องยนต์วางโฟลเดอร์ fonts/ ข้างไฟล์ให้เมื่อเด็คอ้างถึง
- เอเจนต์โหมดโค้ด commit เมื่อถูกขอเท่านั้น และเขียนข้อความตามสไตล์ของรีโป
- กล่องแจ้งการย่อประวัติไม่ค้างหลังย่อเสร็จ เมนูดรอปดาวน์ไม่ขึ้นกรอบโฟกัสหนาที่แถวแรก และช่องพิมพ์ขยายลื่นเมื่อขึ้นบรรทัดใหม่
