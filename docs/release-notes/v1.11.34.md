# 🪟 Aetox v1.11.34

วันที่ 23 พฤศจิกายน 2026

รุ่นนี้จัดบ้านใหม่สองที่ที่คนใหม่เจอเป็นอย่างแรก — คอลัมน์ซ้ายเหลือแค่ของที่ใช้จริง และไกด์เปิดมาแล้วพาไปรู้จักห้าอย่างที่ผู้ใช้ตั้งเพิ่มเองได้ แทนที่จะทักทายแล้วปล่อยให้เดา ตามด้วยงานเบราว์เซอร์จำลองที่กรอบเครื่องเหมือนของจริง เทอร์มินัลที่อ่านออกบนธีมสว่าง และการ์ดคำถามที่ไม่กระตุกตอนถูกถาม

## คอลัมน์ซ้ายเหลือสองแถว — เซสชันใหม่ · ผู้ช่วย/โค้ด · ความสามารถ

- **เดิม** คอลัมน์มีแถว จัดทีม · โปรเจกต์ · พนักงานเฉพาะทาง · ชิ้นงาน · เพิ่มเติม · แก้ไขแถบด้านข้าง ปนกับประตูของโต๊ะ จนคนใหม่ต้องไล่อ่านเพื่อหาว่าอะไรคือที่ทำงานจริง
- **ตอนนี้** เหลือประตูของโต๊ะกับความสามารถ (พับเปิดได้) และแถวบนสุดเปลี่ยนชื่อเป็น «เซสชันใหม่» ทั้งผู้ช่วยและโค้ด · ห้องที่ถูกถอดยังมีประตูครบ: พนักงานเฉพาะทางกับชิ้นงานอยู่ใน ⋯ ของหัวข้อแชท โปรเจกต์อยู่ใน ⋯ ของหัวข้อโปรเจกต์ — ไม่มีห้องไหนไร้ทางเข้า
- ถอดกลไกปักหมุดและบันทึกลำดับคอลัมน์ทั้งชุด (ไม่มีแถวให้ปักแล้ว) พร้อม CSS ที่ไม่มีใครใช้
- **เทสต์** vitest `deskNav` เขียนใหม่ 4 ตัว · `sidebarNewChat`/`sidebarHistory` ตามชื่อแถวใหม่ · tester กดใช้จริงบน dev 8/8 ผ่าน

## ไกด์: เปิดมาแล้วพาทัวร์ห้าอย่างที่ตั้งเพิ่มได้

- **เดิม** กดไกด์แล้วขึ้นคำทักทายกับชิป 6 ปุ่ม ซึ่งอ่านเป็นช่องค้นหาที่มีหน้า — คนใหม่ไม่เคยรู้ว่าของที่ตั้งเพิ่มได้ทั้งห้าอยู่ในคอลัมน์ซ้าย
- **ตอนนี้** ไกด์เปิดมาเป็นทัวร์ 6 จุดในคอลัมน์: แถว «ความสามารถ» แล้วไล่ MCP server (เครื่องมือเสริม) · สกิล (วิธีทำงาน) · ชุดคำสั่ง (พรอมต์สำเร็จรูปเรียกซ้ำได้) · การใช้คอมพิวเตอร์ (ปิดไว้เป็นค่าเริ่มต้น) · การเชื่อมต่อ (บัญชีและเซิร์ฟเวอร์ภายนอก) — ยืนข้างแถวแล้วอธิบาย ไม่ต้องกดออกจากหน้า และจบในคอลัมน์
- คำอธิบายทั้งห้าเขียนใหม่เป็น «ตั้งอะไรได้» แทนการเล่าโครงหน้า (ไทย/อังกฤษ/จีน) · จบทัวร์แล้วชิป «อธิบายหน้านี้หน่อย» ยังเป็นปุ่มแรกของชุดคำถาม และป้าย Shift+คลิก ยังอยู่ในแบนเนอร์บน
- **เทสต์** vitest guide/guideCore/guideCatalog/guideNavGraph 145/146 (ที่แดงคือ `guide.page.settings.deskpanel.use` ที่ไม่มีคีย์ใน locale มาตั้งแต่ก่อนรุ่นนี้) · svelte-check 4 error/24 warning = baseline · tester กดจริงบน dev 6/6 ผ่าน (ไล่ 1/6 → 6/6 โดยหน้าแชทอยู่กับที่, จบแล้วชิปกลับมา, กดแถว MCP เปิดหน้าได้ปกติ)

- **ตอนนี้** ตัด 36 ชุดที่ซ้ำกับจอในแอป ซ้ำกันเอง หรือซ้ำกับโต๊ะอื่น (โค้ด 25 · ผู้ช่วย 8 · เลขา 3) เก็บ site/hero/pricing และตัวอย่างธุรกิจ 3 ตัว (booking, shop, excel-app) · เกณฑ์คือ «ซ้ำ» ไม่ใช่ตัวเลขการใช้งาน เพราะแอปไม่มีเทเลเมตรีและ `/name` ถูกขยายเป็นพรอมต์ก่อนบันทึก จึงไม่มีร่องรอยว่ากดชุดไหน

## เบราว์เซอร์จำลอง: กรอบเครื่องเหมือนจริง และตัวเครื่องตรงกับจอ

- **เดิม** ทุกเครื่องใช้กรอบเดียวกัน และตัวเครื่องถูกจัดกลางแผงขณะที่หน้าต่างจริงเว้นขอบซ้าย 12 ขวา 3 แถมวาดใต้ zoom ของ UI — เครื่องจึงใหญ่กว่าจอจริง
- **ตอนนี้** กรอบวาดแยกตามเครื่องจริง (bezel หนาบาง ขอบโลหะ ปุ่มยื่น ลำโพง กล้องหน้า ปุ่ม Home ของ iPhone SE) ครบ Galaxy S24 · iPhone 16 Pro · Pixel 9 · iPad mini · หมุนแนวนอนได้พร้อมบอกหน้าเว็บผ่าน `screenOrientation` (ทดสอบกับ WebView2 จริง: portrait-primary / landscape-primary 90) · เมนูขนาดหน้าจอมีรูปเครื่องตามสัดส่วนจอและเลือกสีเครื่องดำ/เงินได้ (จำแยกต่อแท็บ) · ตัวเครื่องใช้กรอบเดียวกับหน้าต่างจริงและหารด้วย `currentCSSZoom`
- **เทสต์** ตรวจในหน้าต่าง dev จริงครบ 8 รุ่น ทั้งแนวตั้ง แนวนอน และสีเงิน

## เทอร์มินัลบนธีมสว่าง: อ่านออกทั้งตัวอักษรและสีที่โปรแกรมส่งมา

- **เดิม** ภาพจากเครื่องผู้ใช้: แท็บเป็นสีขาวแต่พื้นเทอร์มินัลดำ และตัวอักษรเกือบมองไม่เห็น (วัดได้ #70747A บน #000) — สาเหตุอยู่ที่พื้นหลัง: `xterm.css` ของไลบรารีตั้ง `.xterm-viewport` เป็นดำตายตัว ธีมจึงคุมพื้นไม่ได้เลย
- **ตอนนี้** พื้น viewport โปร่งใสให้ theme คุมได้ · `theme.background` เป็นสีทึบจริงของ pane (ไม่ใช่โปร่งใส ซึ่งทำให้ xterm วัด contrast กับดำแล้วดันตัวอักษรให้จาง) · เปิด `minimumContrastRatio: 4.5` ให้ xterm ดันทุกสีให้อ่านออก แม้โปรแกรมจะส่งสี 256 สีหรือ truecolor มาเอง
- **เทสต์** vitest `terminalRendering` 10/10 (ล็อกพื้นทึบ + contrast floor + บรรทัด CSS ที่เป็นตัวแก้จริง) · probe ด้วย xterm.js ตัวเดียวกับโปรเจกต์บนพื้นธีมสว่าง: ก่อนแก้สี 256/truecolor แทบมองไม่เห็น หลังแก้อ่านชัด

## สถิติ: เมนูเดียวจบ และตัวเลขไม่สะกดหน่วยซ้ำ

- หน่วย (ทั้งหมด/วัน/เดือน/ปี) เป็นเมนูดรอปดาวน์เดียว มีกรองผู้ให้บริการอยู่ข้าง ๆ — แถวในเมนูบอกโทเคนและเงินต่อค่าย และปุ่มบอกจำนวนค่ายที่เลือกอยู่
- ถอดการ์ด «ใช้บ่อยสุด» เพราะตาราง «แยกตามโมเดลและค่าย» ด้านล่างบอกอยู่แล้ว · การ์ดบทสนทนา/ต่อเนื่องติดคำ «ทั้งเครื่อง» เมื่อกรองค่าย เพราะ engine แยกให้ไม่ได้
- แถวเมนูผู้ให้บริการเป็นบรรทัดเดียว (ติ๊กกับโลโก้ซ้าย ชื่อตัดด้วย ellipsis ยอดชิดขวา) และแถบเมนูชิดขวาเหมือนเดิม
- เอา «/ปี» ออกจากการ์ดตัวเลข เพราะแถบ «แสดงตัวเลขเป็น» บอกหน่วยครบแล้ว — เดิมพูดซ้ำสี่ครั้ง
- **เทสต์** `Settings.test.ts` ผ่าน (รวมเทสต์กรองค่าย 1 จาก 2 ค่าย + ป้ายทั้งเครื่อง) · svelte-check 4 error/24 warning = baseline
