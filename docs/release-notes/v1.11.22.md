**รุ่นนี้เปลี่ยนวิธีที่เอเจนทำงานกับโค้ดเดิม: หาต้นเหตุก่อนแก้ และกล้าแก้ที่ตัวเหตุไม่ใช่ที่จุดที่โชว์อาการ · แผนที่โปรเจกต์อ่าน import ของ JS/TS จาก grammar · engine สร้างรายงานรายเดือนได้แล้ว (ยังรอหน้าจอ)**

## โต๊ะโค้ด: หาเหตุให้ถึง แล้วค่อยกำหนดขนาดของการแก้

- **เดิม** พรอมป์มีแต่ "minimal / surgical / don't touch unrelated files" คำว่า cause ไม่มีอยู่เลย คำสั่งที่ชัดที่สุดจึงเป็น "แตะให้น้อย" และจุดที่เห็นอาการคือการเปลี่ยนแปลงที่เล็กที่สุด
- **รุ่นนี้** กฎใหม่: ทำให้อาการเกิดซ้ำก่อน แล้วตามไปถึงสิ่งที่ผลิตมัน · ไฟล์นับว่า "เกี่ยว" เมื่อไม่มีมันแล้วแก้บั๊กไม่ได้ · การออกแบบที่ยังผลิตบั๊กเดิมคือส่วนหนึ่งของการแก้
- `minimal` ยังอยู่ แต่ขอบเขตชัดขึ้น: จำกัด *ระยะที่การแก้ลาม* ไม่ใช่ *ระยะที่ค้นหา* — การแก้ที่เล็กที่สุดที่เอาต้นเหตุออก ไม่ใช่ที่เล็กที่สุดที่ซ่อนอาการ
- คอมเมนต์เดิมที่ผิดแล้วให้แก้ ไม่ใช่เก็บไว้เพราะ "preserve existing comments"
- การแก้เชิงโครงสร้างต้องมีหลักฐานรองรับ: เคสที่ทำซ้ำได้ · ขอบเขตผลกระทบที่ตรวจแล้ว · พฤติกรรมที่ต้องไม่ขยับ

## คอมเมนต์เขียนเหตุ ไม่เขียนแก้ต่าง

- กฎในพรอมป์โต๊ะโค้ด: คอมเมนต์/ข้อความคอมมิต/บันทึก เขียนสิ่งที่โค้ดพูดไม่ได้ — ข้อจำกัด เหตุผล และกับดัก
- คำอ้างเจ้าของ วันที่ "วัดแล้ว" หรือ "เทสต์ผ่าน" เป็นหลักฐานที่ตามหลังเหตุผล ไม่แทนที่เหตุผล และตัวเลขต้องบอกวิธีตรวจมันซ้ำ

## แผนที่โปรเจกต์: import ของ JS/TS จาก grammar

- **เดิม** การสแกนบรรทัดพลาด import ที่ตัดบรรทัด, `export … from` และ `require()` ที่อยู่ในฟังก์ชัน — เส้นทาง dependency ของไฟล์ที่เขียนแบบนั้นจึงขาด
- **รุ่นนี้** อ่าน module specifier จาก tree-sitter (`aetoxts_imports`) แล้วแปลงเป็น edge ด้วยกฎเดิม (relative = syntactic, `@/` `~/` = heuristic, ชื่อแพ็กเกจไม่ใช่ไฟล์)
- บิลด์ที่ไม่มี CGO ยังใช้ตัวสแกนเดิม ไม่พัง

## รายงานรายเดือน (engine — หน้าจอยังไม่มา)

- `BrainMonthly` อ่านรายงานของเดือน, `RunMonthlyNow` สร้างใหม่จากสิ่งที่เกิดขึ้นจริงในเดือนนั้น (จำนวนเทิร์น คำถามซ้ำ งานที่หลายเรื่องในคำขอเดียว)
- ค่าตั้ง: `monthly_report_auto` (ปิดเป็นค่าตั้งต้น — แบ็กกราวด์คอลที่ไม่มีใครขอ) และ `monthly_model` (ว่าง = โมเดลที่ใช้อยู่)
- เดือนที่ไม่มีข้อมูลถูกปฏิเสธ ไม่สร้างรายงานเปล่า · ยังไม่มีหน้าจอไหนเรียก API นี้
