# Aetox v1.9.25

วันที่ 15 ตุลาคม 2026

**ปรับเสียงอ่านได้ละเอียดขึ้น แก้เสียง Microsoft Edge และเปิดแผงทีมหลังสร้างสำเร็จ**

## เสียงอ่านคำตอบ

- ปรับความเร็ว ระดับเสียง ความดัง และช่วงเว้นตามที่แต่ละผู้ให้บริการรองรับ พร้อมบอกว่าค่าใดปรับโดยผู้ให้บริการหรือโดย Aetox
- ทดลองฟังด้วยโมเดลและเสียงที่กำลังตั้งค่าได้ แม้ไม่ใช่ผู้ให้บริการหลักที่เลือกไว้
- แก้การยืนยันตัวตน Microsoft Edge ให้ใช้รูปแบบใหม่ เพื่อแก้คำขอเสียงที่ถูกปฏิเสธ
- เก็บการเชื่อมต่อ Edge และตัวอ่าน Windows กับ Piper แบบ native ให้พร้อมใช้ระหว่างคำขอ โดยไม่ต้องเริ่มตัวอ่านใหม่ทุกท่อน
- ให้ Windows และ Piper แบบ native อ่านท่อนแรกก่อนท่อนถัดไป ส่วนเสียงคลาวด์ยังเตรียมหลายท่อนพร้อมกันได้

## เสียงภาษาไทยในเครื่อง

- เพิ่มหน้าจัดการแพ็กเสียง PyThaiNLP พร้อมรายการโมเดล เสียง ขนาดดาวน์โหลด และข้อมูลสัญญาอนุญาต
- แสดงผู้ให้บริการเสียงในเครื่องในหน้าต่างเพิ่มผู้ให้บริการ พร้อมป้ายบอกประเภทงานที่รองรับ
- รองรับการดาวน์โหลดต่อจากส่วนที่ค้างและตรวจ SHA-256 ก่อนใช้ไฟล์
- **ข้อจำกัดรุ่นนี้:** runtime สำหรับแพ็ก PyThaiNLP ยังไม่เผยแพร่ จึงยังดาวน์โหลดติดตั้งแพ็กเหล่านี้จากแอปไม่ได้ หน้ารายการจะแสดงว่ายังไม่พร้อมให้ดาวน์โหลด

## ทีมเอเจน

- หลังสร้างทีมจากการ์ดในแชท เปิดแผงข้างแสดงทีม หัวหน้า สมาชิก และไฟล์ที่สร้าง
- เลือกงานเริ่มต้นของทีมเพื่อใส่ในกล่องข้อความได้ โดยไม่ส่งแทนผู้ใช้
- แผงทีมแสดงสถานะเมื่อยกเลิกการสร้างจากการ์ดเดิม

## การทำงานของผู้ช่วยและการอัปเดต

- ลดการถามยืนยันสิ่งที่ผู้ใช้สั่งแล้ว และให้ผู้ช่วยตัดสินใจเรื่องทางเทคนิคที่ย้อนกลับได้เอง
- เพิ่มการตรวจไฟล์และลายเซ็นของรุ่นก่อนเผยแพร่ เพื่อไม่ปล่อยรุ่นที่ตัวอัปเดตในแอปติดตั้งไม่ได้
