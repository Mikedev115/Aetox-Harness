# Aetox Mobile Android 0.3.17

**รุ่นนี้คือรุ่นที่มือถือเริ่มอัปเดตตัวเอง** — ไม่ต้องรอให้ Aetox บน Windows ออกรุ่นใหม่ก่อน
และนับจากรุ่นนี้ไป มือถือมีรอบปล่อยของตัวเอง

## มีอะไรใหม่

- **แอปถามที่ปล่อยเองว่ามีรุ่นใหม่ไหม** วันละครั้งตอนเปิดแอป อ่าน `mobile-latest.json` จากหน้าเว็บ (`https://mikedev115.github.io/Aetox-landing/mobile-latest.json`) แล้วเทียบ `versionCode` กับที่ติดตั้งอยู่ — เดิมตัวเลขนี้มาจาก `/install/meta` ของ PC ที่จับคู่ไว้เท่านั้น PC ที่ยังเป็นรุ่นเก่าจึงกลายเป็นเพดานของมือถือ (เช่น PC 1.11.30 บอกว่า 0.3.15 คือรุ่นล่าสุดทั้งที่ 0.3.16 ออกแล้ว)
- **แถบ "พร้อมติดตั้ง" ในแอป** ขึ้นใต้แถบสถานะเมื่อมีรุ่นใหม่ กด "อัปเดต" แล้วแอปโหลด APK จาก release ของรุ่นนั้น ตรวจ SHA-256 ให้ตรงกับที่ประกาศไว้ ก่อนส่งให้ตัวติดตั้งของ Android — ไม่ติดตั้งเงียบ ไม่มีสิทธิ์ใหม่
- **ไม่ประกาศว่ามีรุ่นใหม่เมื่อไม่แน่ใจ** เน็ตไม่ถึง ไฟล์ manifest ผิดรูปแบบ URL ไม่ได้มาจาก release ของเรา หรือแฮชไม่ครบ 64 ตัวอักษร → เงียบไว้ ไม่เด้งเตือน
- **หน้า "มือถือ" บน PC ยังใช้ได้** เป็นทางสำรองสำหรับเครื่องที่ออกเน็ตไม่ถึง GitHub — ติดตั้งจาก PC ได้เหมือนเดิม
- **ฝั่ง Windows ไม่ออกโดยขึ้นกับ APK อีก** `release-local.ps1` ตรวจ APK เฉพาะเมื่อมีไฟล์ใน worktree (ก่อนหน้านี้ถ้าไม่มี APK ที่ตรง `build.gradle` บิลด์ Windows หยุด)

## ต้องใช้

Android 10 ขึ้นไป · ติดตั้งรุ่นนี้**ครั้งเดียว**จาก release หรือหน้า download (รุ่นก่อนหน้า 0.3.16 ยังไม่รู้จัก manifest จึงต้องติดตั้งรุ่นนี้ด้วยมือ)
หลังจากนั้นการอัปเดตครั้งต่อไปมาจากในแอปเอง · การอัปเดตต้องออกเน็ตถึง GitHub ได้ (Tailscale อย่างเดียวไม่พอสำหรับขั้นนี้ แต่หน้า PC ยังติดตั้งให้ได้)
