# Aetox v1.9.26

วันที่ 16 ตุลาคม 2026

**จัดการประวัติแชทหลายรายการ และติดตั้งแพ็กเสียงไทยในเครื่องได้แล้ว**

## ประวัติแชท

- เลือกแชทหลายรายการเพื่อลบจากแถบข้างและหน้าประวัติ พร้อมตรวจรายการก่อนยืนยัน
- เพิ่มหน้าจัดการประวัติที่ค้นหาชื่อ กรองโปรเจกต์และอายุแชท และแบ่งหน้าได้ทั้งโต๊ะผู้ช่วยและโต๊ะโค้ด
- โต๊ะโค้ดกรองประเภทแชทและซ่อนแชทสั้นได้ โดยยังคงขอบเขตโปรเจกต์ที่กำลังเปิด
- ข้ามแชทที่ปักหมุดหรือกำลังทำงาน และแสดงผลของแต่ละรายการเมื่อมีรายการที่ลบไม่สำเร็จ

## เสียงภาษาไทยในเครื่อง

- เผยแพร่ runtime Python/ONNX สำหรับแพ็กเสียง PyThaiNLP แล้ว จึงติดตั้งจากหน้าจัดการแพ็กเสียงได้ ไม่ติดข้อจำกัด runtime ที่ยังไม่พร้อมใน v1.9.25
- ติดตั้งส่วนเสริมของ Vachana ให้อัตโนมัติ พร้อมตรวจขนาดและ SHA-256 ของไฟล์ก่อนใช้งาน
- ป้องกันการเปิดใช้ runtime ที่ติดตั้งไม่ครบหรือถูกยกเลิกระหว่างทาง และปฏิเสธไฟล์บีบอัดที่ชี้ออกนอกโฟลเดอร์ติดตั้ง

## การ์ดเปิดแชทใหม่

- แก้ช่องชื่อโปรเจกต์และช่องเลือกโฟลเดอร์ให้ใช้หน้าตาเดียวกับแอป ไม่แสดงช่องกรอกสีเทาแบบค่าเริ่มต้นของ browser
- เก็บการ์ดของแต่ละแชทไว้เมื่อสลับแชท แม้ engine ของแชทเดิมถูกปล่อยเพื่อคืนหน่วยความจำหรือสร้างใหม่หลังเปลี่ยนการตั้งค่า
- ป้องกันผลโหลดเก่าทับการ์ดใหม่หรือไปปรากฏในแชทอื่น โดยยังไม่เก็บการ์ดข้ามการปิดแอป

## การเชื่อมต่อและหน้าจอ

- ตั้งพอร์ต OAuth callback ของ Google Workspace ได้จากหน้าตั้งค่าการเชื่อมต่อ พร้อมแสดง redirect URI และเตือนเมื่อค่าพอร์ตขัดกัน
- แก้ชื่อโมเดลยาวหักบรรทัดในรายการเลือก และเมนูวิดีโอถูกตัดเมื่อเปิดใกล้ขอบพื้นที่
