# 🧩 Aetox v1.10.5

วันที่ 19 ตุลาคม 2026

**รุ่นแก้เล็ก: ปุ่ม ฟัง บนแผน รายการชิ้นงานที่อ่านออก และการ์ดแชทใหม่ที่ไม่ไหลตามลงท้ายแชท**

## ฟังแผนได้ ไม่ต้องอ่านเอง

- **เดิม** แผนในแท็บชิ้นงานมีแค่ ขอแก้แผน / แก้เอง / คัดลอก ปุ่ม ฟัง มีแค่ใต้คำตอบในแชท
- **รุ่นนี้**
  - แถบของแผนมีปุ่ม ฟัง อ่านทีละหัวข้อ: ชื่อแผนกับสถานะ แล้วแต่ละหัวข้อ ขั้นตอนอ่านเป็น "ขั้นที่ 1, …"
  - ใต้แถบมีบรรทัดบอกว่ากำลังอ่านส่วนไหน (เช่น 2 / 3) กด ■ หยุดได้ทุกเมื่อ
  - ใช้เสียงเดียวกับ ฟัง ในแชท ลิงก์อ่านแค่ชื่อเว็บ ไม่อ่าน URL ทั้งเส้น และการแบ่งโหลดเสียงเป็นชิ้นยังเป็นระบบเดิม
  - หัวข้อถัดไปเริ่มเมื่อหัวข้อก่อนเล่นจบเองเท่านั้น ถ้ากดหยุด เกิด error หรือมีเสียงอื่นมาแทน การอ่านแผนจบตรงนั้น

ไม่ได้ทำ: ปุ่มเล่นทีละขั้น และปุ่ม ฟัง บนรายงานปิดงาน

## แถวชิ้นงานขึ้นตัวเลขแปลก ๆ ทุกแถว

- **เดิม** ทุกแถวบอกชื่อโฟลเดอร์ที่ไฟล์อยู่ ซึ่งเกือบทุกไฟล์คือโฟลเดอร์ของแชทเอง ที่ตั้งชื่อตาม session
  ทุกแถวเลยขึ้น `20261019-183128.412` เหมือนกันหมด และ 11 แถวดันแผนลงไปครึ่งล่างของแท็บ
- **รุ่นนี้**
  - แถวบอกชนิดกับเวลาที่ได้ไฟล์ เช่น "เอกสาร · 18:31" "หน้าเว็บ · 18:40" "สไลด์ · 12 หน้า · 18:45" ใช้คำเดียวกับถาดไฟล์
  - บอกโฟลเดอร์เฉพาะไฟล์ที่อยู่นอกโฟลเดอร์ของแชท
  - รายการแสดง 4 แถว ที่เหลือพับไว้หลังแถว "อีก N ชิ้น" (แถวที่เลือกอยู่แสดงเสมอ)

## บรรทัด "เปิดแชทใหม่ที่ … แล้ว" ตามลงท้ายแชทตลอด

- **เดิม** การ์ดแชทใหม่ที่ agent เสนอถูกวาดต่อท้ายข้อความสุดท้ายเสมอ พอกด เริ่ม แล้วคุยต่อ
  บรรทัด "เปิดแชทใหม่ที่ ผู้ช่วย › แชทเปล่า แล้ว" ก็ลงมาอยู่ล่างสุดทุกข้อความ จนกว่าจะปิดแอป
- **รุ่นนี้** การ์ดอยู่ใน turn ที่มันเกิด ก่อนข้อความถัดไปของผู้ใช้ เลื่อนขึ้นไปตามประวัติเหมือนข้อความอื่น
  การ์ดที่ยังไม่กด เริ่ม ก็ใช้กฎเดียวกัน
