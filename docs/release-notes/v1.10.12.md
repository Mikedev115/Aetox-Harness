# 🧩 Aetox v1.10.12

วันที่ 21 ตุลาคม 2026

**Aetox จำเรื่องของคุณเป็นสายรายเรื่อง และเรียนโฟลเดอร์ความรู้ที่เชื่อมไว้ครั้งเดียว ไม่ต้องค้นทุกแชท**

## เรื่องของคุณแตกเป็นสาย โหลดเฉพาะเรื่องที่คุยอยู่

- **เดิม** ทุกอย่างที่ Aetox รู้เกี่ยวกับคุณอยู่ใน `USER.md` ไฟล์เดียวขนาด 4 KB ซึ่งส่งไปกับทุกคำขอ บนเครื่องที่ใช้งานมานาน ไฟล์นี้เต็ม (3,700 bytes) จนบันทึกประจำวันเริ่มทิ้งเรื่องใหม่ และเรื่องที่ต้องการมากกว่าหนึ่งประโยค เช่น เพลงที่ฟัง หรือร้านที่ทำ ก็ไม่มีที่ลง พอคุณบอกว่า "เปิดเพลง" ผู้ช่วยเลยต้องค้นแชทเก่าหา playlist เดิมซ้ำ
- **รุ่นนี้** เรื่องที่ยาวแยกเป็นสายของตัวเอง ไฟล์ละเรื่องในโฟลเดอร์ `memory/you/` ส่วน `USER.md` เหลือเฉพาะแกน สายจะถูกแนบไปกับข้อความเมื่อข้อความนั้นมีคำที่ตรงกับสาย ไม่เปลืองการเรียกเครื่องมือ และไม่ทำให้ cache ของ prompt เปลี่ยน ผู้ช่วยเปิดดูและแก้สายเองได้ (คำที่ใช้โหลดสาย ย้ายบรรทัด) ทุกการแก้มีปุ่มย้อนกลับ บันทึกประจำวันแตกสายให้เองเมื่อ `USER.md` ใกล้เต็ม และไม่ทิ้งเรื่องใหม่แบบเงียบ ๆ อีก แผนที่ความจำมีจุดของแต่ละสายห้อยอยู่ใต้ "คุณ"
- **ค้นแชทเก่า** ไม่ดึงข้อความของแชทที่กำลังค้นอยู่กลับมาเอง (เดิม 220 จาก 1,185 บรรทัดเป็นของแชทตัวเอง) คำค้นหลายคำต้องเจอครบทุกคำก่อน ถ้าไม่เจอถึงค่อยหาทีละคำ (ทดสอบกับคำค้นจริง 201 คำ: ค้นแล้วไม่เจอเลยลดจาก 35 เหลือ 11) ผลจัดกลุ่มตามแชท และพอเจอเรื่องของคุณที่ไม่เปลี่ยน ผู้ช่วยจะถูกเตือนให้จดไว้

ไม่ได้ทำ: ลูกมือไม่ได้อ่านสาย และสายไหนจะโหลดตัดสินจากคำที่ตรงกัน ไม่ได้ใช้ model ตัดสิน ถ้าคำตรงผิดหรือขาด ผู้ช่วยแก้คำของสายเองได้

## โฟลเดอร์ความรู้ที่เชื่อมไว้: เรียนครั้งเดียว ไม่ต้องค้นทุกแชท

- **เดิม** ผู้ช่วยถูกสั่งให้ "ค้นโฟลเดอร์ก่อนถาม" ทุกครั้งที่งานเกี่ยวกับคุณ บนเครื่องที่เชื่อมโฟลเดอร์ไว้ เครื่องมือถูกเรียกบนโฟลเดอร์นั้น 80 ครั้งใน 22 แชท และการค้นข้อความ 9 ใน 27 ครั้งไม่เจออะไรเลย ทั้งที่ไฟล์ไม่ได้เปลี่ยนมาสองเดือน ส่วนหน้า "คลัง" ต้องเลือกไฟล์ให้เรียนเองทุกครั้ง และสรุปของไฟล์ภาษาไทยบางไฟล์ออกมาเป็นภาษาจีนหรือเกาหลี
- **รุ่นนี้** หน้าต่าง "ให้ Aetox เรียนรู้" มีช่อง **"เรียนไฟล์ใหม่และไฟล์ที่แก้ในโฟลเดอร์เดียวกันให้เองต่อไป"** ผูกกับ model ที่แสดงอยู่ ตอนที่คุณไม่ได้ใช้งาน Aetox จะเรียนไฟล์ที่เพิ่มหรือแก้ **เฉพาะในโฟลเดอร์ของไฟล์ที่เลือก ไม่ลงไปในโฟลเดอร์ย่อย** ส่วนที่เหลือผู้ช่วยค้นเองเมื่องานต้องใช้ แล้วจดสิ่งที่เจอไว้ เพิ่มโฟลเดอร์ใหม่แล้วหน้าต่างนี้เปิดขึ้นเอง ข้อความบอกตรง ๆ ว่าไฟล์ไหนจะถูกส่งไปให้ผู้ให้บริการ
- การเรียนหนึ่งครั้งได้สองอย่าง คือสรุปของไฟล์ (เหมือนเดิม) และ **เรื่องของคุณที่ไฟล์บอก** ซึ่งลงสายเป็นบรรทัดที่ลงท้ายด้วย `← ไฟล์ต้นทาง` ผู้ช่วยเปิดไฟล์อ่านละเอียดได้เมื่อบรรทัดเดียวไม่พอ ถ้าไฟล์ถูกแก้แล้วเรียนใหม่ จะเปลี่ยนเฉพาะบรรทัดที่มาจากไฟล์นั้น บรรทัดที่คุณหรือผู้ช่วยแก้ไปแล้วจะไม่ถูกทับ
- ระบบกันไม่ให้ขยะเข้าความจำเอง ไม่ฝากไว้กับ model: ทุกบรรทัดต้องเป็นเรื่องของคุณ (ขึ้นต้นด้วย "ผู้ใช้") และเขียนเป็นภาษาเดียวกับความจำที่มีอยู่ ตอนทดสอบกับไฟล์จริง model ตัวเล็กเคยเอาสารบัญที่จดเรื่องเครื่องมือ กับคำแนะนำในบันทึก มาจดเป็น "เรื่องของคุณ" ระบบนี้ตัดพวกนั้นทิ้ง สรุปของไฟล์ภาษาไทยเป็นภาษาไทยแล้ว
- หน้า "คลัง": โฟลเดอร์ที่เรียนเองอยู่มีป้าย "เรียนเองต่อเนื่อง · model" และปุ่ม **หยุดเรียนเอง** หยุดแล้วสิ่งที่เรียนไปยังอยู่

ไม่ได้ทำ: ยังไม่ได้วัดว่าการค้นโฟลเดอร์ลดลงจริงเท่าไร ไฟล์ที่ถูกลบไปแล้วยังเหลือบรรทัดของมันในสาย (ผู้ช่วยเห็นว่าไฟล์ไม่มีแล้วก็แก้ได้) และส่วนที่ติ๊กไว้นับเป็น "เรียนแล้ว" ตั้งแต่ตอนติ๊ก ไม่ได้รอให้เรียนรอบแรกเสร็จก่อน

## ดูได้ว่าใครใช้ token ไปเท่าไหร่

- **เดิม** หน้าต่างคอนเท็กซ์แสดงได้แค่ของตัวหลัก ไม่รู้ว่าหัวหน้าทีม เอเจน หรือลูกมือที่ถูกจ้างใช้ไปคนละเท่าไหร่
- **รุ่นนี้** แผงขวามีแท็บ **"การใช้"** แสดงยอดรวม สัดส่วน cache hit/miss และตารางเรียงตามสายจ้างงาน (ใครจ้างใคร) แต่ละแถวมี model, token, cache และค่าใช้จ่าย คนที่ถูกจ้างหลายครั้งกางดูงานย่อยได้ ถ้าใช้แพ็กเกจที่ไม่มีบิล จะแสดง ≈ $ คิดจากราคา API ของผู้ขาย และไม่นำไปรวมกับยอดเงินจริง popover ของคอนเท็กซ์มีปุ่ม "ดูตามคนด้านข้าง" ข้อมูลทั้งหมดมีอยู่แล้วในฐานข้อมูล ไม่ได้เก็บอะไรเพิ่ม
