# v1.11.14

## ถามผู้ใช้ได้หลายเรื่องในใบเดียว

`ask_user` เดิมถามได้ครั้งละข้อเดียว และบล็อกทั้งเทิร์นจนกว่าจะได้คำตอบ — ต้นทุนของการถามจึงเป็น "เทิร์นหนึ่ง" โมเดลเลยเลี่ยงการถาม แล้วเดาแทน

รอบนี้ถามได้ **1–5 ข้ออิสระในการ์ดเดียว**:

- ตัวเลือกแรกของแต่ละข้อถูกทำเครื่องหมาย **(แนะนำ)** ให้เห็นชัด
- ข้ามข้อที่ไม่ต้องการตอบได้ (สถานะ `skipped` แยกจาก `unanswered`)
- พิมพ์คำตอบเองได้ทั้งช่องในการ์ดและช่องแชทเดิม
- คำถามที่คำตอบข้อหนึ่งขึ้นกับอีกข้อ ยังต้องแยกคนละครั้ง
- การ์ดขออนุญาต (อนุญาต / ปฏิเสธ) คงเป็นใบเดียว ไม่มีข้อ ไม่มีป้ายแนะนำ

ผลที่โมเดลได้รับเป็น JSON ต่อข้อ: `status` เป็น `answered` / `skipped` / `unanswered` พร้อม `outcome` ของทั้งครั้ง (`submitted`, `timed_out`, `cancelled`) จึงรู้ว่าข้อไหนได้คำตอบ ข้อไหนถูกข้าม และไม่เดาแทนเมื่อไม่มีคนตอบ

ผิวที่ใช้ได้เหมือนกัน: หน้าต่างแชท, คอนโซล CLI และแอปมือถือ (ถามเรียงทีละข้อ)

## สกิลและทิศทางของเดสก์ผู้ช่วย

- สกิลใหม่ `aetox-ask-user`: ถามเมื่อคำตอบเป็นสิทธิ์ของผู้ใช้ (เงิน คำสัญญากับคนอื่น รสนิยมของเขา) ไม่ถามเรื่องที่อ่านจากไฟล์หรือความจำได้ และเก็บคำตอบลงความจำเพื่อไม่ถามซ้ำ
- เดสก์ผู้ช่วยเปลี่ยนจาก "ตอบ ไม่ถาม" เป็น "ตอบเป็นค่าตั้งต้น และถามในสิ่งที่ผู้ใช้เท่านั้นตอบได้"

## แก้บัณฑิตที่เจอระหว่างทดสอบ

- ช่องพิมพ์ในการ์ดแย่ง caret ทุกครั้งที่การ์ดวาดใหม่ ทำให้พิมพ์ในช่องแชทไม่ได้ — โฟกัสครั้งเดียวต่อคำถามหนึ่งครั้งแล้ว
- การ์ดขออนุญาตมีอักษร A/B และป้าย (แนะนำ) เหมือนการ์ดคำถาม — ตัดออก ให้เหมือนเดิม
