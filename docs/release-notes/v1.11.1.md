# 🪟 Aetox v1.11.1

วันที่ 8 พฤศจิกายน 2026

**รุ่นนี้ซ่อมทางตันจุดเดียวในหน้าตั้งค่าผู้ให้บริการ — เจ้าที่เปิดสวิตช์ไว้แล้วแต่ตั้งค่าไม่จบเคยหายไปจากทั้งสองที่ที่ควรกดเข้าไปต่อได้ ตอนนี้มีประตูของตัวเองทั้งใต้การ์ดผู้ให้บริการและในหน้าต่างเพิ่มผู้ให้บริการ**

## ผู้ให้บริการที่เปิดไว้แต่ยังไม่ได้ตั้งค่า กลับเข้าไปตั้งค่าได้

- **เดิม** หน้าตั้งค่าผู้ให้บริการวาดการ์ดเฉพาะเจ้าที่มีอะไรอยู่ข้างหลังจริง (มีบัญชี มีคีย์ หรือเป็นรันไทม์ในเครื่อง) ที่เหลือถูกนับรวมเป็นบรรทัดเดียวว่า "ยังไม่ได้เพิ่ม N เจ้า — ซ่อนไว้ ไม่ได้ลบ" ซึ่งกดแล้วเปิดแคตตาล็อก ที่เจ้านั้นขึ้นป้าย "เพิ่มแล้ว" เป็นข้อความเฉย ๆ ไม่เปิดอะไร — เจ้าที่เปิดไว้แล้วตั้งค่าไม่จบจึงไม่มีทางกลับไปหน้าตั้งค่าของตัวเองได้จากที่ไหนเลย (owner, 8 พ.ย. 2026: "กดดูไม่ได้ มีแค่กดเพิ่ม")
- **รุ่นนี้** บรรทัดใต้การ์ดเลิกนับรวม แต่แยกเป็นแถวของแต่ละเจ้า มีโลโก้ ชื่อ และคำสถานะของตัวเอง กดแถวไหนก็เปิดหน้าตั้งค่าของเจ้านั้น · ป้าย "เพิ่มแล้ว" ในหน้าต่างเพิ่มผู้ให้บริการกลายเป็นปุ่มที่พาไปหน้าเดียวกัน
- **เจ้าที่แชทใช้อยู่ไม่ถูกซ่อนอีก** การ์ดของผู้ให้บริการที่โมเดลปัจจุบันวิ่งอยู่ถูกวาดเสมอ แม้จะยังไม่มีบัญชีหรือคีย์ติดตั้งไว้
- **ข้อความสามภาษา** บรรทัดนับใหม่เป็น "เปิดไว้แต่ยังไม่ได้ตั้งค่า N เจ้า" (เดิมอ่านเหมือนของที่ถูกซ่อนและไม่ได้เพิ่ม) และจีนได้คำแปลของบรรทัดนี้ครบแล้ว
- **ไฟล์** `ProviderPicker.svelte` · `ProviderAddDialog.svelte` · `Settings.svelte` · `locales/{th,en,zh}.ts` · `test/providerReach.test.ts` (ใหม่)
- **ไม่ได้แตะ** ฝั่ง Go, ฐานข้อมูล และหน้าตั้งค่าของผู้ให้บริการเอง — งานนี้เป็นงานหน้าจอทั้งชุด
