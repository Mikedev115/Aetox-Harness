# 🪟 Aetox v1.12.0

วันที่ 11 พฤศจิกายน 2026

**รุ่นนี้เพิ่มโหมดที่สี่ "มุ่งเป้า" — บอกเป้าแล้ว Aetox เขียนแผนเอง เดินทีละขั้นจนจบ และข้ามเทิร์นให้เองโดยไม่ต้องกดไปต่อ · มาพร้อมเพดานโทเคนที่ตั้งได้ และสองทางที่รันหยุดเองพร้อมบอกเหตุผล · คู่คิดเปิดไฟล์ในโปรเจกต์ได้แล้ว และการ์ดติดตั้งสกิลกลับมาอยู่ในมือเอเจนที่คุยกับคุณตรง ๆ**

## มุ่งเป้า: แผนที่เดินจนจบ ไม่จบเทิร์นตอนแผนยังไม่ครบ

- **เดิม** แผนมีไว้ดูและมีไว้ให้กด "ไปต่อ" เองทีละเทิร์น โมเดลตอบจบเทิร์นเมื่อไรงานก็หยุดตรงนั้น ถึงแผนจะยังเหลือขั้นที่ไม่ได้แตะ
- **รุ่นนี้** โหมด **มุ่งเป้า** (ตัวเลือกที่สี่ ถัดจากวางแผน) ถือแผนในห้องนั้นเป็นเป้าหมาย เอนจินตรวจทุกครั้งที่โมเดลจะจบเทิร์น: ถ้ายังมีขั้นที่ไม่เสร็จหรือยังไม่มีรายงานปิดงาน มันส่งกลับไปทำต่อ แล้วพอเทิร์นจบก็ตั้งเทิร์นถัดไปให้เองเมื่อไม่มีใครรอคิวอยู่ — พิมพ์แชทระหว่างนั้นได้เลย ข้อความของคุณมาก่อนแผนเสมอ
- เริ่มด้วยห้องที่ยังไม่มีแผนก็ได้: โหมดนี้สั่งให้เขียนแผนก่อนจากสิ่งที่คุณขอ แล้วจึงลงมือ ขั้นที่ทำไม่ได้ให้ทำเป็น "ล้มเหลว" พร้อมเหตุผล ไม่ปล่อยค้าง
- **ไฟล์** `internal/mode/stance.go` · `internal/engine/goal_run.go` · `internal/engine/stance.go` · `internal/engine/app.go` · `stances.ts` · `locales/th.ts`

## เพดานโทเคน และสองทางที่รันหยุดเองพร้อมบอกเหตุผล

- **เดิม** รันที่กดไปแล้วไม่มีเพดาน และไม่มีทางหยุดตัวเองนอกจากคนกดหยุด
- **รุ่นนี้** ตั้งงบโทเคนได้ (`PlanRunTokenBudget`, 0 = ไม่จำกัด) งบกินจาก usage ของแต่ละรอบจริง ไม่ใช่ขนาด context ที่ส่งซ้ำทุกครั้ง · หมดงบรันหยุดเองและขอรายงานปิดงานหนึ่งครั้ง · อีกทางคือ **ติดปัญหา**: สามเทิร์นติดที่ไม่เปลี่ยนอะไรเลย (ไม่มีขั้นขยับ ไม่มีหลักฐานใหม่) ทั้งสองกรณีการ์ดบอกเหตุผลเป็นภาษาไทยและปุ่ม "ไปต่อ" ยังกดได้ เพราะอุปสรรคอาจหมดไปแล้ว
- **ไฟล์** `internal/engine/goal_run.go` · `plan_run_store.go` · `usage.go` · `internal/engine/db.go` (migration 83) · `plan/view.ts` · `PlanPane.svelte`

## `/goal` ใช้ได้จากพาเลต

- **เดิม** การสั่งงานแผนต้องไปกดที่การ์ดแผน
- **รุ่นนี้** พิมพ์ `/goal` ในพาเลตแล้วได้แถวที่ตรงกับสถานะจริงของการ์ด — `/goal` เริ่ม, `/goal continue` ทำต่อจากแผนที่มี, `/goal pause` / `/goal stop` / `/goal resume` ตามที่รันอยู่ และ `/goal <เป้าหมาย>` พาเป้าหมายที่คุณพิมพ์เข้าไปเป็นเทิร์นเปิดรัน ไม่ใช่ประโยคสำเร็จรูป
- **ไฟล์** `Palette.svelte` · `stores/cockpit.svelte.ts` · `test/Palette.test.ts`

## คู่คิดเปิดไฟล์ได้แล้ว

- **เดิม** โหมดคู่คิดไม่ถือเครื่องมือเลยแม้แต่ตัวเดียว แผนที่เขียนไว้ในไฟล์หรือในแท็บอื่นจึงเปิดไม่ได้ คำตอบมาจากความจำหรือผลักให้คุณไปโหมดวางแผนเอาข้อมูลมาเอง
- **รุ่นนี้** คู่คิดถือดิสก์อย่างเดียว — `read`, `list`, `glob`, `grep` — ไม่มีการเขียน ไม่มีคำสั่ง ไม่มีเว็บ ไม่มี calc และไม่มีการส่งงานให้ใคร ยังไม่มีทางเปลี่ยนแปลงอะไรได้เหมือนเดิม แต่ตอบจากไฟล์ที่กำลังคุยกันได้จริง
- **ไฟล์** `internal/mode/stance.go` · `internal/mode/stance_test.go` · `actions_test.go`

## เอเจนติดตั้งสกิลให้ได้ในแชทตรง

- **เดิม** เอเจนในแชทที่คุณคุยด้วยตรง ๆ ตอบว่าไม่มีเครื่องมือติดตั้ง ทั้งที่คุณสั่งให้ติดตั้ง เพราะ `plugin_install` ถูกปฏิเสธไว้ในไฟล์โปรไฟล์ของ general ซึ่งเป็นบรรทัดที่กลไกคืนสิทธิ์ให้ไม่ได้
- **รุ่นนี้** มันถูกกันด้วยกลไก "ไม่มีใครกดการ์ด" แทน และคืนให้เมื่อมีคนนั่งอยู่ในแชทนั้น — การ์ดติดตั้งขึ้นให้คุณกด ลูกมือที่ไม่มีใครดูยังไม่ได้ และ `deny:` ของโปรไฟล์เองหรือเพดานของโต๊ะยังชนะเสมอ
- **ไฟล์** `internal/subagent/profile.go` · `store.go` · `profiles/subagents/general/AGENT.md` · `desk_surface_test.go`

## เอเจนฝั่งโค้ดขึ้นในหน้าบุคคล

- **เดิม** เพิ่มเอเจนเข้าฝั่งโค้ดแล้วมันไม่ขึ้นในหน้าบุคคลเลย หน้าจอถาม `ListChairs` ว่าใครเป็นเอเจน แต่ลิสต์นั้นคือโผของโต๊ะผู้ช่วย เอเจนฝั่งโค้ดจึงไม่อยู่ในกองไหนและหายทั้งแถว
- **รุ่นนี้** หน้าจออ่าน `desk` จากโปรไฟล์เอง ซึ่งเป็นฟิลด์เดียวกับที่ไดเรกทอรีใช้กรอง สองที่จึงไม่ตอบขัดกันได้อีก
- **ไฟล์** `Settings.svelte` · `test/personnel.test.ts`

## โฟลเดอร์ใหญ่ไม่ค้างตอนเก็บจุดย้อนกลับ

- **เดิม** เปิดโฟลเดอร์ใหญ่แล้วทั้งหน้าจอค้างโดยไม่มี error เพราะจุดย้อนกลับของเทิร์นถูกเก็บ *ก่อน* แถวของเครื่องมือจะขึ้นจอ และการเก็บคือ git pass ทั้งทรี
- **รุ่นนี้** แถวขึ้นจอก่อนแล้วค่อยเก็บ (ยังก่อนเครื่องมือจะรัน) และการเก็บมีเพดาน 15 วินาที ถ้าโฟลเดอร์ใหญ่เกินกว่านั้น เทิร์นนี้ไม่มีจุดย้อนกลับ — แลกแบบเดียวกับ badge ของ git และโฟลเดอร์ที่ใหญ่เกินจะ snapshot
- **ไฟล์** `internal/engine/app.go` · `internal/snapshot/capture_bound_test.go` · `internal/engine/undo_capture_order_test.go`
