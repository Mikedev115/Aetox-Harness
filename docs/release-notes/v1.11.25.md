# 🪟 Aetox v1.11.25

วันที่ 18 พฤศจิกายน 2026

รุ่นนี้เก็บของที่ค้างจากการใช้งานจริงห้าเรื่อง — แผนที่จบแล้วไม่ค้างเป็นกำลังรัน, หน้าสถิติที่อ่านยอดจริงได้, รีวิวความจำที่ไม่ถามทุกห้านาที, สกิลเอกสารสองตัวที่ไม่แย่งกัน และการ์ดจัดทีมที่บอกฐานของแต่ละที่นั่ง

## แผนที่จบแล้วไม่ค้าง "กำลังรัน"

- **เดิม** แถบแผนบนช่องพิมพ์ค้างเป็นรันอยู่ (จุด live + ปุ่ม พัก) ทั้งที่ขั้นครบและรายงานเขียนแล้ว และเปิดห้องเดิมวันหลังการ์ดขึ้น "หยุดกลางทาง — กดไปต่อได้" บนงานที่จบแล้ว
- **ต้นเหตุ** จุดเดียวที่ปิดรันคือ goal check ในลูปเทิร์น ซึ่งฝังอยู่บนออบเจกต์แชทและหายไปเมื่อแชทถูกสร้างใหม่ (เปลี่ยนโมเดล/ระดับ/โหมด หรือ config ที่พักไว้ลงกลางเทิร์น) พอถึงขอบเทิร์นจึงไม่มีอะไรปิดรัน — วัดจาก `aetox.db` จริง 18 พ.ย.: 3 ห้องขั้นครบ 100% มีรายงานแล้ว แต่แถวยัง running ไม่มี `ended_at`
- **ตอนนี้** ไม่มีขั้นค้างแล้วปิดรันเป็น done ที่ขอบเทิร์น · check ถูกติดตั้งคืนทุกครั้งที่สร้างแชทใหม่และตอนเปิดเทิร์น · แถวค้างที่ขั้นครบและมีรายงานของรอบนั้นอ่านเป็น done ไม่ใช่ "หยุดกลางทาง"
- **ไฟล์** `internal/engine/goal_run.go` · `internal/engine/plan_run_store.go` · `internal/turn/executor.go`

## หน้าสถิติ — เลขหลักคือยอดรวมทั้งประวัติ

- **เดิม** หน้าสถิติยกอัตราคาดการณ์ (18.3B ÷ 3 เดือน × 12 = 73.1B/ปี) ขึ้นเป็นเลขใหญ่ โดยมียอดจริงเป็นตัวจิ๋วบรรทัดล่าง กดดูเลขเต็มไม่ได้ และป้ายในหน้าเดียวปนสองภาษา
- **ตอนนี้** เพิ่ม "ทั้งหมด" เป็นตัวเลือกแรกและเป็นค่าที่เปิดมาเจอ — การ์ดทุกใบพิมพ์ยอดรวมทั้งประวัติ โดยอัตราต่อวัน/เดือน/ปีเป็นประโยคใต้เลข พร้อมบอกว่าคาดการณ์จากกี่เดือน
- **ตัวเลขกดได้** ตัวเลขที่ย่อทุกตัวกดแล้วเป็นเลขเต็มพร้อมหลักคั่นพัน กดซ้ำกลับเป็นแบบย่อ
- **โครงสร้างค่าใช้จ่าย** เปิดแยกตามค่ายพร้อมช่องติ๊กไม่นับค่ายนั้น — โทเคน ครั้งที่เรียก ตาราง และยอดรวมลดตาม ส่วนบทสนทนา ต่อเนื่อง และกราฟยังเป็นทั้งเครื่อง
- **ไฟล์** `desktop/frontend/src/lib/Settings.svelte` · `desktop/frontend/src/lib/locales/th.ts` · `desktop/frontend/src/lib/locales/en.ts`

## รีวิวความจำ — วันละครั้ง โควตา 3 ใบ และกฎลงไฟล์โปรเจกต์

- **เดิม** ตัวรีวิวเสนอ 213 ใบ อนุมัติ 45 (21%) ปฏิเสธ 122 (57%) และ 17 พ.ย. วันเดียว 24 ใบ — เพราะนาฬิกา idle 5 นาทีต่อแชทเรียกโมเดลทุกครั้งที่มีข้อความใหม่ ไม่มีโควตา และทุกคำตำหนิถูกเขียนเป็นกฎกลางที่ทุกเดสก์อ่าน
- **ตอนนี้** รีวิวอัตโนมัติเหลือ 1 ครั้ง/24 ชม., 3 ใบ/วัน, หยุดเมื่อคิวค้างถึง 8 ใบ · หนึ่งรอบส่งได้ไม่เกิน 3 ใบ · กฎที่มาจากแชทในโปรเจกต์ลงไฟล์ความจำของโปรเจกต์นั้น ส่วนกฎกลางเฉพาะแชทที่ไม่มีโปรเจกต์
- **ไม่เสนอซ้ำ** ถ้าโมเดลระบุว่าคำสั่งนั้นมีอยู่แล้ว ใบถูกทิ้งก่อนเข้าคิว และตัวรีวิวได้รับ `AGENTS.md`/`AETOX.md` ของโปรเจกต์ให้เทียบ
- **ลูกมือ** general/tester ไม่อ่าน `USER.md`, `SHAPE.md` และไฟล์ความจำของตัวเอง — บรีฟจากตัวหลักพาไปครบ
- **ไฟล์** `internal/engine/review.go` · `internal/learned/learned.go` · `internal/prompt/prompt.go` · `internal/subagent/profile.go`

## สกิลเอกสาร — หน้า HTML ในแชท กับกระดาษที่พิมพ์เซ็น

- **เดิม** `aetox-document` ประกาศว่าตัวเองเข้าครอบ "เอกสารที่ส่งเป็นไฟล์ — รายงาน ข้อเสนอ" ซึ่งหน้า HTML ที่ส่งเป็น artifact ก็เป็นไฟล์ คำขอทำรายงานเป็น HTML จึงเปิดสกิลกระดาษก่อน และ `aetox-report` เองก็เขียนว่า "หน้ากระดาษเป็นของ aetox-document" ต่อให้เปิดถูกก็ถูกส่งต่อ
- **ตอนนี้** สองทางแยกกันชัด — รายงานที่ส่งเป็นหน้า HTML เปิด `aetox-report`, เอกสารกระดาษที่พิมพ์เซ็นเปิด `aetox-document`

## การ์ดจัดทีมบอกฐานของแต่ละที่นั่ง

- **เดิม** การ์ดร่างทีมมีที่ให้ป้ายฐานอยู่แล้ว แต่ engine ไม่ส่ง `desk` มาสักครั้ง ป้ายจึงไม่เคยขึ้น — คนกดสร้างทีมไม่เห็นว่าที่นั่งแต่ละตัวจะไปยืนฐานไหน ทั้งที่ roster เดียวรับได้ทั้งสองฐาน (`subagent.memberCeiling`)
- **ตอนนี้** ที่นั่งทุกแถวมีป้าย "ฐาน…" — ค่าเริ่มต้นคือฐานผู้ช่วย (office) และบรรทัด `desk:` ของเอเจนเป็นตัวทับ
- **ตรวจบน dev** การ์ดร่างจริงขึ้น "ฐานโค้ด" ทั้งสองที่นั่ง tooltip ถูก ไม่ล้นคอลัมน์ และส่วนที่พับไว้ (`เพิ่มเติม`, `ทำไมจัดแบบนี้`) ยังกางได้ตามเดิม
- **ไฟล์** `internal/engine/org_card.go`
