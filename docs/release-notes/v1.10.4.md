# 🧩 Aetox v1.10.4

วันที่ 19 ตุลาคม 2026

**รุ่นแก้เล็ก: แพ็กเกจ Microsoft Store ผ่านการตรวจได้อีกครั้ง และหน้าต่างติดตั้งสกิลเลื่อนได้**

## อัปเดตผ่าน Microsoft Store ค้างที่การตรวจตั้งแต่ 1.9.11

- **เดิม** v1.9.11 แก้ปัญหาที่รุ่น Store กด "เปิดโฟลเดอร์ความจำ" แล้ว Explorer เปิด Documents แทน
  วิธีที่ใช้คือให้แพ็กเกจขอสิทธิ์ `unvirtualizedResources` เพื่อเขียน `%APPDATA%\aetox` ตัวจริง
  แต่ Microsoft ให้สิทธิ์นี้เฉพาะเกมของพาร์ตเนอร์ และแพ็กเกจแบบ external location เท่านั้น
  ทุก submission ที่มีสิทธิ์นี้จึงค้างที่ขั้น Certification ไม่เคยผ่าน คนที่ลงจาก Store เลยยังอยู่ที่ 1.9.10
- **รุ่นนี้**
  - แพ็กเกจ Store ไม่ขอสิทธิ์นั้นแล้ว manifest กลับไปเป็นแบบเดียวกับรุ่นที่เคยผ่าน
  - ปุ่มเปิดโฟลเดอร์ทุกปุ่มส่ง path ที่มีอยู่จริงให้ Explorer เอง ถ้าโฟลเดอร์อยู่ใน `Packages\...\LocalCache` ของแพ็กเกจก็เปิดที่นั่น
    ใช้ลำดับเดียวกับที่ Windows ใช้หาไฟล์ ปัญหาเปิด Documents จึงไม่กลับมา
  - เอาขั้นย้ายข้อมูลจาก LocalCache ไป AppData ตอนเปิดแอปออก เพราะ AppData ของรุ่น Store กลับไปเป็น virtualized แล้ว

ไม่ได้ทำ: รุ่น Store กับรุ่นติดตั้งจะไม่ได้ใช้โฟลเดอร์ข้อมูลเดียวกัน เพราะ Store ไม่อนุญาต
แต่ละรุ่นยังมีข้อมูลของตัวเองเหมือนก่อน 1.9.11

## หน้าต่างติดตั้งสกิลเลื่อนไม่ได้

- **เดิม** พอวางลิงก์ repo ที่มีสกิลเยอะ (`cursor/plugins` มี 169 สกิล) รายการจะถูกตัดที่ขอบหน้าต่าง
  เลื่อนต่อก็ไม่ได้ และปุ่มติดตั้งที่อยู่ท้ายการ์ดก็หายไปด้วย
- **รุ่นนี้** หน้าต่างเลื่อนได้ครบทุกรายการ แถวปุ่มยกเลิกกับปุ่มติดตั้งติดอยู่ที่ขอบล่างตลอดระหว่างเลื่อน

## เปลี่ยนอื่น ๆ ในรุ่นนี้

- tests ที่เพิ่มในรุ่นนี้: `TestStorePackageKeepsAppDataVirtualized` (manifest ห้ามมีสิทธิ์ที่ปิด virtualization),
  `TestPackagedPathFollowsTheOSLookupOrder`, `TestUnderRootIgnoresCaseAndNeedsASeparator`
- มือถือและ CLI: โค้ด Android ไม่เปลี่ยนตั้งแต่ `mobile-v0.3.2` จึงไม่ออก APK ใหม่ ตัวติดตั้งยังมี APK 0.3.2 พร้อม `android-build.json` เหมือนเดิม
  CLI ไม่เปลี่ยน ได้เอนจินใหม่ไปพร้อมรุ่นนี้
