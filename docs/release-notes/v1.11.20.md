# 🪟 Aetox v1.11.20

วันที่ 17 พฤศจิกายน 2026

**รุ่นนี้ปิดงานเอกเซลให้ครบวง: เขียนกราฟและตั้งค่าพิมพ์ลงไฟล์ .xlsx จริง, `sheet_edit` จัดรูปแบบ/แทรก-ลบ-เรียงแถว/ตรวจค่า/ไฮไลต์/อ่านสูตรได้, พรีวิวมีหัวคอลัมน์ A B C และแก้เซลล์ได้ด้วยดับเบิลคลิก — และมีห้อง "ตาราง" ที่รวมไฟล์ตารางของแชทไว้ที่เดียว · ห้องความสามารถได้ MCP เพิ่มอีก 40 ตัว (เกม 20 · แอนดรอยด์และมือถือ 20) พร้อมหน้านำเข้าที่แยกจากการติดตั้ง MCP**

## เอกเซล: ไฟล์ที่ส่งต่อได้จริง ไม่ต้องกลับไปทำใน Excel

- **เดิม** ตัวเขียน `.xlsx` ทำได้แค่ตาราง: หัวหนา+freeze, autoFilter, ความกว้างคอลัมน์ และฟอร์แมต 6 ตัว — กราฟและการตั้งค่าพิมพ์ยังต้องเปิด Excel ทำเอง
- **รุ่นนี้** กราฟ column/bar/line/pie เขียนเป็น chart part + drawing + rels จริง ชี้ช่วงในแผ่นงาน (แก้เลขแล้วกราฟขยับตาม ไม่ใช่ภาพวาด)
- ช่วงกราฟหยุดที่เรกคอร์ดสุดท้าย: แถวที่ขึ้นต้นด้วยข้อความและที่เหลือเป็นสูตรทั้งหมดคือแถวรวม จึงไม่ถูกพล็อตซ้ำ (ก่อนแก้ยอดทั้งปีถูกวาดซ้ำเป็นแท่งที่ 13)
- การพิมพ์: A4 แนวตั้ง/นอน, ย่อพอดีหนึ่งหน้ากว้าง, หัวตารางซ้ำทุกหน้าผ่าน `_xlnm.Print_Titles` — และชีตที่ไม่ได้ขอตั้งค่าพิมพ์จะไม่ถูกเดาให้
- ฟอร์แมตเพิ่ม 3 ตัวท้ายตารางสไตล์ (accounting, `d/m/yyyy`, `hh:mm`) โดยคง index 0–6 เดิมไว้ เพราะ index ถูกเขียนลงทุกเซลล์ของไฟล์ที่มีอยู่แล้วบนเครื่องคนใช้
- `sheet_write` รับ `page`/`charts` และรายงานกราฟที่วาดไม่ได้ (คอลัมน์ที่ระบุไม่มีอยู่) แทนที่จะทิ้งทั้งเล่ม

## `sheet_edit` ทำได้ครบขึ้น โดยไม่เพิ่ม tool ใหม่

- เพิ่ม 5 action ใน tool เดิม: `format` (สี/เส้นขอบ/จัดชิด/wrap/ความกว้าง-สูง), `rows` (แทรก-ลบ-เรียง), `validate` (dropdown), `conditional` (ไฮไลต์ตามเงื่อนไข), `formulas`
- `formulas` อ่านสูตรจริงด้วย `GetCellFormula` — ก่อนหน้านี้ `read` คืนค่าที่แคชไว้เท่านั้น สกิลตรวจไฟล์จึงต้อง unzip ดูเอง
- คงเพดานเดิม (64MB, 2000 เซลล์ต่อครั้ง) และคำอธิบาย schema เป็นอังกฤษล้วนตามกฎ "สิ่งที่โมเดลอ่านต้องเป็นอังกฤษ"

## ห้อง "ตาราง" และพรีวิวที่แก้ได้

- **เดิม** ความสามารถเอกเซลครบแต่ไม่มีห้องรวม — ไฟล์ `.xlsx` เปิดได้เฉพาะเป็นแท็บไฟล์ทีละไฟล์
- **รุ่นนี้** ห้อง "ตาราง" (`SheetsPane`) รวมไฟล์ `.xlsx` ของแชทจาก `ListArtifactsForSession` และใช้ `SheetPane` ตัวเดิมทางขวา — ไม่มีตารางชุดที่สองให้เลื่อนหา
- พรีวิว `.xlsx` มีหัวคอลัมน์ A B C, สลับดูกราฟได้ และไฟล์ที่ไม่มีกราฟก็กดดูกราฟได้ (แก้กราฟสด ๆ ในแผง)
- **ดับเบิลคลิกเซลล์แล้ว Enter คือบันทึก** ผ่าน `Engine.EditWorkbookCell` — เขียนเซลล์เดียวด้วยกติกาเดียวกับ `sheet_edit` (`=` คือสูตร, เลขที่มี `,` คั่นคือตัวเลข, ที่เหลือคือข้อความ) แล้วตอบด้วยพรีวิวของไฟล์ที่บันทึกแล้วจริง ไม่ใช่การเดาว่า Excel จะแสดงอะไร
- เพดานเดิม 8MB และชื่อเซลล์ต้องเป็น A1 เท่านั้น; ชีตที่ไม่มีจริงตอบ error ที่บอกชื่อชีต
- เซลล์สูตรในพรีวิวแสดงเป็นสูตร ไม่ใช่ค่าที่แคชไว้จนดูเหมือนไฟล์พัง

## ห้องความสามารถ: MCP เพิ่ม 40 ตัว และหน้านำเข้าแยกหน้า

- หมวดเกม 20 ตัว ครบทั้งทำเกมและเล่นเกม · สายแอนดรอยด์และมือถือ 20 ตัวที่ชั้นวางไม่เคยมี
- หน้านำเข้าจากแอปอื่นแยกจากหน้า MCP แล้ว และนำเข้าโปรแกรมที่มีอยู่แล้วจะเติมแถวเดิมแทนการสร้างซ้ำ
- ผลค้นทะเบียนวาดโลโก้จริง (ไม่ใช่ตัวอักษรย่อ), เซิร์ฟเวอร์ local ที่ต่อไม่ติดบอกสาเหตุถูกเรื่อง, chip "หาเพิ่ม" กรองจริงและนับเฉพาะ MCP

## เดสก์และหน้าจอ

- ปุ่ม "พับแผงนี้" ที่หัวแถบแท็บ ใช้ได้ทุกห้อง
- ห้องตารางตอนว่างเป็นข้อความกลางแผงเดียว ไม่ใช่สองฝั่งว่างคนละแบบ
- `TooltipLayer` ไม่เขียน state ตอนตัวเองถูกทำลายแล้ว
- แผงเหตุผลสดกางได้เฉพาะแถวที่กดเอง และหุบเมื่อเปลี่ยนแชท; แถวที่รันขนานกันไม่หายไปตอนหน้าต่างไม่ได้โฟกัส
- ตัวเลขข้างคำว่า "กำลังเชื่อมต่อ" นับเวลาของคำขอนั้น ไม่ใช่อายุของเทิร์น
- หน้าจอหยุดเฉพาะลูปที่ไม่มีใครดู (ไม่หยุดทุกแอนิเมชัน) และรู้ว่ามีคนอยู่จริงเมื่อมีอินพุต แล้วถามซ้ำระหว่างห่าง

## ซับเอเจน

- ภาระงานที่ไหลเข้าเร็วกว่าที่ทำทันเป็นเหตุผลให้ส่ง `delegate` — แต่ไม่ยิงซ้ำเมื่อผู้ใช้ส่งคำขอเดิม
