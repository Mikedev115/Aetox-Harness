# 🧩 Aetox v1.10.11

วันที่ 21 ตุลาคม 2026

**แชทผ่าน OpenRouter กลับมาใช้ cache ได้ และรูปที่แนบมา model ดูเองได้เลย ไม่ไปเปิดเครื่องมืออ่านรูปซ้ำ**

## แชทผ่าน OpenRouter ไม่ใช้ cache เลย

- **เดิม** แชท `glm-5.3-flash` ผ่าน OpenRouter ได้ Cache hit 0% ห้ารอบติดกัน แต่ละรอบรอ 13–20 วินาทีกว่าคำตอบจะเริ่มขึ้น OpenRouter มีผู้ให้บริการที่รัน model ตัวนี้ราว 35 เจ้า บางเจ้าไม่ได้ใช้ cache เลย และแชทเดียวกันก็ถูกย้ายไปมาระหว่างเจ้าได้
- **รุ่นนี้** Aetox ขอให้ OpenRouter ใช้บริษัทเจ้าของ model ก่อน เช่น `z-ai/...` ไป Z.AI ถ้าเจ้านั้นไม่ว่าง OpenRouter จะใช้เจ้าอื่นแทนแบบเดิม ผลทดสอบจริง: แชทที่ประวัติยาวขึ้นทุกรอบ ใช้ cache ได้ครบทุกส่วนที่ส่งไปแล้วในรอบก่อน ทั้งตอนกลาง turn และตอนข้าม turn

ไม่ได้ทำ: Gemini ยังทำงานแบบเดิม เพราะขอ Google ก่อนแล้ว cache ไม่ได้ดีขึ้น ส่วน model ที่ไม่มีเจ้าของรันเอง (เช่น Llama) ก็ยังได้เหมือนเดิม

## แนบรูปแล้ว model ไปเรียกเครื่องมืออ่านรูปอีกรอบ

- **เดิม** แนบภาพหน้าจอแล้ว model ไม่ตอบจากภาพทันที แต่ไปเรียก "อ่านรูป" ซึ่งเป็น OCR ที่อ่านภาษาไทยเพี้ยนบ่อย ทั้งที่ภาพถูกส่งไปพร้อมข้อความแล้ว ทดสอบด้วยภาพหน้าจอจริงรอบละ 12 ครั้ง: Claude Haiku 5.5 เรียกเครื่องมือ 12 ใน 12 ครั้ง, GLM 5.3 Flash 7 ใน 12 ครั้ง
- **รุ่นนี้** สำหรับ model ที่รู้แน่ว่ามองเห็นรูป ข้อความจะบอกตรง ๆ ว่ารูปอยู่ในข้อความนี้ ดูได้เลย ผลทดสอบชุดเดิม: ทั้งสองตัวเหลือ 0 ใน 12 ส่วน Kimi K3 กับ Gemini 3 Flash ที่ดูเองอยู่แล้วก็ยังดูเองเหมือนเดิม
- เปิดแชทเก่ากลับมา รูปจะไม่ได้ส่งไปกับประวัติอีก ข้อความเลยเปลี่ยนเป็นบอก model ว่ารูปไม่อยู่แล้ว ถ้าจะดูใหม่ให้เปิดไฟล์ตาม path แทน

ไม่ได้ทำ: model ที่ยังไม่รู้ว่ามองเห็นรูปหรือเปล่า ยังได้ข้อความแบบเดิม ที่บอกให้แจ้งผู้ใช้ตรง ๆ ถ้ามองไม่เห็นรูป
