# ห้องของออฟฟิศ · Room packs

ห้องของศูนย์บัญชาการเป็น **โฟลเดอร์** ไม่ใช่ปลั๊กอิน: วางโฟลเดอร์ลง `<DataRoot>/rooms/<id>/`
แอปก็อ่านเจอทันที ไม่มีขั้นติดตั้ง ไม่มี build ไม่มีเซิร์ฟเวอร์ของตัวเอง — แอปเสิร์ฟไฟล์ของแพ็กให้ที่
`/aetox-room/<id>/` เอง

A room is a folder. Drop it under `<DataRoot>/rooms/<id>/` and the app lists it; there is no
install step and no build.

## สามข้อที่แพ็กยึด · Three rules a pack keeps

1. **แพ็กไม่มีอำนาจ** — หน้าของแพ็กอยู่ใน `iframe sandbox="allow-scripts"` ไม่มี origin ของตัวเอง
   อ่านได้แค่ไฟล์ในโฟลเดอร์ตัวเอง ไม่ถึงดิสก์ เอนจิน หรือเน็ต
2. **คำเป็นของโฮสต์** — ป้ายทุกอันมาจาก `hello.words` แพ็กไม่เขียนภาษาเอง
3. **นักแสดงเป็นของแอป** — `roster` คือคนชุดเดียวที่แพ็กวาดได้ ห้ามวาดมาสคอตหรือตัวละครที่สอง

## เริ่มจากตัวอย่าง · Start from the example

`example-hospital/` เป็นแพ็กระดับข้อมูลที่ใช้ได้จริง — คัดลอกโฟลเดอร์ไปวางที่
`<DataRoot>/rooms/example-hospital/` แล้วเปิดการ์ดห้องบนหัวห้อง เลือก "Ward"

`id` ใน `room.json` ต้องตรงกับชื่อโฟลเดอร์

## ตรวจก่อนติดตั้ง · Check before installing

```
aetox room check <folder>
```

อ่านด้วยกฎตัวเดียวกับที่แอปใช้ (`internal/roompack`): **0** ผ่าน · **2** มีรหัสที่การ์ดจะขึ้น
พร้อมบรรทัดที่ควรแก้ · **1** ไม่ใช่โฟลเดอร์

## ผูกห้องกับโปรเจกต์ · Bind a room to a project

`.aetox.json` ในโฟลเดอร์โปรเจกต์ (`<DataRoot>/project/<ชื่อ>/.aetox.json`) รับคีย์ `room`:

```json
{ "description": "…", "room": "example-hospital" }
```

- ไม่มีคีย์ = ใช้ห้องที่เลือกไว้ในหน้าต่าง
- `"room": "builtin"` = โปรเจกต์นี้เอาห้องที่มากับแอป
- ลำดับ: โปรเจกต์ → ที่หน้าต่างเลือก → ห้องที่มากับแอป
